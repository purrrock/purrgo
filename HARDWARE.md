# PurrGO — Аппаратная архитектура

PurrGO — автономный GNSS-навигатор и трекер без функции расчёта маршрутов.

Основные требования к аппаратной части:

- автономная работа;
- низкое энергопотребление;
- GNSS-позиционирование;
- отображение предкомпилированных векторных карт;
- запись треков;
- управление физическими кнопками;
- хранение данных на microSD.

Подробности программной архитектуры описаны в [`docs/architecture.md`](docs/architecture.md).

---

## 1. Профили аппаратной разработки

В проекте используются две отладочные платы. Они предназначены для отладки STM32-кода и периферии. Обе платформы поддерживаются: F411 сохраняется после миграции на U585.

| Назначение | Development (F411) | Development (U585) |
|---|---|---|
| MCU | STM32F411CEU6 (128 Kbytes RAM) | STM32U585CIU6 (784 Kbytes RAM) |
| GNSS | GY-NEO6MV2 | GY-NEO6MV2 |
| Дисплей | Waveshare 2.7inch e-Paper HAT | Waveshare 2.7inch e-Paper HAT |
| Разрешение | 176 × 264 px | 176 × 264 px |
| Градации | 4 уровня серого | 4 уровня серого |
| Хранилище | microSD по SDIO (4 бита) | microSD по SPI2 (в 48-выводном корпусе U585CI нет SDMMC) |
| Питание | отладочная плата / USB | USB 5 В (питание от батарей и мониторинг батареи отложены) |
| Ввод | кнопки | кнопки |
| Распиновка | [`PurrGO_STM32F411_PINOUT.md`](PurrGO_STM32F411_PINOUT.md) | [`PurrGO_STM32U585_PINOUT.md`](PurrGO_STM32U585_PINOUT.md) |

Отладочные платы не являются частью финального устройства. Их задача — разработка и отладка переносимого программного ядра и периферийных драйверов. План миграции: [`TODO_migrate.md`](TODO_migrate.md).

### GNSS

Для разработки используется **GY-NEO6MV2** на базе CASIC AT6558R.

Модуль удобен для экспериментов благодаря готовой плате и стандартным выводам.

### Финальный GNSS

Для Release используется **G10A F30**.

Модуль имеет выводы:

```text
1PPS
VCC
TX
RX
GND
EN
```

Питание модуля: 3.3–5 V согласно имеющейся документации на модуль.

Гибкие выводы G10A F30 делают его менее удобным для макетной разработки, поэтому для разработки используется GY-NEO6MV2.

Финальная аппаратная конфигурация:

| Компонент | Release |

| MCU | STM32U585CIU6 ( 786 Kbytes RAM) |

| Градации | 4 уровня серого |
| Интерфейс дисплея | SPI |
| Хранилище | microSD |

| Питание | 1 × 18650 Li-ion |

## 3. Микроконтроллер

Release MCU:

**STM32U585CIU6**

Использование STM32U5 обусловлено требованиями к низкому энергопотреблению и наличием необходимой периферии для GNSS, SPI, DMA, microSD и дисплея.

Аппаратно-зависимый код STM32 размещается в платформенном слое. Подробнее — в [`docs/architecture.md`](docs/architecture.md).

---

## 4. Дисплей

Release-дисплей:

**Waveshare 2.7inch e-Paper HAT**

Основные параметры:

- разрешение физической панели: 264 × 176;
- ориентация PurrGO: **portrait**;
- логическое разрешение PurrGO: **176 × 264**;
- 4 градации серого;
- интерфейс SPI.

Дисплей является единственным предусмотренным Release-дисплеем.

Подробности подключения и управления дисплеем должны находиться в документации его драйвера и аппаратной схемы, а не в этом документе.

---

## 5. Кнопки

На этапе разработки используются четыре встроенные кнопки Waveshare 2.7inch e-Paper HAT (K1…K4). На платах STM32F411 и STM32U585 они подключены к PA0, PA1, PC14, PC15 (см. `PurrGO_STM32F411_PINOUT.md`, `PurrGO_STM32U585_PINOUT.md`). Количество и расположение кнопок финального устройства пока **TBD**; нужно определить в процессе разработки, достаточно ли четырёх кнопок для интерфейса PurrGO.

Отдельный тачскрин для Release не предусматривается.

## 6. GNSS

### Development

```text
GY-NEO6MV2
    |
    | UART
    v
STM32
```

### Release

```text
G10A F30
    |
    | UART
    v
STM32U585CIU6
```

Для передачи данных между GNSS-приёмником и MCU используется UART.

1PPS G10A F30 может использоваться для точной синхронизации времени, если эта функция потребуется в финальной прошивке.

---

## 7. microSD

microSD используется как основное внешнее хранилище:

- карты;
- записанные треки;
- путевые точки;
- конфигурация.

Для разработки используется microSD-модуль (картридер) с выводом Detect и подтяжками на модуле: на F411 он подключён по SDIO (шина 4 бита), на U585 по SPI (в корпусе UFQFPN48 у STM32U585CI нет SDMMC).

Для Release будет приобретён **модуль microSD с низким рабочим напряжением**, рассчитанный непосредственно на систему 3.3 V. Модуль с преобразованием питания на 5 V для Release не используется.

Структура данных:

```text
/PURRGO/
    /maps/
    /tracks/
    /waypoints/
    /config/
```

Предкомпилированные карты находятся в `/PURRGO/maps/`.

Формат карт описан в [`docs/purrgo_map_specification_v3.md`](docs/purrgo_map_specification_v3.md).

## 8. Питание

Основной источник питания Release:

**1 × 18650 Li-ion**

Цель проекта — получить длительную автономную работу при минимальном собственном потреблении цепей питания.

На данном этапе конкретная схема преобразования напряжения не фиксируется.

При выборе окончательной схемы необходимо учитывать:

- диапазон напряжения разряда 18650;
- допустимое напряжение питания STM32U585;
- допустимое напряжение GNSS-модуля;
- питание microSD;
- питание дисплея;
- ток покоя преобразователей;
- необходимость отключения отдельных потребителей.

Особое внимание должно быть уделено току покоя преобразователей: при низком среднем потреблении PurrGO он может существенно влиять на время автономной работы.

## 9. Цели автономной работы

Для Release установлены следующие проектные цели:

| Режим | Цель |
|---|---:|
| Непрерывная навигация | ≥ 24 ч |
| Типичный режим | ≥ 36 ч |
| Экспедиционный режим | ≥ 48 ч |

Это **цели проекта**, а не заявленные характеристики готового устройства.

Фактическое время работы должно быть определено измерениями после завершения аппаратной и программной реализации.

## 10. Основные аппаратные интерфейсы

Архитектура Release предусматривает:

```text
                    +----------------+
                    |   STM32U585    |
                    |                |
                    | UART <---------+---- G10A F30
                    |                |
                    | SPI  ----------+---- E-Ink
                    |                |
                    | SPI  ----------+---- microSD
                    |                |
                    | GPIO <---------+---- Buttons
                    |                |
                    | 1PPS <---------+---- GNSS
                    +----------------+
```

Распиновка отладочных плат ведётся в `PurrGO_STM32F411_PINOUT.md` и `PurrGO_STM32U585_PINOUT.md`. Распиновка Release должна быть зафиксирована отдельно после разработки аппаратной схемы Release.

---

## 11. Принципы аппаратной архитектуры

1. Release использует STM32U585CIU6.
2. GNSS Release — G10A F30.
3. Для разработки GNSS используется GY-NEO6MV2.
4. Release-дисплей — Waveshare 2.7inch e-Paper HAT.
5. Рабочее разрешение дисплея в PurrGO — 176 × 264.
6. Карты и пользовательские данные хранятся на microSD.
7. Данные PurrGO находятся в каталоге `/PURRGO/`.
8. Release питается от одной Li-ion ячейки 18650.
9. Количество и расположение кнопок финального устройства пока не определены (на этапе разработки используются 4 кнопки E-Ink HAT).
10. Аппаратные детали, не утверждённые проектом, не должны фиксироваться как окончательные параметры.
