# План: ревью проекта PurrGO + предложения доработок

## Цель

Провести полное ревью проекта офлайн GNSS-навигатора PurrGO (STM32U585 + E-Ink 2.7") и оформить результат:

1. **Новый документ** `docs/review-2026-11.md` — структурированное ревью по подсистемам с находками, рисками и рекомендациями.
2. **Дополнение `TODO.md`** — новые пункты работ из рекомендаций ревью, вписанные в существующую структуру приоритетов и стиля меток.

Код **не меняется** (по выбору владельца: только предложения).

## Метод ревью

Единый чек-лист по каждой области: корректность/устойчивость к плохим данным, границы слоёв, ресурсные лимиты (стек 8 КБ, RAM ~90 % занято), энергопотребление, тестируемость, дрейф документации.

## Структура документа `docs/review-2026-11.md`

1. Резюме (общая оценка, топ-5 рекомендаций).
2. Сильные стороны (что уже хорошо: архитектура core/platform, тесты, CI, энергостратегия).
3. По подсистемам: наблюдения → риски → рекомендации, каждая находка со ссылкой `файл:строка` и серьёзностью (высокая/средняя/низкая).
4. Доработки по направлениям: функциональность (POI-поиск, V4-индекс, читалка), энергия, качество/надёжность, инструментальная цепочка.
5. Сводная таблица рекомендаций с приоритетами, увязанная с разделами TODO (P1..P4/Backlog).

## Правила дополнения TODO.md

- Новые пункты добавляются только для рекомендаций, которых нет в TODO.md (проверка на дубли перед добавлением).
- Соблюдать стиль: разделы P1–P4/Backlog, метки **[HW]/[CubeMX]/[решение]/[проверить]**, ссылки на файлы/доки.
- В ревью-документе рядом с каждой рекомендацией указывать, попала ли она в TODO.md.

## Проверка результата

- Все находки в документе снабжены `файл:строка`; факты сверены с кодом (никаких домыслов без пометки «требует проверки»).
- Документ не противоречит существующим docs; расхождения (как eink.md) фиксируются как находки, молча не правятся (правки доков — отдельное решение владельца).
- `TODO.md`: новые пункты не дублируют существующие; нумерация/стиль сохранены.
- Итог в чате: краткое резюме ревью + список добавленных пунктов TODO.
