# PurrGO — руководство пользователя

Что умеет устройство, как им управлять и какие файлы нужны на microSD. Аппаратная часть - [`hardware.md`](hardware.md), устройство
ПО - [`architecture.md`](architecture.md).

## Запуск

При включении на экране показывается баннер с логотипом PurrGO и номером версии
(в Debug-сборке внизу плашка `DEBUG BUILD`), затем открывается карта.

## Кнопки

Четыре аппаратные кнопки в ряд под экраном: KEY1 | KEY2 | KEY3 | KEY4. На плате STM32U585 это кнопки E-Ink HAT K1…K4 на PA0, PA1,
PC14, PC15 (см. [`PurrGO_STM32U585_PINOUT.md`](../PurrGO_STM32U585_PINOUT.md)). Функции кнопок зависят от экрана. В нижней строке
экрана показаны подсказки (в читалке экран целиком занят текстом).

События: SHORT_PRESS и LONG_PRESS.

## Карта

| Event        | KEY1     | KEY2      | KEY3   | KEY4                       |
|--------------|----------|-----------|--------|----------------------------|
| SHORT_PRESS  | PAN_LEFT | PAN_RIGHT | PAN_UP | PAN_DOWN                   |
| LONG_PRESS   | ZOOM_OUT | ZOOM_IN   | CENTER | NEXT_SCREEN → TRIP_COMPUTER|

CENTER (долгое K3) возвращает автоследование и ставит маркёр GNSS в центр карты. Пока автоследование выключено (карта сдвинута
кнопками), в центре карты рисуется перекрестие: это точка для WAYPOINT > MAP CENTER.

Слои карты включаются в меню MAP LAYERS (порядок отрисовки и стиль - [`architecture.md`](architecture.md#layer-drawing-order)): LANDUSE, WATER (вместе
с линейными водными объектами), LANDUSE LABELS, WATER LABELS, ROADS, POI, POI LABELS, ROUTE, WAYPOINT, TRACK. Цель навигации рисуется
иконкой цели вместо прицела.

## Trip computer

| Event        | KEY1 | KEY2 | KEY3 | KEY4                          |
|--------------|------|------|------|-------------------------------|
| SHORT_PRESS  | NONE | NONE | NONE | NEXT_SCREEN → MENU            |
| LONG_PRESS   | NONE | NONE | NONE | NEXT_SCREEN → MENU            |

Экран показывает данные GNSS-решения, цель навигации и (при приёмнике UBX) диагностику приёмника.

### Поля

| Поле | Что показывает | Когда и как отображается |
|---|---|---|
| `LOC:` | местное время `ЧЧ:ММ` | UTC плюс часовой пояс из пункта меню TZ. До первого фикса время не определено (нули плюс смещение TZ) |
| `UTC:` | время UTC `ЧЧ:ММ` | берётся из решения GNSS. После потери фикса остаётся последнее известное значение |
| `SPD:` | скорость над землёй, `км/ч` | целое число (дробная часть отбрасывается). Без фикса `0 km/h` |
| `CRS:` | курс (направление движения) в градусах, от севера по часовой стрелке, два знака после точки | `N/A`, если фикса нет, скорость ниже 0,5 м/с (1,8 км/ч) или приёмник оценивает точность курса хуже 45° |
| `WPT:` | имя цели навигации | цель выбирается в меню WAYPOINT (HERE, MAP CENTER, точка из GPX). Без цели `NONE` |
| `DST:` | расстояние до цели | пусто, если цели нет; `---`, если цель есть, но фикса нет. Формат: до 1 км - `250 m`, до 10 км - `2.35 km`, до 100 км - `12.3 km`, дальше - `153 km`. В радиусе 15 м от цели добавляется `ARRIVED` |
| `BRG:` | пеленг на цель: градусы от истинного севера и румб (`N`, `NE`, `E`, `SE`, `S`, `SW`, `W`, `NW`), например `045 deg NE` | пусто, если цели нет; `---`, если нет фикса |
| `FIX:` | есть ли фикс | `3D` - решение есть, `NO` - нет (приёмник не дал решения или замолчал на 5 с). Различие 2D и 3D на экране не показывается |
| `SAT:` | число спутников, использованных в решении (`numSV` из UBX-NAV-PVT) | обновляется и без фикса |
| `LAT:` / `LON:` | широта и долгота в десятичных градусах, 7 знаков после точки; минус - южное полушарие и западная долгота | без фикса остаются последние известные значения |
| `ALT:` | высота над уровнем моря (MSL), метры | целое число. Без фикса остаётся последнее известное значение |

Без фикса значения LAT, LON, ALT, UTC и LOC не очищаются, а остаются последними известными: ориентируйтесь на поле `FIX:`.

### Компас на цель

Справа от строк `WPT`/`DST`/`BRG` рисуется круглый компас: кольцо с восемью засечками и буквами N, E, S, W снаружи.

- Компас появляется, когда задана цель (`WPT` не `NONE`).
- Стрелка рисуется, когда есть фикс (то есть известны расстояние и пеленг). Без фикса виден только циферблат.
- Если курс надёжен (фикс есть, курс определён и скорость не меньше 1 узла, около 1,85 км/ч), циферблат повёрнут по курсу: вверх экрана
  направлено движение, буква N стоит там, где север. Стрелка показывает цель относительно направления движения: стрелка вверх - цель
  прямо по курсу.
- Если курс ненадёжен (стоите на месте или идёте очень медленно), вверху стоит N, стрелка показывает истинный пеленг на цель от севера.

### Солнце

Блок появляется после первого фикса с момента включения и дальше пересчитывается раз в минуту, пока есть фикс. Время восхода и захода
показывается местное (с учётом TZ).

| Строка | Значение |
|---|---|
| `SUN: ЧЧ:ММ-ЧЧ:ММ` | восход и заход Солнца сегодня в этой точке |
| `TO SUNSET: ЧЧh ММm` | сколько осталось до захода (днём) |
| `TO SUNRISE: ЧЧh ММm` | сколько осталось до восхода (ночью; вместо `TO SUNSET`) |
| `DAY: ЧЧh ММm` | продолжительность светового дня |
| `POLAR DAY` / `POLAR NIGHT` | полярный день или полярная ночь: захода (восхода) нет, длина дня `24h 00m` (`00h 00m`) |

### Данные приёмника UBX

Четыре нижние строки видны только в сборке с приёмником UBX (`PURRGO_GNSS_UBX = 1`, у G10A-F30 это так). `---` в любой из них
означает, что свежих данных нет: сообщение не приходило последние 3,5 с.

| Поле | Что показывает | Пояснение |
|---|---|---|
| `TRP:` | `12.34 km` - дистанция трека | пройденный путь по одометру приёмника с начала записи текущего трека (одометр сбрасывается при создании нового GPX-файла). Если запись выключена (LOG: OFF), счётчик не сбрасывается и считает с последнего сброса или включения приёмника. Разрешение 10 м |
| `ACC:` | `H1.5 m V2.3 m` - точность | `H` - оценка погрешности по горизонтали, `V` - по вертикали, метры с десятыми. `---` при отсутствии фикса |
| `SIG:` | `JAM ... SPF ...` - глушение и спуфинг | см. таблицу ниже |
| `RF:` | `CW10 AGC35 CN38` - состояние радиотракта | см. ниже |

**SIG**: `JAM` - глушение, `SPF` - подмена сигнала (спуфинг). Источник: глушение берётся из UBX-MON-RF (`jammingState`, с включённым ITFM), а спуфинг из UBX-NAV-STATUS
(`spoofDetState`). Если нет ни одного свежего источника, показывается `---`; если нет одного из двух - у него `--`.

| Значение JAM | Смысл | Значение SPF | Смысл |
|---|---|---|---|
| `--` | неизвестно | `--` | неизвестно или выключено |
| `OK` | глушения нет | `OK` | признаков спуфинга нет |
| `WARN!` | обнаружено глушение | `IND!` | есть признак спуфинга |
| `CRIT!` | сильная помеха, фикса нет | `AFF!!` | несколько признаков спуфинга |

**RF** собирается из трёх значений:

- `CW<n>` - уровень узкополосной (непрерывной) помехи в процентах, шаг 5;
- `AGC<n>` - уровень усиления входного каскада (AGC) в процентах, шаг 5; высокое значение говорит о сильной помехе;
- `CN<n>` - средний C/N0 спутников, использованных в решении, дБ-Гц (чем выше, тем лучше приём). Показанное значение меняется,
  только когда новое отличается больше чем на 1 дБ, чтобы не перерисовывать экран из-за шума;
- `CW-- AGC--` или `CN--` - соответствующих данных нет (для CN - ещё и если в решении нет спутников);
- `SHORT!` или `OPEN!` в конце - приёмник сообщил о замыкании или обрыве антенны. У G10A-F30 нет схемы контроля антенны, поэтому
  обычно эта пометка не появляется.

### Когда обновляется экран

Данные накапливаются каждую секунду, но чтобы не жечь панель E-Ink, экран перерисовывается не чаще раза в 5 с и только если изменилось одно из:

- минуты в `LOC`/`UTC`;
- позиция сместилась на 5 м и больше;
- скорость изменилась на 1 узел (около 1,85 км/ч) и больше, высота - на 5 м и больше, изменилось число спутников;
- расстояние до цели изменилось на 5 м и больше, пеленг - на 5° и больше, цель достигнута или потеряна;
- изменились значения `TRP`, `ACC`, `SIG` или `RF` (по их шагам округления).

Исключение: появление или потеря фикса перерисовываются сразу. Поэтому показания на экране могут отставать от реальных на несколько
секунд или на величину этих порогов.

## Меню

| Event        | KEY1 | KEY2 | KEY3   | KEY4 |
|--------------|------|------|--------|------|
| SHORT_PRESS  | UP   | DOWN | SELECT | BACK |
| LONG_PRESS   | UP   | DOWN | SELECT | BACK |

Главное меню (заголовок `==== MENU ====`) и его подэкраны (каталог карты, маршрут, WAYPOINT, MAP LAYERS) реагируют одинаково на
короткое и длинное нажатие. BACK из главного меню применяет и сохраняет изменённые настройки и переходит на карту.

| Пункт | Что делает |
|---|---|
| BOOKS | вход в режим чтения книг (GNSS и запись трека выключаются) |
| POWER: ... | источник питания, SELECT перебирает шесть вариантов по кругу (у типов элементов разные кривые разряда, шестой - внешние 5 В) |
| POWER OFF | выключение: трек закрывается, настройки сохраняются, показывается экран выключения |
| TRACKER (SCREEN OFF) | трекер с отключённым дисплеем (ниже) |
| TZ: UTC+HH:MM | часовой пояс, шаг 15 минут |
| MAP DIR | выбор каталога карты в `/PURRGO/MAPS/` |
| ROUTE | выбор GPX-файла маршрута из `/PURRGO/ROUTES/` (NONE - без маршрута); после выбора карта переходит на маршрут, см. ниже |
| OPEN TRACK | просмотр записанного трека из `/PURRGO/TRACKS/` как маршрута (подробнее ниже) |
| WAYPOINT | цель навигации: HERE (текущая позиция), MAP CENTER (центр карты), точка из GPX (см. ниже) |
| POI | NO → CIRCLES → ICONS |
| LOG | запись трека: OFF → STANDARD → EXPEDITION |
| SD LOG | дублировать диагностический лог (тот же, что идёт в UART) в файл на SD: OFF / ON (подробнее ниже) |
| SOUND | звуковые сигналы пьезоизлучателя: OFF (по умолчанию) / ON. При включении звучит короткий проверочный сигнал (подробнее ниже) |
| MAP DETAILS | LOW / HIGH |
| MAP LAYERS | включение слоёв карты |

### Звуковые сигналы (SOUND)

Пока SOUND = OFF, прибор молчит полностью, в том числе при разряде батареи. Включённый звук подаёт сигналы:

| Сигнал | Событие |
|---|---|
| длинный громкий | запись трека остановлена из-за низкого питания; запись оборвалась (сбой SD) |
| двойной громкий | прибытие к цели навигации (радиус 15 м); повторно - после того, как отошли дальше 30 м |
| короткий | первый фикс GNSS после включения |
| тихий щелчок | нажатие кнопки (в режиме трекера с отключённым экраном кнопки молчат) |

Настройка применяется по BACK, как остальные пункты меню, и хранится в `PURRGO.CFG` (`SOUND=0|1`).

### Лог на SD (SD LOG)

Пункт `SD LOG` включает копию диагностического лога (то, что прошивка пишет в UART) в файл `0:/PURRGO/LOGS/LOG.TXT`.
Нужен, когда прошивку проверяют вдали от компьютера: после прогулки карту читают на компьютере. Каждая строка начинается
с времени работы: `[сек.мс]`.

- Включение применяется по BACK, как остальные настройки, и сохраняется в `PURRGO.CFG` (`SD_LOG=1`). Выключено по умолчанию:
  запись на карту потребляет ток.
- При каждом включении прежний `LOG.TXT` переименовывается в `LOG.OLD` (тот, что был раньше, заменяется), создаётся новый.
- Сообщения копятся в памяти и сбрасываются на карту каждые 2 с (физическая запись - раз в 10 с), поэтому при внезапном
  выключении можно потерять последние секунды. Если карты нет, запись откладывается и повторяется сама; после сбоя карты
  файл дописывается дальше.
- Размер ограничен примерно 2 МБ за запуск. Если сообщений слишком много и они не успевают уйти на карту, лишние
  отбрасываются, в файл попадает строка `[SD LOG: N messages dropped]`.
- Уровень сообщений определяется сборкой (`PURRGO_LOG_LEVEL`): в Release по умолчанию остаются только ошибки.

### Просмотр маршрута и записанного трека

Выбор файла в пункте **ROUTE** (каталог `ROUTES/`) или **OPEN TRACK** (каталог `TRACKS/`) включает слой Route и сразу переводит карту на
выбранную линию: центр карты ставится в центр линии, масштаб - наименьший, при котором линия целиком помещается в окно карты. Автоследование
за GNSS при этом выключено (в центре перекрестие); долгое K3 (CENTER) возвращает его. Масштаб и положение можно менять обычными кнопками карты.

В списке **OPEN TRACK** треки показаны по времени старта в местном времени (`2026-11-16 08:12`), новые сверху; имена файлов треков
(`2F8A91C3.gpx`) - это время старта в UTC, и в список они выводятся уже расшифрованными. Файлы с другими именами и файлы прежнего формата
имён показываются как есть. Трек, который пишется прямо сейчас, помечен `REC` и не открывается: он и так нарисован слоем TRACK. Выбранный
трек в списке отмечен `*`, в главном меню пункт ROUTE показывает `TRK <время>`.

Открытый трек - обычный маршрут: рисуется слоем Route (чёрная линия 3 px с белой серединой) под слоем TRACK. Трек длиннее 4096 точек прореживается
по расстоянию (начало и конец остаются). Путевые точки `<wpt>` у записанного трека не читаются (в нём их нет); цель WAYPOINT берётся из WAYPTS.
Выбор нового файла из любого из двух списков заменяет прежний; NONE в списке ROUTE снимает маршрут или трек.

### Трекер с отключённым дисплеем

Пункт `TRACKER (SCREEN OFF)` (сразу под `POWER OFF`): трек пишется как в режиме EXPEDITION, экран не обновляется, на дисплее
остаётся предупреждение о записи трека и отключённом экране. Все кнопки игнорируются, кроме одновременного удержания **K1 и K4** в
течение `PURRGO_BTN_COMBO_HOLD_MS` (1 с): это событие `PURRGO_BTN_COMBO_K1_K4`, выход на карту. Вне режима трекера комбинация
ничего не делает.

В режиме трекера приёмник GNSS работает в экономном режиме PSMCT: точка трека записывается раз в 10 секунд
(`PURRGO_GNSS_TRACKER_PERIOD_S`), приёмник между решениями спит. Это снижает ток, но трек получается реже, чем на
карте (поворот на малой скорости записывается с меньшей точностью). При выходе в карту приёмник возвращается к решениям
раз в секунду, и первый фикс возвращается через несколько секунд.

### Маршруты и путевые точки

Линия маршрута рисуется по точкам `<trkpt>` и `<rtept>` выбранного файла; точки `<wpt>` из него линию не образуют, они используются как
путевые точки (меню WAYPOINT и слой Waypoints). Слой Waypoints рисует иконкой все `<wpt>` из файлов `/PURRGO/WAYPTS/` и из выбранного
маршрута; одновременно показывается не более 64 точек, первыми берутся точки маршрута. Пункт WAYPOINT > MAP CENTER записывает точку в
центре карты в `/PURRGO/WAYPTS/` (`MPnnnnnn.GPX`) и делает её целью навигации.

## Экранная клавиатура (En/Ru)

Экранная клавиатура (`include/purrgo/keyboard.h`, экран - `src/core/ui/ui_keyboard.c`)
предназначена для ввода строки поиска объектов на карте и текста в книгах.
Раскладки EN, RU и SYM (цифры и знаки); Shift: выключен → один раз → Caps.
Текст набирается в кодировке PurrGO-256 (как названия на карте и текст книг).

| Event        | KEY1                | KEY2          | KEY3                      | KEY4              |
|--------------|---------------------|---------------|---------------------------|-------------------|
| SHORT_PRESS  | курсор влево        | курсор вправо | нажать клавишу под курсором | курсор вниз     |
| LONG_PRESS   | стереть символ      | курсор вверх  | готово (ввод принят)      | отмена            |

Курсор по строкам и столбцам замыкается. На экране подсказки кнопок в двух нижних строках.
Клавиатура подключена к читалке: состояние `APP_STATE_BOOK_SEARCH_INPUT` (ввод строки поиска по книге).
Для поиска объектов на карте её ещё не подключали.

## Читалка (BOOKS)

Режим читалки экономичнее навигатора: GNSS и запись трека отключены, дисплей в режиме 1 bit, книга читается из RAM, SD при
перелистывании не используется. Между нажатиями кнопок МК стоит в Stop 2 (пробуждение по кнопке или по таймеру).

### Что происходит при входе и выходе

- Вход выключает запись трека (`purrgo_logger_stop()`) и GNSS (`purrgo_gnss_power_off()`), выход включает GNSS
  (`purrgo_gnss_power_on()`); трек после выхода начнётся заново по первому фиксу. В режиме чтения FSM не
  перерисовывает экран по времени и позиции, логика трека не работает.
- Дисплей в режиме 1 bit (`DISPLAY_MODE_MONO`): перелистывание - быстрое частичное обновление всего экрана
  (каждое 10-е обновление библиотека `epd4g` заменяет полным).
- Первый вход открывает последнюю книгу (`BOOK_FILE`) на сохранённой странице; если книги нет или она не
  открылась - список.

### Экран страницы

Верхняя строка (8 px) - инверсный статус `страница/всего` и заряд батареи; ниже 25 строк по 29 символов
(ячейка 6 x 8 px, шаг строк 10 px, первая строка на y = 12, поля сверху и снизу по 4 px; геометрия PGB 1.1).
Подсказок кнопок на экране нет: он целиком занят текстом.

Страница-картинка (обложка, иллюстрация) занимает окно 176 x 256 под строкой статуса: картинка по центру, 1 bit на
пиксель (1 - чёрный), рисуются только чёрные пиксели. Картинка всегда на отдельной странице, листается теми же
кнопками. Размеры картинки лежат в записи индекса страницы, поэтому до распаковки известно, что на странице.

### Кнопки

| Screen / event       | KEY1                  | KEY2                  | KEY3                       | KEY4                       |
|----------------------|-----------------------|-----------------------|----------------------------|----------------------------|
| List, SHORT / LONG   | вверх / на 8          | вниз / на 8           | открыть книгу              | выход в главное меню       |
| Page, SHORT          | страница назад        | страница вперёд       | переход по процентам       | выход в главное меню       |
| Page, LONG           | на 10 страниц назад   | на 10 страниц вперёд  | список книг                | **поиск по книге**         |
| Go to %, SHORT/LONG  | -1% / -10%            | +1% / +10%            | перейти                    | отмена                     |
| Search found         | предыдущее совпадение | следующее совпадение  | новый запрос (LONG: список)| закончить поиск            |
| Search running       | -                     | -                     | -                          | остановить                 |
| Not found            | -                     | -                     | править запрос             | закрыть сообщение          |

### Поиск по книге

Поиск: K4 (долгое) на странице открывает экранную клавиатуру, запрос принимается долгим K3.
Поиск идёт с начала открытой страницы вперёд до конца книги и затем с начала книги; регистр не
учитывается, Е и Ё считаются одной буквой, фраза может переходить на следующую строку и страницу,
слово - быть разорвано переносом. Найденный текст подсвечен инверсией, строка статуса показывает
`FIND страница/всего`. Страницы-картинки пропускаются.

### Позиция чтения и книги

Запоминается последняя открытая книга и страница: перелистывание обновляет позицию только в RAM, на SD она пишется по тайм-ауту (60 с без
перелистывания) и при выходе из режима. Если книгу перекомпилировали, чтение начинается с первой страницы. Книги делает конвертер
[`tools/book-compiler`](../tools/book-compiler/README.md) из txt, FB2 и EPUB.

## Данные на microSD

Каталоги создаются при монтировании карты, имена в верхнем регистре:

```text
0:/PURRGO/
    PURRGO.CFG          конфигурация (ключ=значение), пишется атомарно
    MAPS/<имя карты>/   предкомпилированные карты (каталог выбирается пунктом MAP DIR; формат - map-format-v3.md)
    TRACKS/             записанные треки (GPX)
    ROUTES/             маршруты (GPX)
    WAYPTS/             путевые точки (GPX)
    BOOKS/              книги (.PGB)
    LOGS/               диагностический лог (LOG.TXT, прошлый запуск - LOG.OLD); пункт меню SD LOG
```

- Маршруты и путевые точки: GPX, имя файла до 95 символов, расширение `.gpx`. Записанные треки лежат в `TRACKS/` и открываются пунктом OPEN TRACK
  без копирования в `ROUTES/`.
- Книги: файлы `.PGB`, в списке до 48 книг, имя файла до 95 байт.
- Как сделать карту: [`tools/map-compiler/README.md`](../tools/map-compiler/README.md); формат: [`map-format-v3.md`](map-format-v3.md).
