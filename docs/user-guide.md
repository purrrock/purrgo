# PurrGO — руководство пользователя

Что умеет устройство, как им управлять и какие файлы нужны на microSD. Аппаратная часть - [`hardware.md`](hardware.md), устройство
ПО - [`architecture.md`](architecture.md).

## Кнопки

Четыре аппаратные кнопки в ряд под экраном: KEY1 | KEY2 | KEY3 | KEY4. На плате STM32U585 это кнопки E-Ink HAT K1…K4 на PA0, PA1,
PC14, PC15 (см. [`PurrGO_STM32U585_PINOUT.md`](../PurrGO_STM32U585_PINOUT.md)). Функции кнопок зависят от экрана. В нижней строке
экрана показаны подсказки (в читалке экран целиком занят текстом).

События: SHORT_PRESS и LONG_PRESS. DOUBLE_PRESS пока не поддерживается.

## Карта

| Event        | KEY1     | KEY2      | KEY3   | KEY4                       |
|--------------|----------|-----------|--------|----------------------------|
| SHORT_PRESS  | PAN_LEFT | PAN_RIGHT | PAN_UP | PAN_DOWN                   |
| LONG_PRESS   | ZOOM_OUT | ZOOM_IN   | CENTER | NEXT_SCREEN → TRIP_COMPUTER|

CENTER (долгое K3) возвращает автоследование и ставит маркёр GNSS в центр карты. Пока автоследование выключено (карта сдвинута
кнопками), в центре карты рисуется перекрестие: это точка для WAYPOINT > MAP CENTER.

Слои карты включаются в меню MAP LAYERS (порядок отрисовки и стиль - [`map-rendering.md`](map-rendering.md)): LANDUSE, WATER (вместе
с линейными водными объектами), LANDUSE LABELS, WATER LABELS, ROADS, POI, POI LABELS, ROUTE, WAYPOINT, TRACK. Цель навигации рисуется
иконкой цели вместо прицела.

## Trip computer

| Event        | KEY1 | KEY2 | KEY3 | KEY4                          |
|--------------|------|------|------|-------------------------------|
| SHORT_PRESS  | NONE | NONE | NONE | NEXT_SCREEN → MENU            |
| LONG_PRESS   | NONE | NONE | NONE | NEXT_SCREEN → MENU            |

Показывает время (UTC и местное), скорость, курс, координаты, высоту, качество фикса и, если задана цель, расстояние и пеленг до неё.

## Меню

| Event        | KEY1 | KEY2 | KEY3   | KEY4 |
|--------------|------|------|--------|------|
| SHORT_PRESS  | UP   | DOWN | SELECT | BACK |
| LONG_PRESS   | UP   | DOWN | SELECT | BACK |

Главное меню (заголовок `==== MENU ====`) и его подэкраны (каталог карты, маршрут, WAYPOINT, MAP LAYERS) реагируют одинаково на
короткое и длинное нажатие. BACK из главного меню применяет и сохраняет изменённые настройки и переходит на карту.

| Пункт | Что делает |
|---|---|
| BOOKS | вход в режим чтения книг (GNSS и запись трека выключаются) |
| POWER: ... | источник питания, SELECT перебирает шесть вариантов по кругу (у типов элементов разные кривые разряда, шестой - внешние 5 В) |
| POWER OFF | выключение: трек закрывается, настройки сохраняются, показывается экран выключения |
| TRACKER (SCREEN OFF) | трекер с отключённым дисплеем (ниже) |
| TZ: UTC+HH:MM | часовой пояс, шаг 15 минут |
| MAP DIR | выбор каталога карты в `/PURRGO/MAPS/` |
| ROUTE | выбор GPX-файла маршрута из `/PURRGO/ROUTES/` (NONE - без маршрута) |
| WAYPOINT | цель навигации: HERE (текущая позиция), MAP CENTER (центр карты), точка из GPX (см. ниже) |
| POI | NO → CIRCLES → ICONS |
| LOG | запись трека: OFF → STANDARD → EXPEDITION |
| MAP DETAILS | LOW / HIGH |
| MAP LAYERS | включение слоёв карты |

### Трекер с отключённым дисплеем

Пункт `TRACKER (SCREEN OFF)` (сразу под `POWER OFF`): трек пишется как в режиме EXPEDITION, экран не обновляется, на дисплее
остаётся предупреждение о записи трека и отключённом экране. Все кнопки игнорируются, кроме одновременного удержания **K1 и K4** в
течение `PURRGO_BTN_COMBO_HOLD_MS` (1 с): это событие `PURRGO_BTN_COMBO_K1_K4`, выход на карту. Вне режима трекера комбинация
ничего не делает.

### Маршруты и путевые точки

Линия маршрута рисуется по точкам `<trkpt>` и `<rtept>` выбранного файла; точки `<wpt>` из него линию не образуют, они используются как
путевые точки (меню WAYPOINT и слой Waypoints). Слой Waypoints рисует иконкой все `<wpt>` из файлов `/PURRGO/WAYPTS/` и из выбранного
маршрута; одновременно показывается не более 64 точек, первыми берутся точки маршрута. Пункт WAYPOINT > MAP CENTER записывает точку в
центре карты в `/PURRGO/WAYPTS/` (`MPnnnnnn.GPX`) и делает её целью навигации.

## Экранная клавиатура (En/Ru)

Экранная клавиатура (`include/purrgo/keyboard.h`, экран - `src/core/ui/ui_keyboard.c`)
предназначена для ввода строки поиска объектов на карте и текста в книгах.
Раскладки EN, RU и SYM (цифры и знаки); Shift: выключен → один раз → Caps.
Текст набирается в кодировке PurrGO-256 (как названия на карте и текст книг).

| Event        | KEY1                | KEY2          | KEY3                      | KEY4              |
|--------------|---------------------|---------------|---------------------------|-------------------|
| SHORT_PRESS  | курсор влево        | курсор вправо | нажать клавишу под курсором | курсор вниз     |
| LONG_PRESS   | стереть символ      | курсор вверх  | готово (ввод принят)      | отмена            |

Курсор по строкам и столбцам замыкается. На экране подсказки кнопок в двух нижних строках.
Клавиатура подключена к читалке: состояние `APP_STATE_BOOK_SEARCH_INPUT` (ввод строки поиска по книге).
Для поиска объектов на карте её ещё не подключали.

## Читалка (BOOKS)

Режим читалки экономичнее навигатора: GNSS и запись трека отключены, дисплей в режиме 1 bit, книга читается из RAM, SD при
перелистывании не используется. Между нажатиями кнопок МК пока стоит в Sleep (`WFI`, тик 1 кГц); переход в Stop 2 запланирован
([`TODO.md`](../TODO.md), P1).

### Что происходит при входе и выходе

- Вход выключает запись трека (`purrgo_logger_stop()`) и GNSS (`purrgo_gnss_power_off()`), выход включает GNSS
  (`purrgo_gnss_power_on()`); трек после выхода начнётся заново по первому фиксу. В режиме чтения FSM не
  перерисовывает экран по времени и позиции, логика трека не работает.
- Дисплей в режиме 1 bit (`DISPLAY_MODE_MONO`): перелистывание - быстрое частичное обновление всего экрана
  (каждое 10-е обновление библиотека `epd4g` заменяет полным).
- Первый вход открывает последнюю книгу (`BOOK_FILE`) на сохранённой странице; если книги нет или она не
  открылась - список.

### Экран страницы

Верхняя строка (8 px) - инверсный статус `страница/всего` и заряд батареи; ниже 25 строк по 29 символов
(ячейка 6 x 8 px, шаг строк 10 px, первая строка на y = 12, поля сверху и снизу по 4 px; геометрия PGB 1.1).
Подсказок кнопок на экране нет: он целиком занят текстом.

Страница-картинка (обложка, иллюстрация) занимает окно 176 x 256 под строкой статуса: картинка по центру, 1 bit на
пиксель (1 - чёрный), рисуются только чёрные пиксели. Картинка всегда на отдельной странице, листается теми же
кнопками. Размеры картинки лежат в записи индекса страницы, поэтому до распаковки известно, что на странице.

### Кнопки

| Screen / event       | KEY1                  | KEY2                  | KEY3                       | KEY4                       |
|----------------------|-----------------------|-----------------------|----------------------------|----------------------------|
| List, SHORT / LONG   | вверх / на 8          | вниз / на 8           | открыть книгу              | выход в главное меню       |
| Page, SHORT          | страница назад        | страница вперёд       | переход по процентам       | выход в главное меню       |
| Page, LONG           | на 10 страниц назад   | на 10 страниц вперёд  | список книг                | **поиск по книге**         |
| Go to %, SHORT/LONG  | -1% / -10%            | +1% / +10%            | перейти                    | отмена                     |
| Search found         | предыдущее совпадение | следующее совпадение  | новый запрос (LONG: список)| закончить поиск            |
| Search running       | -                     | -                     | -                          | остановить                 |
| Not found            | -                     | -                     | править запрос             | закрыть сообщение          |

### Поиск по книге

Поиск: K4 (долгое) на странице открывает экранную клавиатуру, запрос принимается долгим K3.
Поиск идёт с начала открытой страницы вперёд до конца книги и затем с начала книги; регистр не
учитывается, Е и Ё считаются одной буквой, фраза может переходить на следующую строку и страницу,
слово - быть разорвано переносом. Найденный текст подсвечен инверсией, строка статуса показывает
`FIND страница/всего`. Страницы-картинки пропускаются.

### Позиция чтения и книги

Запоминается последняя открытая книга и страница: перелистывание обновляет позицию только в RAM, на SD она пишется по тайм-ауту (60 с без
перелистывания) и при выходе из режима. Если книгу перекомпилировали, чтение начинается с первой страницы. Книги делает конвертер
[`tools/book-compiler`](../tools/book-compiler/README.md) из txt, FB2 и EPUB.

## Данные на microSD

Каталоги создаются при монтировании карты, имена в верхнем регистре:

```text
0:/PURRGO/
    PURRGO.CFG          конфигурация (ключ=значение), пишется атомарно
    MAPS/<имя карты>/   предкомпилированные карты (каталог выбирается пунктом MAP DIR; формат - map-format-v3.md)
    TRACKS/             записанные треки (GPX)
    ROUTES/             маршруты (GPX)
    WAYPTS/             путевые точки (GPX)
    BOOKS/              книги (.PGB)
```

- Маршруты и путевые точки: GPX, имя файла до 95 символов, расширение `.gpx`.
- Книги: файлы `.PGB`, в списке до 48 книг, имя файла до 95 байт.
- Как сделать карту: [`tools/map-compiler/README.md`](../tools/map-compiler/README.md); формат: [`map-format-v3.md`](map-format-v3.md).
