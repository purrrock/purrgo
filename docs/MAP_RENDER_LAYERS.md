Порядок отображения слоёв на дисплее, от самого нижнего к верхнему:
1. landuse — полигоны
2. water — полигоны
3. waterways — линии (реки, ручьи, каналы); слой `waterways.idx/.mlp` формируется компилятором карт, прошивка его пока не открывает и не рисует
4. подписи landuse
5. подписи water
6. roads — линии
7. POI — точки
8. подписи POI
9. route — линии: GPX-файл из каталога ROUTES, чёрная линия 3 px с белой линией 1 px по центру (`route.c`)
10. waypoints — иконка 46 из `purrgo_poi_icons.c` для каждой точки `<wpt>` выбранного маршрута и всех GPX-файлов каталога WAYPTS, не более 64 точек (`wpt_layer.c`)
11. track — линии
12. цель навигации (WAYPOINT) — иконка 35 из `purrgo_poi_icons.c` (булавка, остриё в точке цели)
13. перекрестие центра карты — иконка 47; только при выключенном автоследовании (карта сдвинута кнопками), это точка для WAYPOINT > MAP CENTER
14. GNSS marker
