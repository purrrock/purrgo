# Руководство по сборке проекта PurrGo в Visual Studio Code (ОС Windows)

## Требования к рабочему окружению
1. Установленный компилятор C/C++ для Windows (MinGW-w64 GCC или MSVC из состава Build Tools for Visual Studio).
2. Утилита CMake (путь к исполняемому файлу должен быть добавлен в системную переменную `PATH`).
3. Visual Studio Code со следующими расширениями:
   * **C/C++** (от Microsoft)
   * **CMake Tools** (от Microsoft)

## Открытие и конфигурация
1. Откройте директорию клонированного репозитория `purrgo` в VS Code (`File` -> `Open Folder...`).
2. При первом открытии расширение CMake Tools запросит выбор комплекта инструментов компилятора (Select a Kit). 
   * Выберите установленный компилятор (например, `GCC ... x86_64-w64-mingw32` или `Visual Studio Build Tools ... amd64`).
   * Если меню не отобразилось, нажмите `Ctrl+Shift+P`, введите команду `CMake: Select a Kit` и выберите компилятор.
3. Расширение автоматически запустит процесс конфигурации CMake. В панели Output (вкладка CMake/Build) должна появиться информация об успешной генерации файлов сборки. Для ручного запуска конфигурации используйте `CMake: Configure`.

## Компиляция проекта
1. На нижней панели статуса VS Code нажмите на кнопку **Build** (или клавишу `F7`).
2. По умолчанию будут собраны все цели (Targets). Для сборки конкретной программы нажмите на кнопку выбора цели рядом с кнопкой Build и выберите `pc_realtime_logger`.
3. После завершения компиляции бинарный файл `.exe` будет находиться во вложенной директории внутри папки `build/` (путь зависит от конфигурации генератора, по умолчанию `build/apps/pc_realtime_logger/pc_realtime_logger.exe`).

## Запуск и отладка с передачей аргументов
Так как исполняемый файл требует явной передачи номера COM-порта, запуск через встроенную кнопку расширения CMake приведет к выводу справочной информации (`Usage: ... <COM_PORT>`) и завершению программы с кодом 1.

**Метод 1: Запуск через интегрированный терминал**
1. Откройте терминал в VS Code (`Terminal` -> `New Terminal` или `Ctrl+~`).
2. Вызовите скомпилированный файл, передав порт в качестве аргумента:
   ```cmd
   .\build\apps\pc_realtime_logger\pc_realtime_logger.exe COM3
   ```

**Метод 2: Настройка отладчика (файл launch.json)**
Для полноценного использования точек останова (breakpoints) и отладчика необходимо создать конфигурацию запуска.
1. Перейдите в панель Run and Debug (`Ctrl+Shift+D`).
2. Нажмите `create a launch.json file` и выберите используемый отладчик (C++ GDB/LLDB для MinGW или C++ Windows для MSVC).
3. В созданном файле `.vscode/launch.json` укажите путь к бинарному файлу в поле `program` и добавьте аргумент в массив `args`:
   ```json
   {
       "version": "0.2.0",
       "configurations": [
           {
               "name": "Debug PC Logger",
               "type": "cppdbg",
               "request": "launch",
               "program": "${workspaceFolder}/build/apps/pc_realtime_logger/pc_realtime_logger.exe",
               "args": ["COM3"],
               "stopAtEntry": false,
               "cwd": "${workspaceFolder}",
               "environment": [],
               "externalConsole": false,
               "MIMode": "gdb",
               "setupCommands": [
                   {
                       "description": "Enable pretty-printing for gdb",
                       "text": "-enable-pretty-printing",
                       "ignoreFailures": true
                   }
               ]
           }
       ]
   }
   ```
4. Сохраните файл и запустите сессию отладки кнопкой `F5`.
