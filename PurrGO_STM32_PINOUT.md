# PurrGO — STM32F411CEU6 Development Board Pinout

> Рабочий документ проекта. Здесь фиксируется фактическое назначение выводов STM32F411CEU6 на этапе разработки PurrGO.
>
> **Правило:** если подключение ещё не подтверждено или не решено, оно явно помечается как `НЕ РЕШЕНО`. Не следует считать такое назначение установленным.

## 1. Контроллер

- MCU: **STM32F411CEU6**
- Проект: **PurrGO**
- Назначение текущего этапа: разработка и отладка GNSS-навигатора/логгера.
- Отладочный интерфейс: ST-LINK.
- Отладочный текстовый вывод: UART2.

## 2. Основные интерфейсы

| Интерфейс STM32 | Назначение | Статус |
|---|---|---|
| SPI1 | Периферийные устройства, в частности дисплей | Частично определено |
| SPI2 | MicroSD-карта | **Определено** |
| UART1 | GNSS-приёмник | **Определено** |
| UART2 | Отладочный лог | **Определено** |

### SPI1

SPI1 зарезервирован для периферийных устройств проекта.

В частности, планируется использовать его для дисплея.

**Точные GPIO SPI1 и отдельные GPIO управления дисплеем пока не фиксируются в этом документе, пока их не подтвердим по текущей конфигурации CubeMX/проекту.**

### SPI2 — MicroSD

SPI2 используется для связи с MicroSD-картой.

- Интерфейс: **SPI2**
- Назначение: **MicroSD**
- CS карты: **PB12** — это уже настроено в CubeMX.
- Остальные сигналы SPI2: используются аппаратным SPI2 согласно текущей конфигурации CubeMX:
SPI2 настроен как Master, 8 bit, Mode 0, software NSS, MSB first, делитель 256.
Физические линии SPI2 по текущему spi.c: PB10 = SCK, PB14 = MISO, PB15 = MOSI.
CS SD: PB12, active-low, и он инициализируется в GPIO как выход с начальным уровнем HIGH.

> Примечание: На текущем этапе выбран **SPI2**. В проекте содержимое карты должно располагаться в каталоге `PURRGO`. В релизном проекте планируется переход на SDIO.

### UART1 — GNSS

UART1 предназначен для подключения GNSS-приёмника.

- Интерфейс: **UART1**
- Назначение: **GNSS**
- Передача данных GNSS → STM32: используется вход UART.
- Передача команд STM32 → GNSS: используется выход UART, если потребуется.

**Точные GPIO UART1 и конкретная схема TX/RX пока не зафиксированы в этом документе.**

### UART2 — отладочный лог

UART2 предназначен исключительно для диагностического текстового вывода во время разработки.

- Интерфейс: **UART2**
- Назначение: **debug log**
- Подключение: STM32 → USB-UART адаптер → ПК.
- Используемый USB-UART адаптер: PL2303TA TTL.
- Терминал с параметрами `115200`, `8N1` для отладочного UART.

**Точные GPIO UART2 пока не зафиксированы в этом документе.**

## 4. E-Ink дисплей

Для релизного устройства используется **2.9" E-Ink 176×264, 4 градации серого**.

Подключение дисплея ещё не зафиксировано в этом документе.

Для справки: документация Waveshare для имеющегося 2.7" e-Paper HAT указывает SPI-сигналы DIN/CLK/CS и управляющие сигналы DC/RST/BUSY; конкретная распиновка STM32 из примера Waveshare относится к другой плате (Open103Z) и **не должна автоматически переноситься на STM32F411CEU6**.

## 5. GNSS

GNSS-приёмник является отдельным UART-устройством.

| Сигнал | STM32 | Статус |
|---|---|---|
| GNSS TX → STM32 RX | UART1 RX GPIO | **НЕ РЕШЕНО** |
| STM32 TX → GNSS RX | UART1 TX GPIO | **НЕ РЕШЕНО** |
| GND | GND | Требует фиксации физического подключения |
| питание | 3.3 V / другое согласно модулю | Требует фиксации |

## 9. Правила ведения pinout

1. **Не использовать GPIO в коде, если его назначение не зафиксировано здесь или в актуальной конфигурации CubeMX.**
2. После изменения распиновки сначала обновлять этот документ, затем код.
3. Не переносить распиновку из примеров для других STM32 автоматически.
4. Если GPIO назначен в CubeMX, но физическое подключение ещё не проверено, статус должен быть `CONFIGURED`, а не `FIXED`.
5. После фактической проверки на железе статус можно изменить на `FIXED`.
6. Освобождённый GPIO необходимо удалить из назначения или явно пометить как `FREE`.
7. Конфликты GPIO между периферийными устройствами должны быть устранены до реализации драйверов.

## 10. Статусы

- **FIXED** — назначение принято и подтверждено.
- **CONFIGURED** — назначение настроено в CubeMX, но физически ещё не подтверждено.
- **RESERVED** — ресурс зарезервирован под устройство.
- **TBD** — назначение ещё не решено.
- **FREE** — GPIO свободен.
