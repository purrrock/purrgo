# P1. Автономность и энергопотребление

Цель автономной работы:

| Режим | Цель |
|---|---:|
| Непрерывная навигация | ≥ 24 ч |
| Типичный режим | ≥ 36 ч |
| Экспедиционный режим | ≥ 48 ч |

Текущее состояние: SYSCLK 80 МГц постоянно (HSI → PLL, Range 2), в простое `__WFI()` (Sleep), но SysTick 1 кГц
будит МК 1000 раз в секунду; Stop-режимы не используются; Standby только при выключении; GNSS и SD остаются
запитанными. Основной потребитель — GNSS, затем обновления E-Ink и MCU в Run.

## 1. Базовые измерения (делать первыми)

- [ ] **[HW]** Измерить ток: MCU в Run на 80 МГц, в Sleep (`WFI` с тиком 1 кГц), без GNSS/SD/дисплея, с каждым по отдельности.
- [ ] **[HW]** Измерить ток дисплея в простое после засыпания панели и во время обновлений (full/partial).
- [ ] **[HW]** Измерить ток GNSS (G10A F30) в разных режимах и время старта.
- [ ] **[HW]** Измерить ток SD в простое и при чтении.
- [ ] **[HW]** Профилировать цикл: доля времени ядра в Run / в ожидании SPI SD (счётчик `DWT->CYCCNT`).
- [ ] **[HW]** Отпаять красный светодиод PWR (D3, ~0,3 мА) и при необходимости синий PC13 после отладки, до замеров автономности.

## 2. Tickless и Stop-режимы (основной рычаг)

- [ ] **[CubeMX]** Timebase Source: SysTick → LPTIM (или TIM на RTC), чтобы HAL-тик не будил МК 1 кГц. После правки проверить `HAL_Delay()`/`HAL_GetTick()` и их использование (в т. ч. `display_eink.c`).
- [ ] Перейти из Sleep (`WFI`) в Stop 2 в простое между GNSS-обновлениями; восстановление тактирования (PLL) после пробуждения.
- [ ] Определить источники пробуждения: UART приёма GNSS, EXTI кнопок, RTC (периодические задачи, таймаут экрана), EXTI по BUSY E-Ink (вместо опроса из цикла).
- [ ] Интегрировать button interrupts (сейчас опрос `BUTTON_POLL_PERIOD_MS`).
- [ ] **[проверить]** Приём GNSS в Stop: по RM0456 USART1 будит только из Stop 0/1, из Stop 2 — LPUART1; LPDMA1 (домен SRD) работает в Stop, GPDMA1 — нет.
  - Вариант A: оставить USART1 + GPDMA1, ограничиться Stop 0/1.
  - Вариант B: GNSS на LPUART1 + LPDMA1 для Stop 2. **[CubeMX]** смена выводов (PA2/PA3 заняты логом UART2, PB10 занят Detect SD; подобрать пины LPUART1 по таблице AF), канал LPDMA1 в кольцевом linked-list режиме, переработка `gnss_io.c`. **[HW]** перепайка GNSS TX/RX.
- [ ] **[решение]** Standby или Shutdown для выключения (Shutdown — минимальный ток, но сбрасывает SRAM и backup).
- [ ] Динамическая частота: 80 МГц только на рендер/обмен с SD, в остальное время HSI16/MSI; при низкой частоте Range 3/4. Решение по D4 (80 / 160 МГц и ниже) — по замерам времени кадра и тока.
