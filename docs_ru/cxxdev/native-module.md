## Уровень моста JsVM

### Экспорт объектов C++

Все представленные примеры представляют собой «функции, возвращающие базовые принципы или обычные объекты JavaScript», существующие управляющие JavaScript через C++ API. **объект C++ в JavaScript**, чтобы сценарий мог продолжить работу с тем же базовым экземпляром.

Есть несколько разных способов реализовать это:
