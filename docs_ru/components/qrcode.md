
#qrcode

Компонент `qrcode` используется для отображения QR-кода [QR Code](https://en.wikipedia.org/wiki/QR_code). Этот компонент может отображать любые текстовые данные и подходит для отображения такой информации, как адреса веб-сайтов, коды оплаты, ссылки на коды сканирования входа и т. д.

В гибком макете компонент qrcode по умолчанию является элементом уровня блока («block») и будет отображаться в отдельной строке.

## Свойства

### `value` <decl type="string" get set />

Установите текстовые данные для отображения в виде QR-кода. Компонент qrcode автоматически выберет подходящую версию в зависимости от длины и длины данных. В настоящее время максимальная поддерживаемая версия составляет 12 долларов США.

## Описание CSS

Чтобы QR-код было легко сканировать, свойства CSS компонента qrcode должны быть установлены правильно, в том числе:
- «цвет»: цвет кодовой точки QR-кода, обычно черный («черный» или «#000»);
- `background-color`: цвет фона QR-кода обычно белый (`white` или `#fff`);
- «отступ» / «поле»: достаточные внутренние и внешние поля позволяют избежать путаницы между QR-кодами и другими элементами и повысить скорость распознавания при сканировании;
- «ширина»/«высота»: размер QR-кода должен быть достаточно большим, чтобы облегчить съемку.

По умолчанию каждая кодовая точка (модуль) компонента QR-кода будет занимать диапазон $4\rm{px}\times 4\rm{px}$, что на часах может быть едва распознаваемым размером. Однако стратегии макетирования, такие как flex, могут уменьшить размер QR-кода, поэтому разработчикам рекомендуется вручную установить свойства «ширина» / «высота» компонента QR-кода по мере необходимости и протестировать их на устройстве.

В следующем примере показано, как использовать компонент QR-кода. Обратите внимание, что для компонента qrcode в CSS установлены различные поля. Это необходимо для того, чтобы между QR-кодом и другими элементами интерфейса было достаточно места, чтобы не мешать сканированию.

<glyphix id="qrcode-1" :height="450" :width="350">

``` HTML
<дел>
  <qrcode :value="текст"/>
  <p>{{ текст }}</p>
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    текст: «https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array»
  }
}
```

``` CSS
дел {
  цвет фона: черный;
  отступ: 8 пикселей;
}

qrкод {
  поле: 16 пикселей;
  отступ: 16 пикселей;
  цвет: черный; /* Устанавливаем черный цвет переднего плана QR-кода */
  цвет фона: белый; /* Устанавливаем белый цвет фона QR-кода */
  радиус границы: 16 пикселей;
}

п {
  цвет: белый;
  размер шрифта: 0,75рем;
}
```

</глификс>

::: совет
Стили цвета кодовой точки («color») и фона («background-color») для **высококонтрастных** компонентов QR-кода всегда следует задавать явно. Чтобы избежать расхождений между темой стиля устройства по умолчанию и унаследованными атрибутами стиля, что приводит к ухудшению распознавания.

В то же время установите достаточно большой отступ («отступ»), чтобы обеспечить легкое сканирование и распознавание.
:::
