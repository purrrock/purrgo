
# выдвижной

Компонент «pullable» используется для добавления функции запуска дополнительной загрузки или обновления взаимодействий во время верхнего и нижнего раскрывающегося списка в списке прокрутки. `pullable` компоненты по умолчанию являются элементами уровня блока.

::: предупреждение
<experimental /> Это экспериментальный компонент, функция pullable не стабильна, а анимация может быть недостаточно естественной.
:::

`pullable` должен быть первым или последним дочерним компонентом [`scroll`](scroll.md). Если это первый дочерний компонент, продолжение протягивания вниз начала содержимого «прокрутки» вызовет событие «вытягивания»; и наоборот, когда `pullable` является последним дочерним компонентом `scroll`, подтягивание внизу вызовет событие `pulling`.

Компонент `pullable` по умолчанию скрыт и будет отображаться только при его перемещении вверх/вниз. Следующий пример демонстрирует использование компонента pullable.

<glyphix id="comComponents-pullable-1" height="360" width="360" title="Потяните вверх/вниз, чтобы загрузить больше">

```html
<полоса прокрутки>
  <pullable :hold="pulldown" on:pulling="onPulldown">
    <progress-arc занят start-angle="0" stop-angle="360" />
    <p>{{раскрытие || 'продолжай тянуть вниз...'}}</p>
  </pullable>
  <p for="item in items">элемент ({{item}})</p>
  <pullable :hold="pullup" on:pulling="onPullup">
    <progress-arc занят start-angle="0" stop-angle="360" />
    <p>{{подтягивание || 'продолжай тянуть...'}}</p>
  </pullable>
</прокрутка>
```

```js
экспортировать по умолчанию {
  данные: {
    раскрывающееся меню: ноль,
    подтягивание: ноль,
    предметы: []
  },
  первый: 0,
  последний: 0,
  onInit() {
    это.обновление(0, 10)
  },
  обновление (первое, последнее) {
    for (пусть я = this.first; i > first; --i)
      this.items.unshift(i)
    for (пусть я = this.last; я <последний; ++i)
      this.items.push(i)
    this.first = первый
    this.last = последний
  },
  onPulldown (событие) {
    this.pulldown = событие? 'пожалуйста, освободите' : 'обновление...'
    если (!событие) {
      setTimeout(() => {
        this.update(this.first - 5, this.last)
        this.pulldown = ноль
      }, 1000)
    }
  },
  onPullup (событие) {
    this.pullup = событие? 'пожалуйста, освободите' : 'обновление...'
    если (!событие) {
      setTimeout(() => {
        это.обновление(это.первое, это.последнее + 5)
        this.pullup = ноль
      }, 1000)
    }
  }
}
```

## Свойства

### `hold` <decl type="bool" get set />

По умолчанию `pullable` виден только при перемещении вниз вверху или вверху внизу, но когда свойство `hold` имеет значение true `, компонент `pullable` останется отображенным. Это свойство обычно устанавливается, когда событие [`pulling`](#pulling) приводит к обновлению содержимого, и отменяется после завершения обновления содержимого.

### `pulling` <decl type="bool" get Listen />

Когда `pullable` полностью вытянут, сработает событие `pulling`, и значение его события будет следующим:
- `true`: это событие срабатывает, когда опускание/подтягивание достигает полного расстояния срабатывания вытягивания `pullable`;
- `false`: это событие срабатывает, когда пользователь отпускает предмет после достижения вышеуказанного условия полного выдвижения.

В следующем примере показано, когда срабатывает значение события pulling. Вы можете попробовать медленно потянуть вниз из верхней части списка и обратить внимание на всплывающее сообщение, когда срабатывает событие «вытягивания».

## Инструкция по применению

### Расположение компонента

Компонент «pullable» должен быть первым или последним дочерним элементом вертикальной «прокрутки». Он автоматически определяет режим действия в зависимости от позиции: обнаруживает, что пользователь перемещается вниз из верхней части списка, когда это первый дочерний элемент, и наоборот.

Для списков, которые необходимо обновить только путем открытия, будет работать следующее использование:
```html
<прокрутка>
  <pullable :hold="refresh" on:pulling="onPulling">
    <p>тянем...</p>
  </pullable>
  <div for="элемент в элементах">
    ...
  </div>
</прокрутка>
```

Код JavaScript может прослушивать событие pulling и управлять атрибутом Refresh:
``` js
экспортировать по умолчанию {
  данные: {
    обновить: ложь
  },
  onPulling (удерживать) {
    if (!hold) { // удержание ложно, когда пользователь отпускает
      this.refresh = true // означает обновление
      // В этом примере таймер используется для имитации операции загрузки и прекращает загрузку через 1 с.
      setTimeout(() => this.refresh = false, 1000)
    }
  }
}
```

Для получения конкретных эффектов обратитесь к примеру документа события [`pulling`](#pulling).

### Оперативное управление контентом

Компонент «pullable» может содержать различные компоненты для отображения содержимого подсказки. Как и в текущем примере в этой статье, вы можете объединить анимацию загрузки с текстом всплывающей подсказки. Кроме того, значение события pulling можно использовать для управления содержимым приглашения. Обычно рекомендуется использовать этот метод обработки состояния:
1. Установите адаптивное свойство (например, «обновить») для каждого извлекаемого компонента. Значение по умолчанию — «ноль». Свойство Refresh также используется для управления свойством [`hold`](#hold) объекта `pullable`.
2. В исходном состоянии (т. е. «обновление» имеет значение «ложь») содержимое подсказки «pullable» должно напоминать пользователю «продолжать извлечение для обновления».
3. Когда пользователь опускает вниз, запускается событие «вытягивания», совершающее 4 или 5 шагов в зависимости от значения события.
4. Если для параметра «pulling» установлено значение «true», пользователю будет предложено «отпустить, чтобы начать обновление».
5. Когда значение «вытягивание» равно «ложь», это означает, что пользователь отпустил. В это время для параметра «refresh» должно быть установлено значение «true» и начать обновление содержимого. И должен напоминать пользователю «обновление».
6. После обновления содержимого снова установите для параметра «refresh» значение «false», чтобы вернуться в исходное состояние.

Вы также можете обратиться к первому примеру в этом документе, который реализует функцию продолжения загрузки, заключающуюся в одновременном вытягивании вниз начала списка и поднятии вверх в хвосте. В этом примере используется трюк для управления всем состоянием «перетягиваемого» объекта с помощью всего одного реактивного свойства.

Этот трюк устанавливает начальное значение реактивного свойства «refresh» равным «null» (аналогично «false») и использует такой шаблонный код:
``` HTML
<pullable :hold="refresh" on:pulling="onPulling">
  <p>{{обновить || "Продолжить опускание"}}</p>
</pullable>
```
Если параметр «обновить» не установлен, содержимое подсказки «продолжить вытягивание» по умолчанию будет отображаться после извлечения «вытаскиваемого». Затем функцию обратного вызова события onPulling следует записать следующим образом:
``` js
экспортировать по умолчанию {
  асинхронный onPulling (событие) {
    this.refresh = событие? «Пожалуйста, отпустите»: «Обновление»
    if (!event) { // Запускаем операцию обновления при отпускании
        ожидайте запускаRefreshJobs()
        this.refresh = null // Сброс состояния после завершения обновления
    }
  }
}
```

### Ограничения

В настоящее время существуют некоторые ограничения на «извлекаемые» компоненты. Помимо необходимости использования в компоненте вертикальной прокрутки, вам также необходимо убедиться, что количество элементов списка превышает размер видимой области прокрутки, в противном случае могут возникнуть проблемы. Кроме того, интерактивный эффект «тяни» может быть тупым.
