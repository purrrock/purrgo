
#изображение-аниматор

Компонент image-animator используется для воспроизведения набора кадровой анимации последовательности изображений. По умолчанию компонент является встроенным элементом.

<glyphix id="image-animator-1" height="190" width="360" >

```html
<div class="flex-column">
  <div class="frame-box">
    <image-animator :images="frames" :play="play" :duration="100" />
  </div>
  <дел>
    <button on:click="play = 'start'">начать</button>
    <button on:click="play = 'pause'">пауза</button>
    <button on:click="play = 'stop'">стоп</button>
  </div>
</div>
```

```js
экспортировать по умолчанию {
  данные: {
    игра: «стой»,
  },
  кадры: Array.from({ length: 60 }, (_, i) => `/assets/planet-${i}.png`),
};
```

## Свойства

### `images` <decl type="string[]" set />

Установите коллекцию изображений кадров последовательности. Каждый элемент images — это путь или URI изображения кадра. Обычно размер каждого кадра одинаковый.

Поддерживает изображения в формате PNG или JPEG.

Если кадр последовательности не меняется, для экономии памяти рекомендуется сделать его нереактивным свойством:

```js
экспортировать по умолчанию {
  // фреймы — это неотзывчивое свойство компонента
  кадры: [
    "/assets/sprite-1.png",
    "/assets/sprite-2.png",
    "/assets/sprite-3.png",
  ],
};
```

Преимущество этого заключается в том, что несколько объектов-компонентов будут использовать один и тот же объект массива Frames (отзывчивые свойства будут скопированы в каждый экземпляр компонента). Только если кадр последовательности действительно требует оперативности, его следует записать в объект данных.

Если кадры последовательности кодируются последовательно, вы можете использовать этот прием, чтобы упростить создание массива кадров последовательности:

```js
экспортировать по умолчанию {
  // последовательность из 4 кадров, пронумерованная начиная с 0
  кадры: Array.from({ length: 4 }, (_, i) => `/assets/sprite-${i}.png`),
  // Альтернативно, последовательность из 4 кадров, пронумерованных начиная с 1
  кадры: Array.from({ length: 4 }, (_, i) => `/assets/sprite-${i + 1}.png`),
};
```

Передайте массив «frames» свойству «images» в шаблоне компонента, чтобы указать кадры последовательности для воспроизведения анимации:

```html
<image-animator :images="frames" play :duration="100" />
```

::: Примечание
Атрибут images в настоящее время не поддерживает структуру ImageFrame быстрых приложений, поэтому вы не можете использовать определение коллекции кадров, например `[{ src: '...' }, ...]`.
:::

### `duration` <decl type="number" get set />

Укажите продолжительность воспроизведения каждого кадра в миллисекундах.

### `play` <decl type="'start' | 'pause' | 'stop'" get set Listen />

Установите статус воспроизведения, поддерживая статус начала, паузы и окончания. `image-animator` изначально находится в состоянии `stop`, поэтому он автоматически остановится в позиции первого кадра [`images`](#images).

| ценность | описание |
| :-------: | ----------------------- |
| `'старт'` | Начать воспроизведение с текущего кадра.     |
| `'пауза'` | Приостановите воспроизведение и отобразите текущий кадр. |
| `'стоп'' | Остановите воспроизведение и отобразите первый кадр. |

Как показано выше, «play» поддерживает только три значения перечисления: «start», «pause» или «stop». Но для автоматического воспроизведения анимации можно использовать следующий трюк:

```html
<image-animator :images="frames" play :duration="100" />
```

То есть напрямую напишите атрибут `play` без значения, что эквивалентно методу записи `:play="true"` [неявный атрибут](/framework/comComponent/template.md#implicit Attribute Value). `true` Этот логический тип всегда преобразуется в значение перечисления `'start'` по умолчанию. Этот метод записи очень подходит для сцен, требующих автоматического воспроизведения анимации последовательности кадров.

### `iteration` <decl type="number" set />

Установите количество повторов воспроизведения для всех кадров последовательности в «изображениях». При достижении верхнего предела он автоматически переключится в режим «паузы». `0` означает неограниченное время игры.
