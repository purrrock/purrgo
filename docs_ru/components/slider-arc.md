
# слайдер-дуга

Селектор скольжения по дуге по умолчанию является элементом уровня блока и не поддерживает изменение стиля.

## Свойства

Наследовать свойства компонента [slider](slider).

### `arc-center` <decl type="{ x: число, y: число }" set />

Установите положение центра дуги.

### `start-angle` <decl type="number" set />

Установите начальный угол дуги, значение по умолчанию: $-90$.

### `progress-angle` <decl type="number" set />

Установите максимальный угол поворота дуги, значение по умолчанию: $360$, один круг дуги.

### `arc-width` <decl type="number" set />

Установите ширину дуги.

### `arc-radius` <decl type="number" set />

Установите радиус дуги.
