
# сборщик

Компонент выбора текста. Этот компонент отображает группу текста. Нажатие на средний текстовый элемент вызовет событие выбора, а операция скольжения может заставить все текстовые элементы прокручиваться и отображаться.

::: предупреждение
Функциональность компонента Picker не проверена и не поддерживается.
:::

## Свойства

### `range` <decl type="string[]" set />

Все строки в значении атрибута range будут отображаться в компоненте Picker. Пользователь может манипулировать компонентом Picker для прокрутки или выбора этих строк.

Информацию о методе индексирования строки в значении атрибута range см. в разделе [атрибут index](#index).

### `loop` <decl type="boolean" set />

Настройте, будет ли компонент выбора отображаться в цикле (т. е. бесконечно долго). Когда значение этого атрибута равно true, отображение цикла включается. Значение по умолчанию — «ложь».

### `value` <decl type="string" Listen />

Следите за текстом текущего выбранного элемента. Этот мониторинг будет запущен, когда выбранный элемент изменится во время операции прокрутки. Функцию этого атрибута также можно реализовать с помощью метода `on:index="handle(rangeData[$event])"`.

### `index` <decl type="Integer" get set Listen />

Значение индекса выбранного элемента компонента Picker. Правило индексирования: [атрибут `range`](#range) Значение индекса первого строкового элемента в массиве значений атрибута равно $0$, а индексы остальных строк увеличиваются на единицу. Установка атрибута index позволяет указать выбранный элемент компонента выбора, а также вы можете прослушивать изменения в этом атрибуте, чтобы обнаружить изменения в выбранном элементе, вызванные операциями прокрутки.

### `scroll` <decl type="{ x: число y: число }" get set Listen />

Операцию прокрутки можно отслеживать с помощью атрибута «scroll», а компонентом «picker» также можно управлять в коде для отображения эффекта прокрутки. Подобно компонентам выровненного списка, операция прокрутки в программе выбора также привязывается к ближайшему элементу.

Поскольку компонент Picker поддерживает только вертикальный режим, поле x значения свойства Scroll всегда равно 0.

### `scrolled` <decl type="boolean" read Listen />

Отслеживайте, находится ли «выборщик» в состоянии прокрутки, с помощью свойства «scrolled». Значение атрибута, вызванное событием, равно «true», что означает, что «Picker» прокручивается, в противном случае это означает, что «Picker» прекратил прокрутку.

Как операции прокрутки, вызванные касанием пользователя, так и прокрутка свойства прокрутки вызовут событие прокрутки. Когда средство выбора выходит из состояния прокрутки, значение параметра события прокрутки равно false.

### `демпфирование` <decl type="number" set />

Установите коэффициент демпфирования анимации прокрутки окна выбора. Допустимый диапазон значений — $[0.1, 50]$ (неподдерживаемые значения будут автоматически изменены до верхнего и нижнего пределов). Значение по умолчанию составляет 1,5 доллара США. Больший коэффициент демпфирования приведет к более быстрой остановке анимации, а значение коэффициента демпфирования по умолчанию может вызвать инерционный эффект на большем расстоянии и большей продолжительности.

Коэффициент демпфирования должен быть установлен постоянным и не изменяться. Изменение коэффициента демпфирования не повлияет на анимацию отскока.
