
# стек

`stack` складывает компоненты макета. В составном макете размер и положение каждого подкомпонента такие же, как у компонента «стек», и они складываются и отображаются по порядку. В следующем примере показаны два перекрывающихся текстовых элемента внутри компонента stack.

<glyphix id="comComponents-stack-layout" height="100" width="200" title="Компоновка стека">

``` HTML
<стек>
  <p class="text1">Текст 1</p>
  <p class="text2">Текст 2</p>
</стек>
```

``` CSS
* {
  выравнивание текста: по центру;
}

.текст1 {
  размер шрифта: 64 пикселей;
  цвет: #fff;
}

.текст2 {
  размер шрифта: 48 пикселей;
  цвет: #f008;
}

стек {
  цвет фона: серый;
}
```

</глификс>

::: совет
Компонент stack всегда использует стратегию многоуровневого макета отображения и не может быть изменен на другие макеты (например, гибкий макет или плавный макет) с помощью свойств CSS, таких как display.
:::

## Поведение макета

Компонент stack имеет фиксированную стратегию компоновки стека. Его размер определяется двумя ограничениями:
1. Размер стека сначала определяется свойствами CSS размера, такими как [`width`](../framework/generic/styles.md#width) или [`height`](../framework/generic/styles.md#width);
2. Компоновка родительского элемента может напрямую определять компоновку стека, например, align-items: простирание, flex: 1 и другие атрибуты в гибкой компоновке;
3. В противном случае размер компонента stack определяется максимальной шириной и максимальной высотой дочерних элементов.

Как только размер стека определен, все его дочерние элементы будут иметь одинаковый размер внешнего блока (то есть размер дочернего элемента плюс границы и поля). Иногда это приводит к неприятностям, например, если в качестве фона используется изображение через `stack`, а размер верхнего элемента слишком велик, изображение может не поместиться.
