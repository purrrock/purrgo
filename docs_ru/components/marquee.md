
#шатер

Компонент marquee используется для отображения прокручиваемого текстового содержимого и поддерживает только однострочное отображение. Компонент Marquee не поддерживает дочерние компоненты, включая Span.

Marquee поддерживает общие свойства CSS, но по причинам реализации свойство text-align в настоящее время может не поддерживаться. Поскольку «marquee» отображает только одну строку текста и будет прокручиваться, если текстовое содержимое слишком длинное, такие свойства, как «max-lines», также не имеют никакого эффекта.

## Свойства

### `text` <decl type="string" get set/>

Установите текстовое содержимое, которое совпадает с атрибутом [`text`](p.md#text) компонента `p`. Когда длина текстового содержимого превышает ширину области выделения, текст автоматически прокручивается.
