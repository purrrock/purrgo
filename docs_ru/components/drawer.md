
#ящик

Компонент ящика по умолчанию скрыт и может отображать содержимое путем скольжения.
ящик является основным компонентом ящика. Drawer поддерживает подкомпоненты и макеты. Вы можете настроить в ящике 4 компонента навигации по ящикам, чтобы отображать ящики в четырех положениях: сверху, снизу, слева и справа.

[`drawer`](drawer) Скорость скольжения компонента соответствует скорости скольжения жеста. Чем выше скорость скольжения жеста, тем выше скорость скольжения компонента.

### Пример

Следующий пример демонстрирует функциональность ящика.

<glyphix id="comComponents-drawer" height="360" width="360" >

``` HTML
 <drawer class="раскрывающийся список">
      <drawer-navigation Direction="down" class="drop-down1">
        <p>Панель рассвета</p>
      </drawer-навигация>
      <drawer-navigation Direction="up" class="drop-down1">
        <p>верхняя панель</p>
      </drawer-навигация>
       <drawer-navigation Direction="left" class="drop-down1">
        <p>левая панель</p>
      </drawer-навигация>
       <drawer-navigation Direction="right" class="drop-down1">
        <p>правая панель</p>
      </drawer-навигация>
</ящик>
```
``` CSS
.выпадающий список {
    цвет фона: розовый;
  }
.drop-down1 {
    цвет фона: синий;
  }
п {
  цвет фона: светло-зеленый;
  выравнивание текста: по центру;
  поле: 10 пикселей;
}
```
