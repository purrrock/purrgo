
# кнопка

Компонент кнопки по умолчанию является встроенным элементом. При прикосновении к компоненту может быть вызвано соответствующее событие.

## Свойства

### `checkable` <decl type="boolean" set />

Если установлено значение «истина», это означает, что одно касание реагирует только на одно изменение состояния, а именно: из нажатого в поднятое состояние или из поднятого в нажатое состояние. И контрольное значение нажатого состояния «press» — «истина», а поднятого состояния — «ложь».

### `toggleable` <decl type="boolean" set />

Если установлено значение true, это означает, что значение мониторинга нажатия можно изменить. При нажатии — «истина», а при поднятии — «ложь».

### `press` <decl type="boolean" get set Listen />

Установив свойство `press`, вы можете изменить состояние компонента. Вы также можете отслеживать состояние компонента с помощью команды `on`. По умолчанию выполняется одно касание. Параметр обратного вызова имеет значение true. Вы можете использовать атрибуты «checkable» и «toggleable» для получения различных значений и состояний мониторинга.

## Функциональные ограничения

### Событие `click` недопустимо

Когда компонент «кнопка» не используется, событие щелчка любого собственного компонента обычно отслеживается через атрибут [`click`](/framework/generic/properties.md#click). Но этот подход обычно не работает с «кнопкой». Например, этот код:
```html
<button on:click="onOuterClick">
  <p on:click="onInnerClick">внутренний</p>
  внешняя кнопка
</кнопка>
```

```js
экспортировать по умолчанию {
  onOuterClick() {
    console.log('внешний щелчок');
  },
  onInnerClick (событие) {
    // Предотвращаем всплывание событий, чтобы внешняя кнопка не реагировала на события нажатия
    событие.stopPropagation();
    console.log('внутренний щелчок');
  }
}
```

Вы можете ожидать, что нажатие на «внутренний» текст вызовет метод onInnerClick и предотвратит onOuterClick. Но вы обнаружите, что это не так (лучше всего открыть консоль браузера для просмотра журнала): метод onInnerClick вообще не сработает, а на нажатие отреагирует только внешний компонент button, то есть:
- При нажатии на «внутренний» текст журнал «внутреннего клика» не отображается, а только журнал «внешнего клика»;
- взаимодействие с `кнопкой` срабатывает при нажатии (прозрачность уменьшена).

Это похоже на щелчок по внешнему «внешнему тексту». Причина этого в том, что компонент «кнопка» первым реагирует на весь жизненный цикл нажатого жеста (от нажатия до отпускания), а событие «щелчок» запускается при отпускании руки. Это означает, что независимо от того, предотвращает ли обработчик события «click» внутреннего элемента всплывание, это поведение не изменится.

#### Решение

Чтобы решить эту проблему, вам следует прослушать событие «press» внешней «кнопки» и событие «touchstart» внутреннего элемента:

```html
<button on:press="onOuterClick">
  <p on:touchstart="onInnerClick">внутренний</p>
  внешняя кнопка
</кнопка>
```

```js
экспортировать по умолчанию {
  onOuterClick() {
    console.log('внешний щелчок');
  },
  onInnerClick (событие) {
    // Предотвращаем всплывание событий, чтобы внешняя кнопка не реагировала на события нажатия
    событие.stopPropagation();
    console.log('внутренний щелчок');
  }
}
```

::: совет
Событие «нажатие» также обычно запускается при отпускании кнопки, но для этого требуется, чтобы событие нажатия кнопки никогда не блокировалось. Таким образом, предотвращение всплытия события `touchstart` внутреннего элемента может предотвратить срабатывание события `press` внешней кнопки.
:::

#### Другое время срабатывания

Ограничением этого метода является то, что при нажатии запускается событие touchstart внутреннего элемента. Вы также можете использовать событие touchend для его запуска, но функция предотвращения всплытия события touchstart должна быть сохранена. Это гарантирует, что событие нажатия внешней кнопки не будет вызвано при нажатии.

```html
<button on:press="onOuterClick">
  <p on:touchstart="$event.stopPropagation()" on:touchend="onInnerClick">внутренний</p>
  внешняя кнопка
</кнопка>
```

```js
экспортировать по умолчанию {
  onOuterClick() {
    console.log('внешний щелчок');
  },
  onInnerClick (событие) {
    // Здесь нет необходимости предотвращать всплывание, поскольку оно заблокировано в Touchstart
    console.log('внутренний щелчок');
  }
}
```
