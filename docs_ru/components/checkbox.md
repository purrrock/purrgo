
#checkbox

Элемент «флажок» при активации отображает отмеченный (помеченный) флажок, указывающий, что элемент выбран.

<glyphix id="checkbox-1" :height="65" title="Один флажок">

``` HTML
<дел>
  <checkbox id="checkbox" ::checked="проверено" />
  <label target="checkbox">Проверьте меня!</label>
  <p>проверено: {{ отмечено }}</p>
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    проверено: правда
  }
}
```
</глификс>

::: Примечание
«Флажок» обычно представляет собой квадрат, который можно отметить, но точный эффект определяется устройством. В настоящее время разработчики не могут изменять цвет и другие стили флажков с помощью CSS.
:::

## Характеристики

### `checked` <decl type="boolean" get set Listen />

Это свойство указывает, установлен ли этот флажок. Установка атрибута «checked» может переключить отмеченное состояние флажка: если значение равно «true», он отображается в отмеченном состоянии. Вы также можете работать с отдельными флажками посредством двусторонней привязки:
``` HTML
<модель флажка:checked="да" />
```

Пример, приведенный ранее в этой статье, демонстрирует использование этой привязки. Обратите внимание, что привязку следует выполнять не к атрибуту [`value`](#value), а к атрибуту `checked`.

Событие запускается только тогда, когда пользователь нажимает на флажок, вызывая изменение свойства «checked».

::: предупреждение
Не устанавливайте атрибут «checked» в [группе флажков](#group), чтобы избежать путаницы.
:::

### `value` <decl type="any" get set />

Значение JavaScript, определяющее значение флажка. Обычно это строка или число. Это значение не отображается, но его можно использовать в [Групповые операции] (#group).

### `group` <decl type="any[]" get set Listen />

Если у вас есть несколько связанных компонентов «флажок», вы можете объединить свойства «группа» и «значение»; флажки внутри одной группы образуют массив выбранных значений. Пожалуйста, обратитесь к следующему примеру:

<glyphix id="checkbox-group" :height="65" title="группа флажков" >

``` HTML
<дел>
  <p>выбранные цвета: {{selected.join(', ')}}</p>
  <дел>
    <checkbox id="red" value="red" model:group="selected" />
    <label target="red">красный</label>
    <checkbox id="blue" value="blue" model:group="selected" />
    <label target="blue">синий</label>
    <checkbox id="yellow" value="yellow" model:group="selected" />
    <label target="yellow">желтый</label>
  </div>
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    выбрано: ['желтый']
  }
}
```

``` CSS
метка {
  поле справа: 0,5рем;
}
```

</глификс>

Этого можно добиться, используя `model:group` или `::group` для двунаправленной привязки атрибута `group` к отзывчивому массиву (в примере `selected`):
- Когда пользователь устанавливает флажок в группе, значение адаптивного массива будет обновляться;
— Изменения в элементах адаптивного массива будут отражаться на работе «флажка».

Как показано в примере выше: В исходном состоянии флажок группировки установлен на основе значения атрибута group. В частности, для флажка типа:
``` HTML
<checkbox value="red" model:group="selected" />
```
Поскольку атрибут `value` задает значение ``red'`, когда значение реактивного атрибута `selected` содержит ``red'` (например, `["red"]`), флажок будет установлен. Повторный щелчок по флажку приведет к тому, что он станет снятым, а «красный» элемент будет удален из массива `selected`.

::: совет
Если вы не хотите группировать флажки, вы также можете использовать атрибут [`checked`](#checked) для индивидуальной работы. Но не используйте «checked» и «group» одновременно, Glyphix не учитывает эту ситуацию.
:::

### `indeterminate` <decl type="boolean" get set />

Атрибут `indeterminate` указывает, что флажок находится в **неопределенном** состоянии. Если это свойство имеет значение true, флажок имеет горизонтальную линию, похожую на знак минус, посередине, что указывает на неопределенность его состояния.

Неопределенное состояние можно использовать, когда элемент имеет несколько вариантов: если выбраны все дочерние элементы, родительский элемент также будет выбран; если все они не выбраны, родительский элемент также не будет выбран. Если выбраны некоторые из дочерних элементов, родительский элемент будет находиться в неопределенном состоянии.

Следующий пример демонстрирует это использование. В этом примере показано создание списка таблиц зачарования, так что при выборе частичного рецепта флажок «Таблица зачарования» будет частично установлен. Как видите, этот пример позволяет вам использовать родительский флажок, чтобы установить или снять отметки со всех его дочерних элементов.

<glyphix id="checkbox-indeterminate" :height="140" title="Флажок с тремя состояниями" >

``` HTML
<дел>
  <дел>
    <!--
      Если selected.length == 3, объект будет выбран, в противном случае:
      - Если selected.length == 0, то он не выбран;
      - Другие случаи означают, что часть рецепта выбрана и, следовательно, находится в неопределенном состоянии.
      -->
    <checkbox id="весь"
              :indeterminate="выбранная.длина && выбранная.длина < 3"
              :checked="selected.length == 3"
              on:checked="selectEntirety" />
    <label target="полнота">
      &nbsp;Таблица зачарования:
    </метка>
  </div>
  <div class="группа">
    <div for="x по частям">
      •
      <checkbox :id="x" :value="x" model:group="selected" />
      <label :target="x">&nbsp;{{x}}</label>
    </div>
  </div>
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    выбрано: ['Бриллианты'],
  },
  части: ['Книга', 'Бриллианты', 'Обсидиан'],
  //Вызовите эту функцию при установке флажка целиком, чтобы установить выбранное состояние всех рецептов
  selectEntirety (статус) {
    // Используйте [...this.parts] для копирования списка во избежание внесения изменений на месте
    this.selected = статус? [...эти.части] : []
  },
}
```

``` CSS
.группа {
  поле слева: 0,4рем;
}
```

</глификс>

::: совет
Когда атрибут «checked» установлен (обратите внимание, что он не очищен), атрибут «indeterminate» автоматически очищается. Даже если флажок имеет оба свойства, он будет выглядеть выбранным, а не в неопределенном состоянии.
:::

### Поведение CSS

По умолчанию флажок является встроенным элементом, его отображаемый размер определяется CSS-свойством «font-size» и выравнивается по базовой линии отображения текста. Пожалуйста, не указывайте вручную такие атрибуты, как «ширина» и «высота», иначе это может привести к путанице при отображении.
