
# текстовое поле

Компонент, используемый для ввода одной строки текстового содержимого, которая по умолчанию является встроенным элементом. В отличие от аналогичных элементов графического интерфейса на мобильных телефонах или ПК, «текстовое поле» в настоящее время не реагирует на устройства ввода, такие как клавиатуры, и не отображает интерфейс метода ввода, поэтому вам придется вручную редактировать его содержимое. `text-field` поддерживает манипулирование курсором с помощью сенсорных жестов (например, щелчка и прокрутки).

`text-field` подходит в качестве низкоуровневого компонента для однострочного ввода текста, и вы можете реализовать свою собственную программную клавиатуру (например, сетку паролей или даже голосовой ввод) в соответствии с вашими потребностями. Подробную информацию см. в [Пример](#Базовый пример).

## Свойства

### `value` <decl type="string" set get Listen />

Атрибут value представляет собой строку, которая является текущим редактируемым содержимым текстового поля. Чтение или прослушивание этого значения позволяет получить входной текст, а также вы можете установить это свойство.

Обычно `value` двунаправленно привязывают к определенному реактивному свойству, например:

```html
<текстовое поле ::value="inputText" />
```

### `placeholder` <decl type="string" set get />

Когда содержимое `text-field` пусто, вы можете использовать `placeholder`, чтобы предоставить пользователю короткое приглашение, например, такую фразу, как «Пожалуйста, введите текст».

`placeholder` автоматически отображается, когда вводимый текст пуст, поэтому обычно требуется только фиксированное содержимое, например:

```html
<text-field ::value="inputText" Placeholder="введите здесь" />
```

### `password` <decl type="boolean" set get />

Когда этот атрибут установлен, текстовая область будет использовать «режим шифрования», то есть каждый символ будет заменен на «•» ([Bullet, U+2022](http://www.fileformat.info/info/unicode/char/2022/index.htm)). Вы можете в любой момент отключить или включить атрибут `password`, чтобы переключаться между отображением и скрытием состояния пароля.

В новой версии <version-badge с="0.9" /> режим пароля будет задерживать маскирование введенных символов, поэтому пользователь может видеть только что введенные символы в течение короткого времени, прежде чем они будут заменены на "•". Старые версии сразу маскируют введенные символы.

### `insert` <decl type="(text: string): void" метод />

Вставьте фрагмент текста с содержимым «текст» в курсор, и курсор автоматически переместится вслед за вставленным текстом. Вызов этой функции вызовет событие прослушивания `value`.

### `backspace` <decl type="(): void" метод />

Удалите символ на курсоре, и курсор автоматически переместится вперед. Вызов этой функции вызовет событие прослушивания `value`.

## Инструкция по применению

### Базовый пример

В следующем примере показано базовое использование текстового поля. Вы можете нажимать на кнопки клавиатуры для ввода цифр. Нажмите кнопку «×», чтобы удалить содержимое курсора, и нажмите «A/*», чтобы переключиться между режимом пароля и обычным режимом ввода текста. В режиме пароля входное содержимое будет скрыто с помощью `•`.

<glyphix id="comComponents-text-field-1" width="410" height="160">

```html
<div class="flex-column">
  <div class="flex-row align-baseline">
    <текстовое поле id="текстовое поле"
                ::value="входнойтекст"
                :пароль="пароль"
                Placeholder="Введите здесь" />
    <кнопка проверяется ::press="пароль">A/*</button>
    <button on:click="textField.backspace()">×</button>
  </div>
  <!-- Простая матричная цифровая клавиатура -->
  <div class="flex-row" for="строки на клавиатуре">
    <button class="flex-1" for="ключ в строках"
            on:click="textField.insert(key)">
      {{ключ}}
    </кнопка>
  </div>
</div>
```

```js
экспортировать по умолчанию {
  данные: {
    вводТекст: "",
    пароль: ложный,
  },
  клавиатура: [
    ['1', '2', '3', '4', '5'],
    ['6', '7', '8', '9', '0'],
  ],
  текстовое поле: ноль,
  onReady() {
    // Получение объекта компонента TextField для облегчения вызова методов Insert() и Backspace().
    this.textField = this.$element("текстовое поле")
  },
}
```

``` CSS
.flex-столбец {
  дисплей: гибкий;
  гибкое направление: столбец;
}

.flex-строка {
  дисплей: гибкий;
}

.align-baseline {
  выровнять-элементы: базовая линия;
}

текстовое поле {
  гибкий: 1;
  выравнивание текста: по центру;
  нижняя граница: 2 пикселя, сплошная #666;
}

кнопка {
  радиус границы: 8 пикселей;
  цвет фона: #dee2e6;
  поле: 8 пикселей;
  отступ: авто 12 пикселей;
}

кнопка: активная {
  непрозрачность: 0,5;
}

.flex-1 {
  гибкий: 1;
}
```
</глификс>

В этом примере текст text-field отображается в центре, что достигается с помощью text-align:
``` CSS
текстовое поле {
  выравнивание текста: по центру;
}
```

Сначала мы получаем объект компонента `text-field` с помощью метода `$element` в функции жизненного цикла `onReady()` компонента, поскольку затем нам нужно отредактировать содержимое с помощью методов [`insert()`](#insert) и [`backspace`](#backspace).

Исходя из этого, мы можем напрямую вызвать метод text-field в прослушивателе событий click компонента button, например:
```html
<button on:click="textField.backspace()">×</button>
```

Поскольку физической клавиатуры нет, разработчикам обычно необходимо предоставить собственную реализацию клавиатуры. В учебных целях в этом примере реализована только цифровая клавиатура с 2 строками и 5 столбцами. И вставьте значение ключа в «текстовое поле» в функции прослушивания событий «click» для каждой клавиши:
```html
<div class="flex-row" for="строки на клавиатуре">
  <button class="flex-1" for="ключ в строках"
          on:click="textField.insert(key)">
    {{ключ}}
  </кнопка>
</div>
```

Этот пример также демонстрирует стандартный метод переключения режимов пароля.

### Проверка и форматирование контента

Вы можете проверять и форматировать входной контент, двунаправленно привязывая атрибут [`value`](#value) `text-field` к вычисляемому свойству. Пример ниже демонстрирует этот подход, который позволяет вводить только до 9 цифр (без букв и т. д.) и добавляет разделители «`,`» между каждыми тремя цифрами.

<glyphix id="comComponents-text-field-validator" title="Проверщик контента" width="410" height="200">

```html
<div class="flex-column">
  <div class="flex-row align-baseline">
    <текстовое поле id="текстовое поле"
                ::value="входнойтекст"
                :пароль="пароль"
                Placeholder="Введите здесь" />
    <кнопка проверяется ::press="пароль">A/*</button>
    <button on:click="textField.backspace()">×</button>
  </div>
  <div class="flex-row" for="строки на клавиатуре">
    <button class="flex-1" for="ключ в строках"
            on:click="textField.insert(key)">
      {{ключ}}
    </кнопка>
  </div>
</div>
```

```js
экспортировать по умолчанию {
  данные: {
    пароль: ложный,
    rawText: "",
  },
  вычислено: {
    входной текст: {
      get() { return this.rawText },
      набор (текст) {
        if (text.length < 12 && /^[\d,]*$/.test(text)) {
          this.rawText = text.replace(/[^\d]/g, '')
                             .replace(/\B(?=(\d{3})+(?!\d))/g, ",")
        }
      },
    },
  },
  клавиатура: [
    ["1", "2", "3", "4", "5"],
    ["6", "7", "8", "9", "0"],
    ["А", "Б", "В", "Г", "Е"],
  ],
  текстовое поле: ноль,
  onReady() {
    this.textField = this.$element("текстовое поле")
  },
}
```

``` CSS
.flex-столбец {
  дисплей: гибкий;
  гибкое направление: столбец;
}

.flex-строка {
  дисплей: гибкий;
}

.align-baseline {
  выровнять-элементы: базовая линия;
}

текстовое поле {
  гибкий: 1;
  нижняя граница: 2 пикселя, сплошная #666;
}

кнопка {
  радиус границы: 8 пикселей;
  цвет фона: #dee2e6;
  поле: 8 пикселей;
  отступ: авто 12 пикселей;
}

кнопка: активная {
  непрозрачность: 0,5;
}

.flex-1 {

}
```

Проверка и форматирование контента реализуются посредством двусторонней привязки и вычисляемых свойств. Для узла компонента `text-field`
```html
<текстовое поле id="текстовое поле"
            ::value="входнойтекст"
            :пароль="пароль"
            Placeholder="Введите здесь" />
```
Например, свойство value двунаправленно привязано к inputText, который на самом деле является вычисляемым свойством. Его метод `set()` проверяет, соответствует ли входной контент спецификации (до 11 символов, допускаются только цифры и запятые), затем фильтрует числа с помощью регулярного выражения и форматирует их с запятыми между каждыми тремя цифрами:
```js
набор функций (текст) {
  if (text.length < 12 && /^[\d,]*$/.test(text)) {
    this.rawText = text.replace(/[^\d]/g, '')
                       .replace(/\B(?=(\d{3})+(?!\d))/g, ",")
  }
}
```
Если входное содержимое не соответствует требованиям, метод set() проигнорирует входное значение, а механизм двусторонней привязки сделает содержимое text-field и значение атрибута inputText (полученное с помощью метода get()) согласованным. Поэтому вы обнаружите, что не можете вводить буквенные клавиши.
