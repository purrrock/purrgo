
#штрихкод

Компонент barcode используется для отображения штрих-кодов [Code 128](https://en.wikipedia.org/wiki/Code_128). Компонент «штрих-код» может отображать любую строку ASCII и подходит для отображения штрих-кодов продуктов, кодов оплаты и другой информации.

В гибком макете компонент «штрих-код» по умолчанию является элементом уровня блока («блок») и будет отображаться в отдельной строке.

## Свойства

### `value` <decl type="string" get set />

Установите содержимое, которое будет отображаться в штрих-коде. Поддерживаются произвольные строки ASCII.

## Описание CSS

Чтобы штрих-коды можно было легко сканировать, свойства CSS компонента barcode должны быть установлены правильно, в том числе:
- `color`: цвет штрих-кода, обычно черный (`black` или `#000`);
- `background-color`: цвет фона штрих-кода обычно белый (`white` или `#fff`);
- `padding` / `margin`: достаточные внутренние и внешние поля позволяют избежать путаницы между штрих-кодами и другими элементами и повысить скорость распознавания при сканировании;
- «ширина»/«высота»: размер штрих-кода должен быть достаточно большим, чтобы облегчить съемку.

По умолчанию каждый штрих-код компонента штрих-кода будет занимать ширину $2\rm px$ и высоту $32\rm px$, что может быть слишком маленьким на устройствах с маленьким экраном, таких как часы. Разработчикам рекомендуется вручную установить свойства ширины/высоты компонента штрих-кода по мере необходимости и протестировать их на устройстве.

В следующем примере показано, как использовать компонент штрих-кода. Обратите внимание, что для компонента barcode в CSS установлены различные поля. Это необходимо для того, чтобы между штрих-кодом и другими элементами интерфейса было достаточно места, чтобы не мешать сканированию.

<glyphix id="barcode-1" :height="150" :width="350">

``` HTML
<дел>
  <штрих-код :value="текст"/>
  <p>{{ текст }}</p>
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    текст: '9787111407010'
  }
}
```

``` CSS
дел {
  цвет фона: черный;
  отступ: 8 пикселей;
}

штрих-код {
  поле: 8 пикселей;
  отступ: 8 пикселей;
  цвет: черный; /* Устанавливаем черный цвет переднего плана штрих-кода */
  цвет фона: белый; /* Устанавливаем белый цвет фона штрих-кода */
  радиус границы: 16 пикселей;
  высота: 80 пикселей;
}

п {
  цвет: белый;
  размер шрифта: 0,75рем;
  выравнивание текста: по центру;
}
```

</глификс>

::: совет
Стили цвета кодовой точки (`color`) и фона (`background-color`) для **высококонтрастных** компонентов штрих-кода всегда должны задаваться явно. Чтобы избежать расхождений между темой стиля устройства по умолчанию и унаследованными атрибутами стиля, что приводит к ухудшению распознавания.

В то же время установите достаточно большой отступ («отступ»), чтобы обеспечить легкое сканирование и распознавание.
:::
