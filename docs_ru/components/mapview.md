
#mapview

Компонент карты, используемый для загрузки и отображения тайловых карт. Mapview поддерживает панорамирование жестами, переключение уровня масштабирования, отображение текущего местоположения и рисование навигации по маршруту, а также является основным компонентом для создания картографических приложений.

`mapview` по умолчанию использует элементы уровня блока.

::: совет
Mapview — это компонент расширения времени выполнения. Прежде чем использовать его, вам необходимо убедиться, что целевая платформа интегрировала модуль Mapview.
:::

## Свойства

### `baseUri` <decl type="string" get set />

URI **базового пути** ресурса изображения плитки. Файлы тайлов будут храниться в фиксированной иерархической структуре в этом каталоге. Mapview автоматически рассчитает необходимый путь к файлу тайла на основе текущего уровня масштабирования и координат. Формат:

```
{baseUri}/{zoomLevel}/{tileX}/{tileY}/normal.png (стандартная карта)
{baseUri}/{zoomLevel}/{tileX}/{tileY}/satellite.png (спутниковая карта)
```

Типичное использование — кэширование фрагментов карты в локальном хранилище устройства, а затем указание baseUri на соответствующий каталог:

```html
<mapview baseUri="internal://files/tiles/map_provider" />
```

### `tileType` <decl type="number" get set />

Тип слоя тайловой карты, значения следующие:

| ценность | описание |
| :-: | :-- |
| `0` | Стандартная карта (по умолчанию), загрузите файл фрагментов `normal.png` |
| `1` | Спутниковая карта, загрузка файла фрагментов `satellite.png` |

### `loadPlace` <decl type="string" get set />

URI **заполнителя**, отображаемый при загрузке изображения плитки. Если соответствующий файл плитки не кэширован локально, Mapview будет отображать изображение в месте расположения плитки до тех пор, пока после загрузки плитки не будет запущено обновление [`reload()`](#reload).

```html
<mapview loadPlace="/assets/imgs/loading.png" />
```

### `zoomLevel` <decl type="number" get set />

Уровень масштабирования карты, диапазон значений — $[3, 23]$, значение по умолчанию — $17$. Чем выше уровень, тем детальнее карта; чем ниже уровень, тем шире видимый диапазон.

:::информация
Этот атрибут соответствует уровню масштабирования в стандарте плиток карты, который соответствует определению уровня основных служб плиток, таких как Bing Maps и Google Maps.
:::

### `arrowIcon` <decl type="string" get set />

URI изображения для значка текущего местоположения. Значок будет нарисован в месте экрана, соответствующем широте и долготе, заданным параметром [`navCoordinate`](#navcoordinate) или [`setLocation()`](#setlocation). Значок будет выровнен по координатной точке с центральной точкой.

```html
<mapviewarrowIcon="/assets/imgs/location.png" />
```

### `navCoordinate` <decl type="{ x: число, y: число }" get set />

Координаты широты и долготы текущего местоположения в формате `{ x: широта, y: долгота }`, где `x` — это широта, а `y` — долгота. Установка этого свойства только обновляет положение значка, но не перемещает автоматически центр карты к этим координатам. Если вам нужно одновременно расположить центр карты в текущем местоположении, используйте метод [`setLocation()`](#setlocation) и передайте `force: true`.

::: совет
В сценариях, где необходимо отслеживать местоположение в реальном времени, рекомендуется использовать метод [`setLocation()`](#setlocation) вместо прямого назначения этого свойства, чтобы контролировать, следует ли автоматически возвращаться в центр через параметр `force`.
:::

### `arrowLineWidth` <decl type="number" get set />

Толщина линии маршрута навигации в пикселях. Значение по умолчанию — «12».

### `arrowLineBackgroundColor` <decl type="color" get set />

**Цвет фона** навигационного маршрута (цвет пройденной части) принимает значения цвета CSS, а значение по умолчанию — `#898b90`.

### `arrowLineForgeColor` <decl type="color" get set />

Цвет переднего плана навигационного маршрута (цвет оставшейся части маршрута) принимает значения цвета CSS и по умолчанию имеет значение `#4b73ec`.

### `smallMem` <decl type="boolean" get set />

Включить ли режим устройства с низким объемом памяти, значение по умолчанию — «false».

При включении Mapview объединяет и масштабирует четыре фрагмента размером 256×256 в изображение размером 512×512 для рисования, одновременно уменьшая количество фрагментов, кэшируемых в памяти, для адаптации к устройствам с ограниченной памятью.

::: предупреждение
Режим нехватки памяти снижает четкость карты, поэтому его следует включать только в том случае, если на устройстве явно недостаточно памяти.
:::

### `missTiles` <decl type="Array<{ z: число, x: число, y: число }>" get Listen />

Атрибут только для чтения, запускает мониторинг, когда карта обнаруживает локальный отсутствующий файл тайлов. Параметр обратного вызова представляет собой массив, каждый элемент которого описывает недостающий тайл:

| Поле | Тип | Описание |
| :-- | :-- | :-- |
| `з` | `число` | Уровень масштабирования |
| `х` | `число` | Координата X плитки (номер столбца) |
| `у` | `число` | Координата Y плитки (номер строки) |

После получения этого события приложению обычно необходимо загрузить соответствующий файл тайла с сервера и вызвать [`reload()`](#reload), чтобы обновить карту после завершения загрузки:

```js
экспортировать по умолчанию {
  MissTileHandler (плитки) {
    // плитки: [{ z: 17, x: 105234, y: 49832 }, ...]
    downloadTiles(tiles).then(() => {
      this.$element('mapview').reload()
    })
  }
}
```

```html
<mapview id="mapview" on:missTiles="missTileHandler" />
```

### `directionInfo` <decl type="{ event: string, StepIndex?: Number, Distance?: Number }" get Listen />

Свойство события карты, доступное только для чтения, прослушиватель срабатывает, когда на карте происходят следующие операции:

| значение `event` | время срабатывания | дополнительные поля |
| :-- | :-- | :-- |
| `"двигаться"` | Срабатывает, когда пользователь жестом перемещает карту | Нет |
| `"расчет"` | Срабатывает, когда положение и расстояние поворота пересчитываются в навигации | `stepIndex` (индекс текущего участка маршрута), `distance` (расстояние отклонения от текущего положения до маршрута, в метрах) |

```js
экспортировать по умолчанию {
  onDirectionInfo (информация) {
    if (info.event === 'переместить') {
      // Пользователь вручную перетаскивает карту и может приостановить автоматический возврат в центр.
    } else if (info.event === 'calc') {
      console.log(`Текущий шаг: ${info.stepIndex}, расстояние поворота: ${info.distance} метров`)
    }
  }
}
```

## Метод

### `перезагрузить()`

Перезагрузите все плитки. После того, как новый файл тайла будет записан в локальное хранилище, необходимо вызвать этот метод, чтобы обновить отображение карты.

```js
this.$element('mapview').reload()
```

### `найти()`

Перемещает центр карты в текущую позицию (координаты, указанные в [`navCoordinate`](#navcoordinate)), используемую для функции «возврата в текущую позицию».

```js
this.$element('mapview').locate()
```

### `setLocation(местоположение)`

Устанавливает координаты текущего местоположения и при необходимости перемещает центр карты в это место.

| Поля параметров | Тип | Описание |
| :-- | :-- | :-- |
| `широта` | `число` | широта |
| `долгота` | `число` | долгота |
| `сила` | `логическое` | Если установлено значение true, немедленно расположите центр карты по этой координате (эквивалентно вызову [`locate()`](#locate)), если значение false, обновите только положение значка |

```js
//Обновляем только положение значка, не перемещаем карту
this.$element('mapview').setLocation({
  широта: 39,9042,
  долгота: 116,4074,
  сила: ложь,
})

// Обновляем положение значка и перемещаем центр карты в эту координату
this.$element('mapview').setLocation({
  широта: 39,9042,
  долгота: 116,4074,
  сила: правда,
})
```

### `startNav(linePoints)`

Установите маршрут навигации и начните навигацию. После вызова карта автоматически определит начальную точку маршрута и прорисует полный маршрут.

`linePoints` — это массив точек маршрута, каждый элемент представляет собой двоичный массив в формате `[долгота, широта]`:

```js
константный маршрут = [
  [116.397428, 39.909736], // [долгота, широта]
  [116.404730, 39.913370],
  [116.410072, 39.918933],
]
this.$element('mapview').startNav(маршрут)
```

::: предупреждение
Обратите внимание на порядок параметров: первое значение каждой точки координат — это долгота, а второе значение — широта, в отличие от общепринятого соглашения «сначала широта».
:::

### `insetNavPoint(linePoints)`

Добавляет точки маршрута к существующему маршруту навигации в том же формате, что и [`startNav()`](#startnav). Подходит для сценариев, в которых данные маршрута принимаются сегментами. После добавления вам нужно вызвать [`reload()`](#reload), чтобы обновить отображение.

```js
this.$element('mapview').insetNavPoint(newPoints)
this.$element('mapview').reload()
```

## Пример использования

### Базовое отображение карты

В следующем примере показано, как настроить базовый компонент карты для прослушивания событий отсутствия фрагментов и запуска загрузки.

```html
<шаблон>
  <просмотр карты
    идентификатор="карта"
    :zoomLevel="масштаб"
    :baseUri="tileBaseUri"
    :tileType="Тип плитки"
    loadPlace="/assets/imgs/tile-loading.png"
    arrowIcon="/assets/imgs/location.png"
    on:missTiles="onMissTiles"
    on:directionInfo="onDirectionInfo"
  />
</шаблон>
```

```js
экспортировать по умолчанию {
  данные: {
    масштаб: 17,
    тип плитки: 0,
    tileBaseUri: 'internal://files/tiles/my_provider',
  },

  onReady() {
    //Инициализируем текущую позицию
    this.$element('map').setLocation({
      широта: 39,9042,
      долгота: 116,4074,
      сила: правда,
    })
  },

onMissTiles (плитки) {
    // плитки: отсутствует список плиток, инициируем запрос на загрузку на сервер
    fetchTilesFromServer(tiles).then(() => {
      this.$element('map').reload()
    })
  },

  onDirectionInfo (информация) {
    if (info.event === 'переместить') {
      //Пользователь панорамировал карту
    }
  },
}
```

``` CSS
просмотр карты {
  ширина: 100%;
  высота: 100%;
}
```

### Прорисовка навигационного маршрута

```html
<шаблон>
  <стек>
    <просмотр карты
      идентификатор="карта"
      :baseUri="tileBaseUri"
      :zoomLevel="масштаб"
      arrowIcon="/assets/imgs/location.png"
      стрелкаЛинеВидс="10"
      стрелкаLineBackgroundColor="#888888"
      стрелкаLineForgeColor="#1a73e8"
      on:missTiles="onMissTiles"
    />
    <button @click="startNavigation">Начать навигацию</button>
  </стек>
</шаблон>
```

```js
экспортировать по умолчанию {
  данные: {
    масштаб: 16,
    tileBaseUri: 'internal://files/tiles/my_provider',
  },

  стартНавигация() {
    константный маршрут = [
      [116.397428, 39.909736],
      [116.404730, 39.913370],
      [116.410072, 39.918933],
    ]
    this.$element('карта').startNav(маршрут)
  },

  onMissTiles (плитки) {
    fetchTilesFromServer(tiles).then(() => {
      this.$element('map').reload()
    })
  },
}
```

### Адаптация устройства с малым объемом памяти

```html
<просмотр карты
  идентификатор="карта"
  :baseUri="tileBaseUri"
  :zoomLevel="масштаб"
  :smallMem="isLowEndDevice"
/>
```

```js
импортировать SysDevice из @system.device

экспортировать по умолчанию {
  данные: {
    масштаб: 17,
    tileBaseUri: 'internal://files/tiles/my_provider',
    isLowEndDevice: ложь,
  },
  onInit() {
    // Определить, следует ли включать режим малой памяти, на основе бита архива в устройстве
    this.isLowEndDevice = SysDevice.memoryProfile <= 4096
  },
}
```
