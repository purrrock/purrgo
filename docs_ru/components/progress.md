
# прогресс

Компонент Progress используется для отображения индикатора выполнения, который по умолчанию представляет собой элемент уровня блока.

## Свойства

### `max` <decl type="number" set />

Максимальное значение прогресса, атрибут [`value`](#value) не будет больше его.

### `min` <decl type="number" set />

Минимальное значение прогресса, атрибут [`value`](#value) не будет меньше него.

### `value` <decl type="number" set get Listen />

Установите значение прогресса. Коэффициент отображения прогресса зависит от соотношения атрибута `value` в диапазоне от `min` до `max`, а коэффициент отображения будет ограничен величиной $0\%\sim 100\%$. `value` Значение является целым числом. Если задано значение с плавающей запятой, будет усечена только целая часть.

### `vertical` <decl type="boolean" set />

Если значение свойствавертикально равно true, компонент прогресса будет отображаться вертикально, в противном случае — горизонтально. Значение по умолчанию — «ложь».

## Спецификации CSS

Разработчики могут настроить внешний вид компонента прогресса с помощью CSS.

### Расчет размера

Ширина и высота прогресса по умолчанию такие же, как размер шрифта элемента. Размер шрифта задается атрибутом [`font-size`](/framework/generic/styles.md#font-size) (он также может быть унаследован). Размер прогресса можно настроить с помощью свойств [`width`](/framework/generic/styles.md#width) и [`height`](/framework/generic/styles.md#height).

### Свойства CSS

Следующие свойства CSS могут быть полезны:
- [`background-color`](/framework/generic/styles.md#background-color) может управлять цветом фона `progress`;
- [`color`](/framework/generic/styles.md#color) может управлять цветом индикатора прогресса `progress`;
- [`border-radius`](/framework/generic/styles.md#border-radius) Вы можете установить `progress` для закруглённой границы, например `50%` создаст полукруглую границу;

Другие свойства CSS могут оказаться полезными, например стиль границы с использованием свойства [`border`](/framework/generic/styles.md#border).

### Псевдоэлементы CSS

#### `значение`

Этот псевдоэлемент может определять только индикатор прогресса, не содержащий стиль фоновой части. Например, вы можете установить угловой радиус фона полосы прокрутки и части индикатора выполнения отдельно, чтобы добиться эффекта, при котором внешняя граница будет иметь круглую границу, а индикатор выполнения — прямую границу.

``` CSS
прогресс {
  радиус границы: 50%; /* Закругленные углы фона полосы прокрутки */
}

прогресс::значение {
  граница-радиус: 0; /* Индикатор выполнения полосы прокрутки не имеет закругленных углов */
}
```

### Пример CSS

В следующем примере показаны некоторые способы настройки внешнего вида индикатора выполнения с помощью CSS.

<glyphix id="comComponents-progress-styles" height="140" width="480" title="Стиль индикатора выполнения">

``` HTML
<дел>
  <!--Стиль по умолчанию -->
  <прогресс :value="40" />
  <!-- Прямой стиль индикатора выполнения -->
  <прогресс класс="плоский" :value="50" />
  <progress class="more-style" :value="60" />
</div>
```

``` CSS
div > * {
  поле: 8 пикселей;
}

.квартира::значение {
  /* Установите угловой радиус псевдоэлемента value равным 0, чтобы добиться эффекта прямой головки индикатора выполнения */
  граница-радиус: 0;
}

.more-стиль {
  /* Настраиваем радиус угла */
  радиус границы: 30%;
  /* Цвет фона индикатора выполнения */
  цвет фона: #b3c5d7;
  /* Цвет переднего плана индикатора выполнения */
  цвет: #b5179e;
  /* отступы могут регулировать границу переднего плана индикатора выполнения */
  отступ: 6 пикселей;
  высота: 1,25 рем;
}
```
