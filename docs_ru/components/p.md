
#р

Текстовый компонент. `p` по умолчанию является элементом уровня блока. В отличие от [`span`](span), компонент `p` не поддерживает пересечение строк текста, если он установлен как встроенный элемент. Если вам нужно реализовать верстку форматированного текста, вам следует рассмотреть возможность использования таких компонентов, как `span`.

## Свойства

### `text` <decl type="string" get set/>

Установите текстовое содержимое и поддержите следующие два метода письма.

``` HTML
<p text="Привет, Глификс"></p>
<p>Привет, Глификс!</p>
```

### `color` <decl type="string" get set/>

Установите цвет текста. Поддерживаются только шестнадцатеричные коды цветов, такие как `#f00`, `#e8bb80ff` и т. д. Это свойство представляет собой ярлык для изменения встроенного свойства CSS [`color`](/framework/generic/styles.md#color).

### `lines` <decl type="number" get set/>

Установите максимальное количество строк текста. Текст, превышающий это число, будет обрезан или опущен. Это свойство является ярлыком для изменения встроенного свойства CSS [`max-lines`](/framework/generic/styles.md#max-lines).

### `text-align` <decl type="string" set/>

Установите выравнивание текста, поддерживая значения «слева», «центра», «справа» и других значений. Это свойство является ярлыком для изменения встроенного свойства CSS [`text-align`](/framework/generic/styles.md#text-align).

### `font-size` <decl type="string" set/>

Установите размер шрифта текста, поддерживая `12px`, `1,5em` и другие значения размера шрифта CSS. Это свойство является ярлыком для изменения встроенного свойства CSS [`font-size`](/framework/generic/styles.md#font-size).

### `font-weight` <decl type="number" set/>

Установите толщину шрифта текста. В настоящее время поддерживаются только целочисленные значения, такие как `400`, `600` и ​​т. д. Это свойство представляет собой ярлык для изменения встроенного свойства CSS [`font-weight`](/framework/generic/styles.md#font-weight).

## Советы по использованию

### Контроль размера

В общем, не устанавливайте вручную высоту компонента `p`, например.
``` CSS
p.my-абзац {
  высота: 48 пикселей;
  размер шрифта: 32px;
}
```
На первый взгляд, это устанавливает высоту компонента `p`, превышающую размер шрифта, но происходит следующее:
- Для однострочного текста фактическая высота некоторых шрифтов может превышать размер шрифта, и даже высота «48 пикселей» может выглядеть обрезанной по вертикали.
- Для многострочного текста установка фиксированной высоты приведет к тому, что многострочный текст будет обрезан и не сможет отобразиться полностью.

Если вы хотите контролировать количество отображаемых строк текста, вам следует использовать [`max-lines`](/framework/generic/styles.md#max-lines) и [`text-overflow`](/framework/generic/styles.md#text-overflow) для реализации усечения и пропуска текста вместо установки фиксированной высоты.

### Анимация обрезки текста <version-badge с="0.9"/>

Вы можете использовать атрибут [`width`](/framework/generic/styles.md#width) с модификацией [`transition`](/framework/comComponent/prop-modifier.md#transition-modifier) для реализации анимации обрезки текста. Например:

``` HTML
<p:width="состояние? 240:0"
   width.transition="{duration: 2.0}">
  Привет, Глификс!
</p>
```

В сочетании со стилем `max-lines: 1` вы можете добиться анимации обрезки текста слева направо. Но с этой анимацией есть проблема: когда ширина недостаточна, последний символ будет отброшен, а не обрезан. Текущий обходной путь — поместить текстовое содержимое в дочерний компонент и анимировать ширину родительского компонента:

``` HTML
<div:width="состояние? 240:1"
     width.transition="{duration: 2.0}">
  <p style="max-lines: 1">Привет, Глификс!</p>
</div>
```

Однако при использовании элемента «div» в качестве родительского компонента возникает проблема с анимацией: когда ширина равна «0», размер макета рассчитывается как «(ширина: 0, высота: 0)», что приводит к тому, что элемент не может занимать вертикальное пространство и совершать вертикальный прыжок при запуске анимации. Решение состоит в том, чтобы установить очень маленькое значение ширины (например, «1px») вместо «0», чтобы элемент мог занимать вертикальное пространство и избежать проблем с отскоком.
