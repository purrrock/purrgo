
# а

Компонент привязки, который по умолчанию является встроенным элементом, используется для перехода на указанную страницу.

## Свойства

### `href` <decl type="string" get set />

Укажите [имя страницы](/framework/application/manifest.md#pages) или строку URI, по которой необходимо перейти.

``` HTML
<a href="page1">Перейти на страницу 1</a>
```

В отличие от тега `<a>` в Интернете, компонент `a` поддерживает только переходы по страницам, но не по гиперссылкам.

Атрибут `href` также поддерживает строки [URI](/framework/application/resource.md#uri) формы `PageName?key=value`, которые представляют собой URI, состоящий из имени страницы (в качестве поля пути) и поля запроса. Поле запроса URI будет анализироваться как параметр перехода страницы. Например, при нажатии на этот элемент `<a>`:

``` HTML
<a href="page1?text=test-text&message=hello">Перейти на страницу1</a>
```

Эквивалентно вызову следующего метода [`router.push()`](/api/system-router.md#push):

``` js
router.push({
  ури: 'страница1',
  параметры: {текст: 'test-text', сообщение: 'привет'}
})
```

::: совет
Обратите внимание, что значение поля запроса в URI будет анализироваться только как строковый тип, поэтому `100` в `page1?size=100` будет анализироваться как строка `'100`` вместо числа `100`. Если вам нужно передать параметры определенного типа, используйте API [`router`](/api/system-router.md).
:::
