
#радио

Переключатели, которые по умолчанию являются встроенными элементами, часто используются в **группе переключателей**, которая содержит набор переключателей, описывающих ряд связанных параметров. Одновременно можно выбрать только один переключатель в группе. Радиокнопки обычно отображаются в виде маленьких кружков, которые заполняются для выделения при выборе.

<glyphix id="radio-1" :height="65" title="переключатель">

``` HTML
<дел>
  <p>выбранный цвет: {{color}}</p>
  <дел>
    <radio id="red" value="red" model:group="color" />
    <label target="red">красный</label>
    <radio id="blue" value="blue" model:group="color" />
    <label target="blue">синий</label>
    <radio id="yellow" value="yellow" model:group="color" />
    <label target="yellow">желтый</label>
  </div>
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    цвет: 'синий'
  }
}
```

``` CSS
метка {
  поле справа: 0,5рем;
}
```

</глификс>

::: совет
Радиокнопки аналогичны [`checkbox`](checkbox.md), но `radio` может выбрать только одно значение из группы, а `checkbox` позволяет выбрать несколько значений.
:::

## Свойства

### `checked` <decl type="boolean" get set Listen />

Это свойство указывает, выбран ли этот переключатель. Установка атрибута «checked» может переключить проверенное состояние переключателя: если значение равно «true», оно отображается как отмеченное.

Событие «checked» вызывается, когда пользователь нажимает на переключатель, в результате чего его проверенное состояние изменяется.

::: совет
Манипулирование атрибутом `checked` не рекомендуется для использования `radio`, используйте метод [radio group](#group).
:::

### `value` <decl type="any" get set />

Значение JavaScript, определяющее значение переключателя, обычно это строка или число. Это значение не отображается, но его можно использовать в [группе радио](#group).

### `group` <decl type="any" get set Listen />

Если у вас есть несколько связанных компонентов «радио», вы можете объединить свойства «группа» и «значение». Переключатели внутри одной группы являются взаимоисключающими: значение реактивного свойства, привязанного к «группе», равно свойству «значение» выбранного переключателя. Например:
``` HTML
<radio value="red" model:group="color" />
<radio value="blue" model:group="color" />
<radio value="yellow" model:group="color" />
```
Где «цвет» — это адаптивный атрибут. Когда выбран второй переключатель, значение цвета равно «синему». Если «значение» и «цвет» всех переключателей не совпадают, то переключатель не будет выбран. Например:
``` HTML
<p on:click="color = null">сбросить выбор</p>
```
Выбранное состояние будет очищено:

<glyphix id="radio-reset" :height="65" title="Очистить выбранное состояние">

``` HTML
<дел>
  <p on:click="color = null">выбранный цвет: {{color}} (нажмите, чтобы сбросить)</p>
  <дел>
    <radio id="red" value="red" model:group="color" />
    <label target="red">красный</label>
    <radio id="blue" value="blue" model:group="color" />
    <label target="blue">синий</label>
    <radio id="yellow" value="yellow" model:group="color" />
    <label target="yellow">желтый</label>
  </div>
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    цвет: 'синий'
  }
}
```

метка {
  поле справа: 0,5рем;
}

### Поведение CSS

По умолчанию переключатель является встроенным элементом, его размер отображения определяется CSS-свойством «font-size» и выравнивается по базовой линии отображения текста. Пожалуйста, не указывайте вручную такие атрибуты, как «ширина» и «высота», иначе это может привести к путанице при отображении.
