
# текстовая область

`textarea` <experimental/><version-badge поскольку="0.9" /> — это компонент многострочного ввода текста, который по умолчанию отображается как элемент уровня блока. В отличие от аналогичных элементов графического интерфейса на мобильных телефонах или ПК, textarea в настоящее время не реагирует на устройства ввода, такие как клавиатуры, и не отображает интерфейс метода ввода, поэтому вам придется вручную редактировать его содержимое. textarea поддерживает управление курсором с помощью сенсорных жестов (таких как щелчок и прокрутка) и предоставляет методы для перемещения курсора вверх, вниз, влево и вправо.

`textarea` подходит в качестве низкоуровневого компонента для многострочного ввода текста и может реализовать программную клавиатуру и управление курсором в соответствии с вашими потребностями. Подробную информацию см. в [Пример](#Базовый пример).

::: важная совместимость
`textarea` — это экспериментальный компонент расширения, который в настоящее время доступен только в Glyphix 0.9 и выше и поддерживается только некоторыми устройствами.
:::

## Свойства

### `text` <decl type="string" get set Listen />

Атрибут text — это строка, которая представляет собой редактируемое в данный момент текстовое содержимое textarea. Чтение или прослушивание этого значения позволяет получить входной текст, а также вы можете установить это свойство.

Обычно «текст» двунаправленно привязан к определенному адаптивному атрибуту, и текст также может быть установлен через содержимое внутри элемента, например:

```html
<textarea::text="inputText" />
```

или

```html
<textarea @text="onTextChanged">{{ inputText }}</textarea>
```

:::совет
Атрибут `text` для `textarea` функционально аналогичен атрибуту [`value`](text-field.md#value) для [`text-field`](text-field.md).
:::

### `placeholder` <decl type="string" set get />

Если содержимое текстовой области пусто, вы можете использовать заполнитель, чтобы предоставить пользователю короткое приглашение, например, такую фразу, как «Пожалуйста, введите текст».

`placeholder` автоматически отображается, когда вводимый текст пуст, поэтому обычно требуется только фиксированное содержимое, например:

```html
<textarea ::text="inputText" Placeholder="введите здесь" />
```

### `insert` <decl type="(text: string): void" метод />

Вставьте фрагмент текста с содержимым «текст» в курсор, и курсор автоматически переместится вслед за вставленным текстом. Вызов этой функции вызовет событие прослушивания `text`.

### `backspace` <decl type="(): void" метод />

Удалите символ на курсоре, и курсор автоматически переместится вперед. Вызов этой функции вызовет событие прослушивания `text`.

### `moveCaret` <decl type="(направление: 'вверх' | 'вниз' | 'влево' | 'вправо'): void" метод />

Перемещает курсор на одну позицию в указанном направлении. Необязательные значения параметра «direction»: «вверх», «вниз», «влево» и «вправо», которые соответствуют четырем направлениям: вверх, вниз, влево и вправо соответственно.

### Базовый пример

В следующем примере показано базовое использование textarea. Пользователи могут напрямую вводить несколько строк текста в текстовое поле или использовать виртуальную клавиатуру ниже для редактирования содержимого: нажмите клавишу с буквой/символом, чтобы вставить символы; клавиша «`×`» удаляет содержимое под курсором; клавиша «Аа» переключает регистр на прописные и строчные; клавиша «`1#`» переключает на символьную клавиатуру; клавиша «Enter» вставляет символ новой строки; клавиши со стрелками перемещают курсор.

Сначала мы получаем объект компонента textarea с помощью метода $element в функции жизненного цикла компонента onReady(), поскольку затем нам нужно отредактировать содержимое и переместить курсор с помощью методов [`insert()`](#insert), [`backspace`](#backspace) и [`moveCaret`](#movecaret).

Исходя из этого, мы можем вызвать метод textarea в прослушивателе событий касания компонента button, например:

```html
<button on:touchstart="ta.insert('A')">A</button>
```

Поскольку физической клавиатуры нет, разработчикам обычно необходимо предоставить собственную реализацию клавиатуры. В этом примере реализована полная раскладка клавиатуры QWERTY, поддерживающая переключение верхнего и нижнего регистра, а также символьную клавиатуру. Вызовите соответствующий метод в функции прослушивания событий касания каждой клавиши, чтобы отредактировать текст. Клавиши со стрелками перемещают курсор (вверх, вниз, влево и вправо) с помощью метода [`moveCaret()`](#movecaret), а клавиша перевода строки вставляет символ новой строки `\n` с помощью [`insert()`](#insert).

Разница между ### и текстовым полем

`textarea` и `text-field` являются компонентами ввода текста. Основные различия заключаются в следующем:

| Недвижимость | `текстовая область` | `текстовое поле` |
|------|-----------|-------------|
| Количество строк текста | Одна или несколько строк | Одна линия |
| Поддержка новой строки | Поддержка `\n` новой строки | Не поддерживать новую строку |
| Движение курсора | Движение вверх и вниз | Движение влево и вправо |
| Атрибуты контента | `текст` | `ценность` |
| Режим пароля | Не поддерживается | Поддерживается атрибут `password` |
| Дисплей по умолчанию | Блочные элементы | Встроенные элементы |
