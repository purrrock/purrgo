
# ярлык

Компонент label используется для отображения текста или информации метки и по умолчанию является встроенным элементом. `label` можно использовать со следующими компонентами формы для отображения информации о метке:
-[вход](ввод)
-[радио](радио)
- [переключатель] (переключатель)
- [флажок] (флажок)

Если метка связана с поддерживаемым компонентом формы, нажатие на компонент метки также приведет к обновлению значения компонента формы.

## Свойства

### `text` <decl type="string" set get />

Текстовое содержимое метки поддерживает синтаксис атрибутов или синтаксис текстовых подэлементов:
``` HTML
<label text="label text"></label>
<label>текст метки</label>
```

### `target` <decl type="string" set get />

Идентификатор целевого компонента. Например:
```html
<radio id="red" /><label target="red">красный</label>
```
Щелчок по компоненту «label» в этом примере также вызовет обновление компонента «radio» с идентификатором «red», но щелчок по компоненту «label» не вызовет «щелчок» и другие события касания целевого компонента.

Учитывая проблемы с производительностью, поддерживаются только целевые компоненты, находящиеся на том же уровне, что и компонент «метка» (т. е. имеющие тот же родительский компонент).

::: предупреждение
Изменение целевого компонента в настоящее время не поддерживается.
:::
