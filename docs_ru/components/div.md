
#див

`div` — это самый простой компонент контейнера. `div` поддерживает подкомпоненты и макет, но не поддерживает прокрутку (содержимое будет обрезано напрямую, если оно выходит за границу). Если вы хотите, чтобы контент прокручивался, используйте компонент [scroll](прокрутка).

## Примечания

### Текстовое отображение

Компонент div нельзя использовать для непосредственного отображения текста. Вместо этого для отображения текста необходимо использовать текстовые компоненты, такие как `p`, например:

```html
<!-- Неправильно написано, текст не будет отображаться -->
<div>текстовое содержимое.</div>
<!-- Правильное написание -->
<p>текстовое содержимое.</p>
```

Однако если внутри div есть несколько дочерних элементов, вы можете использовать текст в качестве дочернего элемента:

```html
<дел>
  первый элемент,
  <span style="color: #f0f">второй элемент.</span>
</div>
```
