
#list-item

Подкомпонент списка используется для отображения определенных элементов в списке. Он поддерживает подкомпоненты и макет, но не поддерживает прокрутку.

::: совет
Glyphix не предоставляет тот же компонент контейнера списка, что и быстрые приложения, но использует [`scroll`](scroll.md) для реализации контейнеров прокрутки. Аналогично, нет необходимости использовать компонент list-item, используйте непосредственно [`div`](div.md) или любой другой компонент в качестве элемента элемента списка.
:::
