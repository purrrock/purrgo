
#drawer-навигация

Подкомпонент [`drawer`](drawer), используемый для отображения определенного содержимого ящика.

## Свойства

### `direction` <decl type=" 'left' | 'right' | 'up' | 'down' " set />

Атрибут Direction используется для установки направления навигации по ящику. Необязательные значения: «влево», «вправо», «вверх», «вниз».

| ценность | описание |
| :-------: | -------------------------------------------------- |
| `'левый'` | Навигация по ящику в левой части экрана используется для реагирования на жест скольжения слева направо.       |
| `'право'` | Навигация по ящикам в правой части экрана соответствует жесту скольжения справа налево.       |
| `'вверх'` | Навигация по ящику в нижней части экрана соответствует жесту скольжения снизу вверх.     |
| `'вниз'` | Навигация по ящику в верхней части экрана соответствует жесту скольжения сверху вниз.       |
