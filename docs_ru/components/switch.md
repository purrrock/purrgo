
# переключатель

Switch выбирает компоненты, по умолчанию используются встроенные элементы. Используется для обозначения состояния включения/выключения и позволяет пользователю переключаться между двумя состояниями. Функция «переключатель» аналогична «флажку», но эффект взаимодействия и намерение различны, то есть выражают переключение и проверку соответственно.

<glyphix id="компоненты-переключатель" height="30">

``` HTML
<дел>
  <переключатель ::value="включено" />
  <span>состояние переключателя: {{ включено? 'вкл': 'выкл' }}</span>
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    включено: ложь
  }
}
```
</глификс>

::: Примечание
Компонент `switch` обычно имеет стиль, показанный в примере, но может отличаться в зависимости от устройства. В частности, следует отметить, что ширина «переключателя» может быть разной на разных устройствах, и разработчикам следует зарезервировать соответствующие поля макета.
:::

## Свойства

### `value` <decl type="boolean" set get Listen/>

Представляет состояние переключателя. Если значение равно true, переключатель находится во включенном состоянии, в противном случае — в выключенном. Если атрибут `value` не указан, компонент `switch` по умолчанию отключен.

### `checked` <decl type="boolean" set get/>

Это атрибут быстрой совместимости приложений, и обычно рекомендуется использовать [`value`](#value)

### `change` <decl type="{checked: boolean }" get Listen/>

Это атрибут быстрой совместимости приложений, и обычно рекомендуется использовать [`value`](#value)

## поведение CSS

Общий стиль компонента `switch` определяется системой и не контролируется разработчиком, как и разница в стиле между [Fluent 2](https://fluent2.microsoft.design/comComponents/web/react/switch/usage) и [Material 3](https://m3.material.io/comComponents/switch/overview). Glyphix позволяет настраивать цвет переключателя в CSS и изменять размер переключателя.

### Свойства CSS

#### `цвет`

Установите цвет ползунка компонента `switch`. В отличие от общего CSS [`color`](/framework/generic/styles.md#color), свойство color объекта `switch` не поддерживает наследование, поэтому вы должны определить его в текущем компоненте `switch`.

<glyphix id="comComponents-switch-color" height="36" title="цвет слайдера siwtch">

``` HTML
<дел>
  красный цвет: <switch class="red"/>,
  не наследуется: <switch/>
</div>
```

``` CSS
дел {
  цвет: красный; /* Обратите внимание, что переключатель не наследует атрибут цвета */
}

.красный {
  цвет: красный; /* цвет должен быть определен в стиле компонента переключателя */
}
```
</глификс>

#### `цвет фона`

Управляет цветом фона компонента `switch`, подробности см. в документации псевдокласса [`active`](#active).

#### `размер шрифта`

Вы можете настроить размер `switch` с помощью свойства CSS [`font-size`](/framework/generic/styles.md#font-size) для координации размера встроенного текста. Следующий пример демонстрирует связь между размером шрифта и размером переключателя:

<glyphix id="comComponents-switch-size" height="100" title="размер шрифта и размер переключателя">

``` HTML
<дел>
  <p класс="title">
    текст заголовка: <switch/> (1.25rem)
  </p>
  <р>
    текст содержимого: <switch/> (1rem)
  </p>
</div>
```

``` CSS
дел {
  высота строки: 1,8рем;
}

.title {
  цвет: #415a77; /* Обратите внимание, что переключатель не наследует атрибут цвета */
  размер шрифта: 1,25рем;
}
```
</глификс>

::: предупреждение
Размер дисплея `switch` не контролируется такими свойствами, как `width` и `height`, но всегда определяется `font-size`. Поэтому, пожалуйста, не указывайте вручную такие атрибуты размера, как «ширина», чтобы избежать ненормального отображения.
:::

### Псевдоклассы CSS

#### `активный`

Псевдокласс active используется для определения стиля включения переключателя. Как показано в следующем примере, он обычно настраивается вместе с правилами обычного стиля:

<glyphix id="comComponents-switch-colors" height="36" title="настройки цвета слайдера siwtch">

``` HTML
<дел>
  переключатель цвета: <переключатель/>
</div>
```

``` CSS
/* Стиль, когда переключатель замкнут */
переключатель {
  цвет: #415a77;
  цвет фона: #bde0fe;
}

/* Стиль, когда переключатель включен */
переключатель: активный {
  цвет: #fefae0;
  цвет фона: #ffafcc;
}
```
</глификс>

В этом примере используются CSS-свойства «color» и «background-color» для управления стилем цвета при переключении «switch». Компонент `switch` будет реагировать на конфигурацию этих двух свойств CSS только тогда, когда активирован псевдокласс `active`.

::: совет
Пожалуйста, определите свойства «color» и «background-color» в нормальном и «активном» состояниях одновременно, иначе при переключении «switch» не будет соответствующего перехода цвета.
:::
