
#прокрутка

Контейнер прокручиваемого списка, поддерживающий любой подкомпонент. Направление прокрутки списка определяется конкретным методом макета: при использовании гибкого макета или гибкого макета направления «столбец» элементы располагаются в вертикальном направлении, и список можно прокручивать вертикально; при использовании гибкого макета направления «строка» элементы располагаются в горизонтальном направлении, и список можно прокручивать по горизонтали. Компонент `scroll` не поддерживает двунаправленную прокрутку (то есть горизонтальную и вертикальную прокрутку одновременно).

Компонент `scroll` — это элемент уровня блока, использующий по умолчанию гибкую компоновку.

Компонент прокрутки можно прокручивать с помощью жестов, а компонент вертикальной прокрутки также поддерживает прокрутку кодировщиком (вращающаяся заводная головка на часах и колесо мыши на симуляторе).

::: совет
Некоторые интерактивные примеры в этом документе поддерживают взаимодействие с колесиком мыши (значок мыши справа от заголовка): вы можете навести указатель внутри примера и использовать колесико мыши для прокрутки списка.
:::

## Свойства

### `scroll` <decl type="{ ScrollX: Number, ScrollY: Number, ScrollState: Number }" get Listen />

Значением свойства `scroll` является объект, содержащий следующие поля: `scrollX`, `scrollY` и `scrollState`. Свойства «scrollX» и «scrollY» представляют позиции горизонтальной и вертикальной прокрутки соответственно в пикселях; Свойство `scrollState` представляет состояние прокрутки, и его значение равно $0$, $1$ или $2$. Конкретное значение показано в следующей таблице. Изменения атрибута `scroll` можно отслеживать с помощью директивы `on`. Любое изменение положения контента, вызванное действиями пользователя и операциями API, приведет к запуску мониторинга.

| значение `scrollState` | Описание эффекта |
| :--------------: | ------------------------------------------------------------------------------- |
| $0$ | Перестал скользить |
| $1$ | Пролистывание жестами пользователя |
| $2$ | Пользователь отпустил руку, скольжение вызвано вызовами таких методов, как [`scrollTo`](#scrollto) или inertia |

:::информация
Область, в которой расположены дочерние элементы прокрутки, называется областью «содержимого», а часть, фактически отображаемая компонентом списка, называется областью «просмотра». Элементы располагаются в области контента, их размер может превышать область просмотра, а положение отображения контента можно изменять путем прокрутки.
:::

Диапазон позиции прокрутки обычно находится внутри области содержимого, то есть `scrollX` горизонтального списка находится в диапазоне $[0, \texttt{contentWidth}]$, а `scrollY` вертикального списка находится в диапазоне $[0, \texttt{contentHeight}]$. Но когда список прокручивается до начала содержимого, `scrollX` или `scrollY` будет меньше $0$; аналогично, когда список прокручивается до конца содержимого, значение «scrollX» или «scrollY» будет больше, чем «contentWidth» или «contentHeight».

::: предупреждение
Событие `scroll` будет запускаться каждый кадр во время процесса прокрутки. Прослушивание этого события в коде JavaScript может привести к очевидным пропускам кадров, поэтому старайтесь избегать его использования.
:::

### `scrollTop` <decl type="number" set get Listen />

Позиция вертикальной прокрутки, то есть расстояние от верхней части содержимого компонента прокрутки до верхней части области просмотра в пикселях. С помощью этого свойства вы можете установить позицию прокрутки, а также прослушивать изменения позиции прокрутки с помощью этого свойства.

В отличие от свойства [`scroll`](#scroll), прослушивание самого свойства `scrollTop` не может отличить прокрутку жестами пользователя от прокрутки, вызванной вызовами API или инерцией.

### `scrollLeft` <decl type="number" set get Listen />

Позиция вертикальной прокрутки, то есть расстояние от левой стороны содержимого компонента прокрутки до левой стороны области просмотра в пикселях. С помощью этого свойства вы можете установить позицию прокрутки, а также прослушивать изменения позиции прокрутки с помощью этого свойства.

В отличие от свойства [`scroll`](#scroll), прослушивание самого свойства `scrollLeft` не позволяет отличить прокрутку жестами пользователя от прокрутки, вызванной вызовами API или инерцией.

### `scrollWidth` <decl type="number" get Listen />

`scroll` Ширина области содержимого компонента. Ширина прокрутки в вертикальной компоновке равна ширине просмотра, а ширина прокрутки в горизонтальной компоновке представляет собой сумму ширин всех элементов. Вы можете использовать это для отслеживания изменений ширины контента.

### `scrollHeight` <decl type="number" get Listen />

`scroll` Высота области содержимого компонента. Высота прокрутки в вертикальной компоновке равна высоте просмотра, а высота прокрутки в горизонтальной компоновке равна сумме высот всех элементов. Вы можете использовать это для отслеживания изменений высоты контента.

### `демпфирование` <decl type="number" set />

Установите коэффициент демпфирования анимации прокрутки списка. Допустимый диапазон значений — $[0.1, 50]$ (неподдерживаемые значения будут автоматически изменены до верхнего и нижнего пределов). Значение по умолчанию составляет 1,5 доллара США. Больший коэффициент демпфирования приведет к более быстрой остановке анимации, а значение коэффициента демпфирования по умолчанию может вызвать инерционный эффект на большем расстоянии и большей продолжительности.

<glyphix id="comComponents-scroll-damping" height="360" width="360" title="Колесо с эффектом демпфирования">

``` HTML
<дел>
  <span>демпфирование: {{демпфирование}}</span>
  <button on:click="increase">+</button>
  <button on:click="decrease">-</button>
  <прокрутка :damping="демпфирование">
    <p for="x из 50" class="item">
      Товар {{ x + 1 }}
    </p>
  </прокрутка>
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    Демпфирование: 1
  },
  увеличение() {
    это.демпфирование += 1
    если (this.damping > 20)
      это.демпфирование = 1
  },
  уменьшение() {
    это.демпфирование -= 1
    если (this.damping < 1)
      это.демпфирование = 19,5
  }
}
```

``` CSS
пролет {
  цвет: #404040;
}

прокрутить {
  дисплей: гибкий;
  гибкое направление: столбец;
  цвет фона: #f0f0f0;
  высота: 300 пикселей;
  ширина: 360 пикселей;
}

.item {
  цвет: #фафафа;
  цвет фона: #bdbdbd;
  выравнивание текста: по центру;
  отступы: 20 пикселей 5 пикселей;
  поле: 10 пикселей;
  радиус границы: 16 пикселей;
}

кнопка {
  цвет: #фафафа;
  цвет фона: #adadad;
  радиус границы: 12 пикселей;
  поле слева: 16 пикселей;
  поле внизу: 16 пикселей;
  ширина: 1,2рем;
}
```

</глификс>

::: совет
Коэффициент демпфирования должен быть установлен постоянным и не изменяться. Изменение коэффициента демпфирования не повлияет на анимацию отскока.
:::

### `snapshot` <decl type="boolean" get set />

Когда атрибут `snapshot` включен, подкомпоненты в списке перейдут в режим моментального снимка. Соответствующие демонстрации см. в свойстве [`quiescent`](/framework/generic/properties.md#quiescent) собственных компонентов.

Включение моментальных снимков может увеличить частоту кадров сложных интерфейсов. Например, если элемент списка содержит большой объем текста и непрозрачный фон, режим снимков может кэшировать и объединять большое количество операций рисования в небольшое количество снимков. Платформа Glyphix кэширует эти снимки при повторных отрисовках для дальнейшего повышения производительности.

Однако атрибут snapshot не дает гарантии, что подкомпонент использует снимок. Этот атрибут можно игнорировать, если в системе недостаточно памяти или нет необходимости использовать снимок.

### `деформация` <decl type="string | function" set />

Установите эффект деформации списка. Благодаря эффекту деформации вы можете добиться эффекта рыбьего глаза и других эффектов. Встроенный эффект морфинга можно указать по имени (строке) или эффект морфинга можно определить с помощью функции JavaScript.

| Значение | Описание эффекта |
| :---------: | :----------------------------------: |
| `'нет'` | Нет эффекта трансформации (по умолчанию) |
| `'рыбий глаз'' | Встроенный эффект «рыбий глаз» |
| функция | Укажите эффекты деформации с помощью функций JavaScript |

Эффект деформации должен быть постоянным и немодифицированным.

Когда для списка установлен эффект деформации «рыбий глаз», рекомендуется установить атрибут [`scrollSnap`](#scrollsnap) в значение `'center'`, чтобы получить наиболее разумный эффект.

На рисунке ниже показан эффект деформации «рыбий глаз». Вы можете настроить центрирование изображения с помощью переключателя «Центр».

<glyphix id="comComponents-scroll-deformation" height="360" width="360" title="колесо с эффектом рыбьего глаза">

``` HTML
<дел>
  <p>центр <switch ::value="center" /></p>
  <scroll деформации="рыбий глаз" :scroll-snap="center ? 'center': null">
    <p for="x из 15">
      Товар {{ x + 1 }}
    </p>
  </прокрутка>
</div>
```

``` CSS
дел {
  цвет: #404040;
  дисплей: гибкий;
  гибкое направление: столбец;
}

прокрутить {
  дисплей: гибкий;
  гибкое направление: столбец;
  цвет фона: #f0f0f0;
  гибкий: 1;
}

прокрутите > п {
  цвет: #фафафа;
  цвет фона: #bdbdbd;
  выравнивание текста: по центру;
  отступ: 40 пикселей 10 пикселей;
  поле: 5 пикселей;
  радиус границы: 50%;
}
```

``` js

  данные: {
    центр: правда
  }

```

</глификс>

::: совет
Эффекты деформации обычно используют снимки, поэтому нет необходимости повторно устанавливать «снимок» при настройке атрибута «деформация».
:::

### `scrollSnap` <decl type="'none' | 'start' | 'center' | 'edge'" get set />

Установите режим выравнивания и привязки элементов списка. Например, вы можете выровнять элемент по центру или привязать его к краю элемента.

| ценность | описание |
| :--------: | ------------------------------------------------------------------------------------------------------------------------------- |
| `'нет'` | Элемент не имеет эффектов присасывания и прикрепления, то есть дочерние элементы могут останавливаться в любом положении в соответствии с инерцией прокрутки.                                                   |
| `'старт'` | Выравнивает начальную позицию элемента по начальной позиции области просмотра при остановке прокрутки. Этот режим в настоящее время не поддерживается.                                                   |
| `'центр'` | Остановка прокрутки — это когда центральное положение элемента выравнивается по центру области просмотра.                                                                     |
| `'край'` | Когда прокрутка останавливается, начальная или конечная позиция элемента выравнивается с начальной или конечной позицией области просмотра. Но если свиток не пересекает границу элемента, это не вызовет адсорбции. |

Атрибут `scrollSnap` не регулирует размер элемента, но может использовать такие механизмы, как макет, для реализации списка элементов одинакового размера.

::: предупреждение
Это свойство должно быть установлено при инициализации компонента и не может быть изменено, иначе могут возникнуть ошибки взаимодействия.
:::

### `index` <decl type="number" get set Listen />

Индекс отображаемого в данный момент подкомпонента. Если свойство index установлено, компонент будет прокручиваться до указанного подкомпонента посредством анимации. Изменения позиции можно отслеживать с помощью директивы on, а изменения индекса подкомпонента можно отслеживать с помощью атрибута index.

Значение index автоматически ограничивается, чтобы гарантировать, что оно указывает на действительный элемент. При использовании index вы должны убедиться, что все элементы компонента scroll являются статическими (то есть свойство CSS [`position`](/framework/generic/styles.md#position) является статическим по умолчанию), в противном случае произойдет ошибка.

### `finalChanged` <decl type="bool" get set />

Установите, будет ли событие изменения [`index`](#index) запускаться только при остановке прокрутки. По умолчанию (то есть, значение FinalChanged равно false), всякий раз, когда свойство index компонента прокрутки изменяется из-за жеста прокрутки или по другим причинам, срабатывает его событие прослушивания. Однако это может легко привести к пропаданию кадров анимации или возникновению слишком частых и ненужных событий. Если установлен параметр FinalChanged, событие изменения индекса будет вызвано только при остановке прокрутки.

::: совет
При реализации таких эффектов, как точечные индикаторы, путем мониторинга атрибута index, рекомендуется установить для FinalChanged значение true, что позволит избежать пропадания кадров, вызванного обновлениями рендеринга, инициируемыми событиями, во время процесса скольжения.
:::

  <прокрутка :final-changed="finalChanged" ::index="index">

### `bounces` <decl type="'none' | 'start' | 'end' | 'edge'" get set />

Устанавливает, вызывать ли отскок после прокрутки к границе с помощью жестов. Начальное значение этого свойства — «edge», что позволяет изменять начальную и конечную позиции.

| ценность | описание |
| :-------: | ----------------------------------------- |
| `'нет'` | Отключает все отскоки границ.                     |
| `'старт'` | Разрешает отскок только после перетаскивания в начальную позицию содержимого.     |
| `'конец'` | Разрешает отскок только после перетаскивания в конец содержимого.     |
| `'край'` | Позволяет отскакивать после перетаскивания в начало или конец содержимого. |

В следующем примере показан эффект каждого значения «отскоков». Вы можете попробовать сдвинуть каждый элемент влево или вправо за границу и наблюдать соответствующее поведение взаимодействия.

<glyphix id="comComponents-scroll-bounces" height="360" width="400" title="Анимация перетаскивания и отскока">

``` HTML
<scroll class="column-box">
  <scroll for="item in items" class="row-box"
          :bounces="item" Scroll-snap="edge">
    <p class="item-body">отскакивает: {{item}}</p>
    <p class="slide-button">×</p>
  </прокрутка>
</прокрутка>
```

```js
экспортировать по умолчанию {
  данные: {
    элементы: ['нет', 'начало', 'конец', 'край']
  }
}
```

``` CSS
.column-box {
  дисплей: гибкий;
  гибкое направление: столбец;
}

.row-box {
  дисплей: гибкий;
  гибкое направление: строка;
}

.row-box > п {
  радиус границы: 12 пикселей;
  выравнивание текста: по центру;
  поле: 8 пикселей;
  отступ: 16 пикселей;
}

.item-body {
  цвет фона: #f0f0f0;
  ширина: 100%;
}

.слайд-кнопка {
  ширина: 30%;
  цвет: #ffffff;
  цвет фона: #f04040;
}
```

</глификс>

::: Примечание
В настоящее время свойство «bounces» влияет только на отскок операций жестов, но игнорирует быстрые инерционные отскоки анимации. В приведенном выше примере используется трюк, позволяющий избежать неожиданного поведения:
- `.row-box` использует стратегию привязки кромок (`snap-type="edge"`), чтобы избежать анимации жестов с отскоком.
- Каждый элемент `.row-box` не превышает ширину `100%`, чтобы гарантировать, что стратегия привязки краев не приведет к отскоку внутренней границы.

Этот метод можно использовать для таких интерфейсов, как скользящие меню удаления.
:::

Атрибут `bounces` также будет играть аналогичную роль [`weakGesture`](#weakgesture). В частности, когда граница, запрещающая отскок, пересекается, событиям жеста прокрутки автоматически разрешается всплывать и доставляться. Таким образом, нет необходимости одновременно устанавливать свойства «bounces» и «weakGesture».

::: совет
Поведение пузырькового жеста прокрутки для `bounces` и`weakGesture` является «противоположным». Например, стратегия отскока в режиме «конец» позволяет пользователю вернуться назад после прокрутки за конечную позицию списка, и эта стратегия позволит жесту прокрутки всплывать в начальной позиции. Это соответствует эффекту свойстваweakGesture со значением start.
:::

### `weakGesture` <decl type="'none' | 'start' | 'end' | 'edge'" get set />

Устанавливает обстоятельства, при которых компонент прокрутки будет использовать жесты прокрутки. По умолчанию `scroll` предотвращает всплывание жестов, на которые он реагирует, поэтому его родительский элемент не может получать жесты, которые вызывают прокрутку `scroll`. WeakGesture позволяет всплывать события жестов при перетаскивании в границы содержимого, позволяя родительскому элементу получать эти жесты.

| ценность | описание |
| :-------: | -------------------------------------------------- |
| `'нет'` | Не всплывайте соответствующее событие жеста.                     |
| `'старт'` | Всплывает соответствующее событие жеста после перетаскивания в начальную позицию содержимого.       |
| `'конец'` | Всплывает соответствующее событие жеста после перетаскивания в конец содержимого.       |
| `'край'` | Всплывает соответствующее событие жеста после перетаскивания в начало или конец содержимого. |

Если базовым элементом страницы является компонент горизонтальной прокрутки, но вы хотите, чтобы жест смахивания вправо возвращал страницу, вы можете настроить его следующим образом:
``` HTML
<scroll слабый-жест="start"> ... </scroll>
```
Когда пользователь приближается к заголовку компонента прокрутки и продолжает скользить вправо, чтобы выйти со страницы.

::: предупреждение
Это свойство должно быть установлено при инициализации компонента и не может быть изменено, иначе могут возникнуть ошибки взаимодействия.
:::

### `scrollbar` <decl type="boolean" get set />

Отмечает, должен ли компонент прокрутки отображать полосы прокрутки (не отображаются по умолчанию). Поддерживаются только компоненты вертикальной прокрутки. Свойство «полоса прокрутки» должно быть константой и не может быть изменено с помощью реактивных свойств, например:
``` HTML
<полоса прокрутки>
  ...
</прокрутка>
```
Будет создан компонент прокрутки с полосой прокрутки. Чтобы узнать о эффекте полосы прокрутки, обратитесь к примеру метода [`setIndex`](#setindex).

Стиль полосы прокрутки определяется системой. Например, он может выглядеть как дуга на круглом экране или как прямая полоса на прямоугольном экране.

### `scrolled` <decl type="boolean" Listen />

Следите за тем, прокручивается ли список, с помощью свойства `scrolled`. Если значение свойства события равно true, это означает, что список прокручивается, в противном случае это означает, что список прекратил прокрутку.

Как операции прокрутки, вызванные касанием пользователя, так и прокрутка свойства прокрутки вызовут событие прокрутки. Когда список перестает прокручиваться, значение параметра события `scrolled` равно `false`.

### `setIndex`
<метод decl><pre>
(варианты: {
  индекс: номер,
  поведение?: «мгновенный» | 'гладкий'
}): пустота
</pre></decl>

Перемещает область просмотра к дочернему компоненту, указанному index. Если это движение пересекает границу видового экрана, положение видового экрана останется на первом или последнем компоненте. Функции атрибута параметра `options`:
- `index`: индекс целевого подкомпонента, который нужно переместить, $0$ представляет первый подкомпонент.
- «Поведение»: использовать анимированный переход, когда он «гладкий», и немедленно перемещаться к указанной позиции дочернего компонента, когда «мгновенный» (значение по умолчанию).

При вызове `setIndex()` вы должны убедиться, что все элементы компонента `scroll` статичны, иначе произойдет ошибка.

### `scrollTo`
<метод decl><pre>
(варианты: {
  осталось?: номер,
  верх?: номер,
  поведение?: «мгновенный» | 'гладкий'
}): пустота
</pre></decl>

Прокручивает содержимое до указанной позиции. Функции атрибута параметра `options`:
- `left`: определяет положение, в котором содержимое прокручивается вдоль оси Y. Если параметр left игнорируется или компонент прокрутки имеет вертикальное расположение, прокрутка по оси Y не произойдет.
- `top`: определяет положение, в котором содержимое прокручивается вдоль оси X. Если `top` игнорируется или компонент прокрутки имеет горизонтальное расположение, прокрутка по оси X не произойдет.
- `behavior`: определяет эффект перехода при прокрутке. «Мгновенный» (значение по умолчанию) означает переход непосредственно к целевой позиции без эффекта перехода, а «плавный» плавно прокручивает и создает эффект перехода.

Метод `scrollTo` игнорирует эффект адсорбции элемента.

### `прокрутка`
<метод decl><pre>
(варианты: {
  осталось?: номер,
  верх?: номер,
  поведение?: «мгновенный» | 'гладкий'
}): пустота
</pre></decl>

Прокрутите контент на определенное расстояние. В отличие от [`scrollTo()`](#scrollTo), `scrollBy()` прокручивает относительно текущей позиции содержимого. Функции атрибута параметра `options`:
- `left`: определяет расстояние прокрутки содержимого по оси Y. Если параметр left игнорируется или компонент прокрутки имеет вертикальное расположение, прокрутка по оси Y не произойдет.
- `top`: определяет расстояние прокрутки содержимого по оси X. Если `top` игнорируется или компонент прокрутки имеет горизонтальное расположение, прокрутка по оси X не произойдет.
- `behavior`: определяет эффект перехода при прокрутке. «Мгновенный» (значение по умолчанию) означает переход непосредственно к целевой позиции без эффекта перехода, а «плавный» плавно прокручивает и создает эффект перехода.

Метод `scrollBy` игнорирует эффект адсорбции элемента.

### Управление направлением макета

Направление прокрутки компонента «прокрутка» определяется его методом макета. При использовании гибкого макета (макет по умолчанию) или гибкого макета направления «столбец» элементы располагаются в вертикальном направлении, и список можно прокручивать вертикально; при использовании гибкого макета направления «строка» элементы располагаются в горизонтальном направлении, и список можно прокручивать по горизонтали.

<glyphix id="comComponents-scroll-layout" height="360" width="740" title="Режим макета управляет направлением прокрутки">

``` HTML
<дел>
  <прокрутка>
    <p for="20">вертикальная прокрутка</p>
  </прокрутка>
  <!-- Используется для элементов-заполнителей, поскольку гибкая компоновка еще не поддерживает пробелы -->
  <div style="width: 20px"></div>
  <scroll style="display: flex; flex-direction: row;">
    <p for="20">горизонтальная<br>прокрутка</p>
  </прокрутка>
</div>
```

### `padding` и `overflow` <version-badge с = "0.9" />

По умолчанию (`overflow: clip`) отступы компонента прокрутки непосредственно обрезают видимую область. При прокрутке содержимого область заполнения всегда невидима. Настройка `overflow:visible` позволяет области заполнения оставаться видимой при прокрутке содержимого.

<glyphix id="comComponents-scroll-padding-overflow-visible" height="360" width="740" title="overflow: видимый отступ">

``` HTML
<дел>
  <прокрутка :index="2">
    <p for="20">переполнение: клип</p>
  </прокрутка>
  <!-- Используется для элементов-заполнителей, поскольку гибкая компоновка еще не поддерживает пробелы -->
  <div style="width: 20px"></div>
  <scroll style="overflow: видимый;" :index="2">
    <p for="20">переполнение: видимое</p>
  </прокрутка>
</div>
```

``` CSS
дел {
  дисплей: гибкий;
}

прокрутить {
  отступ: 20 пикселей;
  цвет фона: #f0f0f0;
  гибкий: 1;
}

п {
  цвет фона: #bdbdbd;
  выравнивание текста: по центру;
  отступ: 20 пикселей;
  поле: 4 пикселя;
  радиус границы: 16 пикселей;
}
```

</глификс>

Даже если установлено значение «overflow:visible», «scroll» будет обрезать содержимое в поле отступа, а не позволять ему выходить за пределы этого диапазона, в отличие от обычных элементов, таких как «div». Это связано с тем, что поведение прокрутки и механизм макета «прокрутки» должны гарантировать, что содержимое прокручивается в пределах определенной области, а не позволяет содержимому без ограничений расширяться за пределы области.

В случае обычных контейнеров, таких как div и overflow:visible, содержимое может выходить за пределы всего div (например, за пределами красной границы):

<glyphix id="comComponents-scroll-overflow-div" height="360" width="360" title="переполнение div: видимое">

``` HTML
<div style="overflow: видимый;">
  <p for="20">div {overflow: видимый</p>
</div>
```

``` CSS
дел {
  дисплей: гибкий;
  гибкое направление: столбец;
  отступ: 20 пикселей;
  поле внизу: 100 пикселей;
  граница: 2 пикселя, сплошная красная;
  цвет фона: #f0f0f0;
}

п {
  цвет фона: #bdbdbd;
  выравнивание текста: по центру;
  отступ: 8 пикселей;
  поле: 4 пикселя;
  радиус границы: 16 пикселей;
  гибкое сжатие: 0;
}
```

</глификс>

#### Рекомендуемые настройки для сценариев i18n

В сценариях i18n (интернационализация) текст внутри «прокрутки», возможно, придется переполнить, чтобы избежать возможного усечения. В этом случае рекомендуемая настройка — «overflow:visible», чтобы разрешить содержимому [text overflow](/framework/application/i18n.md#textoverflow) выходить за границы содержимого «прокрутки» при прокрутке, чтобы максимально использовать пространство для отображения текста.

#### Связь со спецификациями HTML/CSS

Поведение `scroll` при настройке `overflow:visible` аналогично `div { overflow-y: Scroll; }` в спецификации HTML/CSS. Заполнение в это время может сохранять содержимое видимым во время прокрутки, как показано в этом CSS:

``` CSS
дел {
  отступ: 20 пикселей;
  переполнение-y: прокрутка;
}
```

Будет получен следующий эффект, то есть область заполнения не будет обрезать содержимое при прокрутке:

<div style="padding: 20px; цвет фона: var(--vp-c-grey-bg); overflow-y: прокрутка; высота: 100 пикселей; ширина: 200 пикселей; граница: 2 пикселя, красный с точками; семейство шрифтов: без засечек;">
  Недавно закончился Михайловский срок, и лорд-канцлер сидит в зале Линкольнс-Инн.
  Неумолимая ноябрьская погода. На улицах столько грязи, словно вода только что
  недавно ушедший с лица земли.
</div>

HTML-элемент «div» не соответствует напрямую поведению «прокрутки» в «overflow: clip».
