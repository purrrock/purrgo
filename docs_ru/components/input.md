
# вход

По умолчанию используется встроенный элемент, который предоставляет интерактивный интерфейс и принимает вводимые пользователем данные.

## Свойства

### `type` <decl type="'checkbox' | 'radio'" set />

Элементы управления, которым можно задать указанные выше типы значений. Фактическая форма конечного компонента «вход» определяется в соответствии с установленным типом.

### `name` <decl type="string" set />

Установите имя компонента `input`.

### `checked` <decl type="boolean" set />

Статус «Проверено» текущего компонента может активировать псевдокласс «Проверено», который вступает в силу, когда типом является флажок. Если установлено значение «on», флажок установлен по умолчанию.

### `value` <decl type="string" set />

Установите значение компонента input.
