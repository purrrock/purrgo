
#полоса прокрутки

Компонент полосы прокрутки. Этот компонент может отображать полосу прокрутки при большом количестве прокручиваемого содержимого, и пользователь может управлять прокруткой содержимого с помощью полосы прокрутки.

## Свойства

### `value` <decl type="number" set get Listen />

Текущее значение полосы прокрутки. Это значение находится между «min» и «max». Значение по умолчанию — $0$.

### `min` <decl type="number" set />

Минимальное значение полосы прокрутки. Это значение не должно быть больше, чем «max». Значение по умолчанию — $0$.

### `max` <decl type="number" set />

Максимальное значение полосы прокрутки. Это значение должно быть не меньше «min». Значение по умолчанию — 100 долларов США.

### `pagestep` <decl type="number" set />

Размер шага прокрутки полосы прокрутки, то есть расстояние каждой прокрутки. Значение по умолчанию — 10 долларов США.
