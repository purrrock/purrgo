
#swiper

Контейнер представления карты, поддерживающий любой подкомпонент. Направление прокрутки представления карточки определяется конкретным методом макета: список, использующий макет «flex-column», является вертикальным, а список, использующий макет «flex-row», — горизонтальным.

## Свойства

### `scroll` <decl type="{ ScrollX: Number, ScrollY: Number, ScrollState: Number }" get Listen />

Значением свойства `scroll` является объект, содержащий следующие поля: `scrollX`, `scrollY` и `scrollState`. Свойства «scrollX» и «scrollY» представляют позиции горизонтальной и вертикальной прокрутки соответственно в пикселях; Свойство `scrollState` представляет состояние прокрутки, и его значение равно $0$, $1$ или $2$. Конкретное значение показано в следующей таблице. Изменения атрибута `scroll` можно отслеживать с помощью директивы `on`. Любое изменение положения контента, вызванное действиями пользователя и операциями API, приведет к запуску мониторинга.

| значение `scrollState` | Описание эффекта |
| :--------------: | ------------------------------------------------------------------------------- |
| $0$ | Перестал скользить |
| $1$ | Пролистывание жестами пользователя |
| $2$ | Пользователь отпустил руку, скольжение вызвано вызовами таких методов, как [`scrollTo`](#scrollto) или inertia |

### `scrollTop` <decl type="number" get Listen />

Позиция вертикальной прокрутки, то есть расстояние от верхней части содержимого компонента swiper до верхней части области просмотра в пикселях. С помощью этого свойства можно отслеживать изменения положения прокрутки. В отличие от свойства [`scroll`](#scroll), прослушивание самого свойства `scrollTop` не может отличить прокрутку жестами пользователя от прокрутки, вызванной вызовами API или инерцией.

### `scrollLeft` <decl type="number" get Listen />

Положение прокрутки в горизонтальном направлении, то есть расстояние от левой стороны содержимого компонента `swiper` до левой стороны области просмотра в пикселях. Вы можете использовать это свойство для отслеживания изменений положения прокрутки. В отличие от свойства [`scroll`](#scroll), прослушивание самого свойства `scrollLeft` не позволяет отличить прокрутку жестами пользователя от прокрутки, вызванной вызовами API или инерцией.

### `scrollWidth` <decl type="number" get Listen />

`swiper` Ширина области содержимого компонента. Ширина swiper в вертикальной компоновке равна ширине просмотра, а ширина swiper в горизонтальной компоновке равна сумме ширин всех элементов. Вы можете использовать это для отслеживания изменений ширины контента.

### `scrollHeight` <decl type="number" get Listen />

`swiper` Высота области содержимого компонента. Высота «swiper» в вертикальной компоновке равна высоте просмотра, а высота «swiper» в горизонтальной компоновке равна сумме высот всех элементов. Вы можете использовать это для отслеживания изменений высоты контента.

### `snapshot` <decl type="boolean" get set />

Когда атрибут snapshot включен, подкомпоненты swiper включают режим моментального снимка. Обратитесь к свойству [`snapshot`](scroll.md#snapshot) компонента `scroll`.

### `деформация` <decl type="string" set />

Установите эффект деформации подэлемента и используйте эффект деформации для достижения эффекта «рыбий глаз» и других эффектов. Встроенный эффект морфинга можно указать по имени (строке) или эффект морфинга можно определить с помощью функции JavaScript.

| Значение | Описание эффекта |
| :-: | :- |
| `'нет'` | Нет эффекта трансформации (по умолчанию). |
| `'исчезать'` | Эффект переключения масштаба Fade. Этот эффект подчеркивает «фокус» элементов в текущем окне просмотра и заставляет элементы за пределами окна просмотра отходить на второй план. Подробности смотрите в эффектах примеров в этом разделе. |
| `'рыбий глаз'` | Встроенный эффект «рыбий глаз», этот компонент свойства используется для компонента [`scroll`](scroll.md) вместо `swiper`. |
| функция | Укажите эффект деформации с помощью функции JavaScript. |

Эффект деформации должен быть постоянным и немодифицированным.

Если содержимое дочерних элементов `swiper` часто меняется, рекомендуется добавить к элементу атрибут [`quiescent`](/framework/generic/properties.md#quiescent) при использовании эффекта деформации, чтобы избежать обновления при переключении и повысить производительность. Вы можете обратиться к следующим примерам:

<glyphix id="comComponents-swiper-deformation" height="360" width="360" title="Эффект деформации элемента">

```html
<swiper деформация="индикатор исчезновения">
  <div for="x in 5" :quiescent="x != 0">
    <progress-arc занято :start-angle="0" :stop-angle="360" />
    <p>панель {{ x + 1 }}</p>
  </div>
</свайпер>
```

``` CSS
дел {
  цвет фона: #eee;
  выравнивание текста: по центру;
  поле: 10 пикселей;
  радиус границы: 24 пикселей;
  дисплей: гибкий;
  гибкое направление: столбец;
  оправдание-содержание: центр;
}

дуга прогресса {
  ширина: 30%;
  высота: 30%;
  нижняя граница: 5%;
}
```

</глификс>

У первого дочернего элемента в примере не включен атрибут «quiescent», поэтому он будет продолжать обновляться во время процесса переключения, в то время как другие элементы перестанут обновляться.

### `vertical` <decl type="boolean" set />

Установите, будет ли компонент swiper располагаться вертикально. Если по умолчанию установлено значение false, будет использоваться горизонтальная компоновка. В следующем примере демонстрируется эффект взаимодействия `swiper` при вертикальной компоновке (обратите внимание, что требуется вертикальная прокрутка, а горизонтальное скольжение не реагирует).

<glyphix id="comComponents-swiper-vertical" height="360" width="360" title="Вертикальная компоновка">

``` HTML
<swiper вертикальная деформация = индикатор «затухания»>
  <p for="x из 5">
    панель {{ x + 1 }}
    {{ х == 0 ? '(проведите пальцем вверх)' : x == 4 ? '(проведите пальцем вниз)' : '' }}
  </p>
</свайпер>
```

``` CSS
п {
  цвет фона: #eee;
  выравнивание текста: по центру;
  поле: 10 пикселей;
  радиус границы: 24 пикселей;
}
```

</глификс>

### `indicator` <decl type="boolean" get set />

Устанавливает, отображает ли компонент `swiper` индикатор точки. Положение отображения точечного индикатора определяется атрибутом «vertical»: точечный индикатор отображается в середине правой стороны, когда макет вертикальный, а точечный индикатор отображается в середине нижней части, когда макет горизонтальный. Для получения конкретных эффектов обратитесь к примерам атрибутов [`deformation`](#deformation) и [`vertical`](#vertical).

Обратитесь к [Свойства CSS индикатора точки](#Point Indicator-css-Properties), чтобы узнать, как настроить стиль отображения точечного индикатора.

### `pageLength` <decl type="number" set />

Установите размер или пропорции подстраницы. Если это процент, задайте размер подкомпонента в направлении скольжения (относительно самого компонента); если это другие числа, задайте размер подкомпонента в направлении скольжения.

### `index` <decl type="number" get set Listen />

Индекс отображаемого в данный момент подкомпонента. Если свойство index установлено, компонент будет прокручиваться до указанного подкомпонента посредством анимации. Изменения позиции можно отслеживать с помощью директивы on, а изменения индекса подкомпонента можно отслеживать с помощью атрибута index.

### `finalChanged` <decl type="bool" get set />

Установите, будет ли событие изменения [`index`](#index) запускаться только при остановке прокрутки. По умолчанию (то есть, значение FinalChanged равно false), всякий раз, когда свойство index компонента swiper изменяется из-за жестов прокрутки или по другим причинам, срабатывает его событие прослушивания. Однако это может легко привести к пропаданию кадров анимации или возникновению слишком частых и ненужных событий. Если установлен параметр FinalChanged, событие изменения индекса будет вызвано только при остановке прокрутки.

::: совет
При реализации таких эффектов, как точечные индикаторы, путем мониторинга атрибута index, рекомендуется установить для FinalChanged значение true, что позволит избежать пропадания кадров, вызванного обновлениями рендеринга, инициируемыми событиями, во время процесса скольжения.
:::

### `weakGesture` <decl type="'none' | 'start' | 'end' | 'edge'" get set />

Устанавливает обстоятельства, при которых компонент `swiper` будет использовать жесты прокрутки. По умолчанию `swiper` предотвращает всплывание жестов, на которые он реагирует, поэтому его родительский элемент не может принимать жесты, которые заставляют `swiper` прокручиваться. WeakGesture позволяет всплывать события жестов при перетаскивании в границы содержимого, позволяя родительскому элементу получать эти жесты.

| ценность | описание |
| :-------: | -------------------------------------------------- |
| `'нет'` | Не всплывайте соответствующее событие жеста.                     |
| `'старт'` | Всплывает соответствующее событие жеста после перетаскивания в начальную позицию содержимого.       |
| `'конец'` | Всплывает соответствующее событие жеста после перетаскивания в конец содержимого.       |
| `'край'` | Всплывает соответствующее событие жеста после перетаскивания в начало или конец содержимого. |

Если базовым элементом страницы является горизонтальный компонент «swiper», но вы хотите, чтобы смахивание вправо возвращало страницу, вы можете настроить его следующим образом:
``` HTML
<swiperweak-gesture="start"> ... </swiper>
```
Когда пользователь приближается к заголовку компонента «swiper» и продолжает скользить вправо, чтобы выйти со страницы.

### `bounces` <decl type="'none' | 'start' | 'end' | 'edge'" get set />

Установите, вызывать ли отскок после прокрутки «swiper» к границе с помощью жеста. Начальное значение этого свойства — «edge», что позволяет изменять начальную и конечную позиции. Свойство `bounces` `swiper` аналогично свойству [`bounces`](scroll.md#bounces) компонента [`scroll`](scroll.md). Дополнительные инструкции см. в соответствующей документации.

### `scrolled` <decl type="boolean" Listen />

Отслеживайте, находится ли компонент `swiper` в состоянии прокрутки, с помощью свойства `scrolled`. Если значение атрибута, вызванное событием, равно true, это означает прокрутку, в противном случае это означает, что прокрутка остановлена.

Как операции прокрутки, вызванные касанием пользователя, так и прокрутка свойства прокрутки вызовут событие прокрутки. При прекращении прокрутки значение параметра события `scrolled` равно `false`.

### `setIndex`
<метод decl><pre>
(варианты: {
  индекс: номер,
  поведение?: «мгновенный» | 'гладкий'
}): пустота
</pre></decl>

Перемещает область просмотра к дочернему компоненту, указанному index. Если это движение пересекает границу видового экрана, положение видового экрана останется на первом или последнем компоненте. Функции атрибута параметра `options`:
- `index`: индекс целевого подкомпонента, который нужно переместить, $0$ представляет первый подкомпонент.
- «Поведение»: использовать анимированный переход, когда он «гладкий», и немедленно перемещаться к указанной позиции дочернего компонента, когда «мгновенный» (значение по умолчанию).

### `scrollTo` <decl type="(position: Number): void" метод />

Прокрутите содержимое до указанной позиции. Направление прокрутки соответствует направлению макета компонента прокрутки.

Метод `scrollTo` игнорирует эффект адсорбции элемента.

## Спецификации CSS

### Свойства CSS индикатора точки

В этом разделе представлены свойства CSS, доступные после того, как компонент `swiper` включает атрибут [`indicator`](#indicator). Они используются для управления частью стиля отображения точечного индикатора. Точечный индикатор для «Swiper» всегда отображается в виде набора горизонтально или вертикально расположенных точек и может быть настроен только разработчиком.

#### `индикатор-цвет`

Определяет цвет индикатора невыделенной точки. Эффект следующий:

<glyphix id="comComponents-swiper-indicator-color" height="360" width="360" title="Цвет индикатора Swiper">

```html
<индикатор смахивания>
  <div for="x в 5">
    <p>панель {{ x + 1 }}</p>
  </div>
</свайпер>
```

``` CSS
дел {
  цвет фона: #eee;
  выравнивание текста: по центру;
  поле: 10 пикселей;
  радиус границы: 24 пикселей;
  дисплей: гибкий;
  гибкое направление: столбец;
  оправдание-содержание: центр;
}

свипер {
  цвет индикатора: #333;
  цвет выбранного индикатора: #ff60ff;
  нижний индикатор: 16 пикселей;
}
```

</глификс>

#### `индикатор-выбранный-цвет`

Определяет цвет индикатора выбранной точки. Для получения эффекта вы можете обратиться к примеру свойства [`indicator-color`](#indicator-color). Вы можете заметить, что точечный индикатор, соответствующий выбранной странице, отображает цвет, определенный этим свойством CSS.

#### `размер индикатора`

Определяет размер каждой точки индикатора в точечном индикаторе в пикселях. Значение по умолчанию — «10 пикселей». В следующем примере демонстрируется эффект установки размера точечного индикатора на «16 пикселей»:

<glyphix id="comComponents-swiper-indicator-size" height="360" width="360" title="Размер индикатора Swiper">

```html
<индикатор смахивания>
  <div for="x в 5">
    <p>панель {{ x + 1 }}</p>
  </div>
</свайпер>
```

``` CSS
дел {
  цвет фона: #eee;
  выравнивание текста: по центру;
  поле: 10 пикселей;
  радиус границы: 24 пикселей;
  дисплей: гибкий;
  гибкое направление: столбец;
  оправдание-содержание: центр;
}

свипер {
  цвет индикатора: #333;
  цвет выбранного индикатора: #ff60ff;
  нижний индикатор: 24 пикселя;
  размер индикатора: 16 пикселей;
}
```

</глификс>

#### `индикатор-верх`

Если «swiper» имеет [горизонтальное расположение](#vertical), используйте атрибут «indicator-top», чтобы указать расстояние точечного индикатора от вершины. По умолчанию индикатор точки будет отображаться внизу по центру, это свойство можно использовать для отображения его вверху:

<glyphix id="comComponents-swiper-indicator-top" height="360" width="360" title="Индикатор верхней точки">

```html
<индикатор смахивания>
  <div for="x в 5">
    <p>панель {{ x + 1 }}</p>
  </div>
</свайпер>
```

``` CSS
дел {
  цвет фона: #eee;
  выравнивание текста: по центру;
  поле: 10 пикселей;
  радиус границы: 24 пикселей;
  дисплей: гибкий;
  гибкое направление: столбец;
  оправдание-содержание: центр;
}

свипер {
  индикатор-верх: 16 пикселей;
}
```

</глификс>

::: предупреждение
Не устанавливайте «indicator-left», «indicator-top», «indicator-right» и «indicator-bottom» одновременно, иначе положение точечного индикатора будет непредсказуемым.
:::
