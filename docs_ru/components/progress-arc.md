
# дуга прогресса

Компонент Progress-arc используется для отображения кругового индикатора выполнения, который по умолчанию является элементом уровня блока.

## Свойства

### `max` <decl type="number" set />

Максимальное значение прогресса, атрибут [`value`](#value) не будет больше его.

### `min` <decl type="number" get setet />

Минимальное значение прогресса, атрибут [`value`](#value) не будет меньше него.

### `value` <decl type="number" get set Listen />

Установите значение прогресса. Коэффициент отображения прогресса зависит от соотношения атрибута `value` в диапазоне от `min` до `max`, а коэффициент отображения будет ограничен величиной $0\%\sim 100\%$. `value` Значение является целым числом. Если задано значение с плавающей запятой, будет усечена только целая часть.

### `busy` <decl type="boolean" get set />

Установите, находится ли компонент Progress-arc в состоянии занятости. В состоянии занятости вместо значения атрибута value будет отображаться анимация загрузки. В следующем примере показано, как использовать круговой индикатор выполнения для имитации анимации загрузки:

<glyphix id="comComponents-progress-arc-busy" height="100" width="300" title="Имитировать анимацию загрузки">

``` HTML
<progress-arc занят :startAngle="0" :stopAngle="360" />
```

</глификс>

В этом примере разница между начальным и конечным углом индикатора выполнения составляет $360^\circ$. В настоящее время типичный эффект анимации загрузки может отображаться через атрибут «busy».

::: совет
Пока индикатор выполнения имеет круглую форму, он будет отображать фиксированный эффект анимации занятости, а начальный и конечный углы не имеют никакого эффекта.
:::

### `startAngle` <decl type="number" get set />

Начальный угол дугообразного индикатора выполнения. Значение по умолчанию — 135 долларов США. Для получения дополнительной информации обратитесь к главе [Конфигурация угла] (#Конфигурация угла).

### `stopAngle` <decl type="number" get set />

Конечный угол дугообразного индикатора выполнения. Значение по умолчанию — 405 долларов США. Для получения дополнительной информации обратитесь к главе [Конфигурация угла] (#Конфигурация угла).

## Инструкция по применению

### Угловая конфигурация

В отличие от линейного [`progress`](progress.md), дугообразные или круглые индикаторы выполнения необходимо правильно настроить с помощью свойств `startAngle` и `stopAngle` для правильного отображения. Оба свойства используют угловые единицы. В экранной системе координат $0^\circ$ указывает на горизонтальное правое направление, то есть на $3$-часовое направление часов, и увеличивается по часовой стрелке, и наоборот уменьшается.

Отображение `прогресс-дуги` представляет собой линейную интерполяцию углового диапазона в соответствии с соотношением `value` в $[\texttt{min}, \texttt{max}]$. В частности, пользователь увидит выделенный угол прогресса, начиная с startAngle и заканчивая valueAngle:

$$
\begin{выровнено}
  k &= \frac{\texttt{value} - \texttt{min}}{\texttt{max}-\texttt{min}}\\
  \texttt{valueAngle} &= (1-k)\texttt{startAngle} + k\cdot\texttt{stopAngle}
\end{выровнено}
$$

Поэтому, если вы хотите отобразить полный круг кругового индикатора выполнения, вам необходимо сделать так, чтобы начальный и конечный углы отличались на $360^\circ$, даже если эти два угла визуально одинаковы. Альтернативно, начальный угол может быть больше конечного угла, что изменит направление прогресса на противоположное.

В приведенных ниже примерах показаны различные конфигурации углов в действии. Обратите внимание, что второй пример демонстрирует технику обратного отображения прогресса.

## Спецификации CSS

### Расчет размера

Размер отображения Progress-arc определяется его свойствами Width и Height. «progress-arc» будет занимать более короткую ось, а центр дугообразного индикатора выполнения будет центром элемента. По умолчанию размер Progress-arc может быть близок к одному символу, что приведет к очень странным эффектам отображения, поэтому обычно необходимо явно указывать ширину и высоту в CSS или использовать другие разумные стратегии компоновки.

::: совет
Лучше всего указать разумную ширину и высоту для компонента Progress-arc, иначе он может быть неразборчивым. Как минимум, также должно быть установлено свойство CSS «width», а стратегия компоновки компонента будет автоматически использовать соотношение сторон $1:1$.
:::

### Свойства CSS

Внешний вид компонента Progress-arc можно настроить с помощью CSS.

#### `ширина штриха`

Это свойство определяет ширину контура дуги компонента Progress-arc. Тип значения — [длина](/framework/render/style-and-layout.md#length), процентная единица не поддерживается.

::: совет
Если вы хотите, чтобы ширина отрисовки компонента Progress-arc была пропорциональна размеру шрифта, рекомендуется использовать единицу длины [`rem`](/framework/application/font-config.md#rem-font size unit), например `0.15rem`.
:::

#### `цвет`

Установите цвет «progress-arc», чтобы выделить индикатор выполнения. По умолчанию будет использоваться цвет системной темы.

#### `цвет фона`

Установите цвет фонового индикатора прогресса «progress-arc», который по умолчанию будет настроен в соответствии с темой системы.
