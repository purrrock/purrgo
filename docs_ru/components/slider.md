
# ползунок

Скользящий селектор, по умолчанию используется для элементов уровня блока.

## Свойства

### `value` <decl type="number" get set Listen />

Текущее значение, по умолчанию: $10$.

При установке свойства value изменится текущее значение компонента. Вы можете использовать команду `on` для отслеживания изменений текущего значения, которая будет срабатывать каждый раз при изменении текущего значения.

### `min` <decl type="number" set />

Минимальное значение, значение по умолчанию: $0$.

### `max` <decl type="number" set />

Максимальное значение, значение по умолчанию: 100 долларов США.

### `vertical` <decl type="boolean" set />

Если значение свойства «vertical» равно true, компонент «слайдер» будет отображаться вертикально, в противном случае — горизонтально. Значение по умолчанию — «ложь».

## Спецификации CSS

Разработчики могут настроить внешний вид компонента слайдера с помощью CSS.

### Расчет размера

Ширина и высота слайдера по умолчанию такие же, как размер шрифта элемента. Размер шрифта задается атрибутом [`font-size`](/framework/generic/styles.md#font-size) (он также может быть унаследован). Размер прогресса можно настроить с помощью свойств [`width`](/framework/generic/styles.md#width) и [`height`](/framework/generic/styles.md#height).

### Свойства CSS

Следующие свойства CSS могут быть полезны:
- [`background-color`](/framework/generic/styles.md#background-color) может управлять цветом фона `slider`;
- [`color`](/framework/generic/styles.md#color) может управлять цветом индикатора выполнения `slider`;
- [`border-radius`](/framework/generic/styles.md#border-radius) Вы можете установить `slider` на закруглённую границу, например, `50%` создаст полукруглую границу;

Другие свойства CSS могут оказаться полезными, например стиль границы с использованием свойства [`border`](/framework/generic/styles.md#border).

### Псевдоэлементы CSS

#### `значение`

Этот псевдоэлемент может определять только индикатор выполнения «слайдер», не содержащий стиля фоновой части. Например, вы можете установить угловой радиус фона полосы прокрутки и части индикатора выполнения отдельно, чтобы добиться эффекта, при котором внешняя граница будет иметь круглую границу, а индикатор выполнения — прямую границу.

``` CSS
ползунок {
  радиус границы: 50%; /* Закругленные углы фона полосы прокрутки */
}

слайдер::значение {
  граница-радиус: 0; /* Индикатор выполнения полосы прокрутки не имеет закругленных углов */
}
```

#### `большой палец` <экспериментальный/>

Псевдоэлемент «thumb» используется для определения стиля слайдера «slider». По умолчанию слайдер не содержит маркеров. Для отображения маркеров необходимо указать ширину и высоту элемента «thumb»:
``` CSS
слайдер::палец {
  ширина: 150%;
  высота: 150%;
  радиус границы: 50%;
}
```
«Ширина» и «высота» в процентах рассчитываются относительно размера самого элемента. Ширина и высота горизонтального слайдера рассчитываются в процентах на основе высоты CSS элемента, а ширина и высота ручки вертикального слайдера рассчитываются в процентах на основе атрибута ширины CSS элемента. Например, элемент CSS
``` CSS
ползунок {
  ширина: 200 пикселей;
  высота: 24 пикселей;
}
```
На данный момент ширина и высота ползунка, соответствующие приведенному выше слайдеру::thumb, равны $24\rm{px} \times 150\% = 36\rm{px}$. Процентный размер радиуса скругления ручки рассчитывается на основе собственного размера ручки. В этом примере расчетное значение радиуса скругления псевдоэлемента `thumb`, равного `50%`, составляет $36\rm{px} \times 50\%=18\rm{px}$.

Псевдоэлемент «thumb» поддерживает свойство CSS «border», но граница не будет превышать размеры псевдоэлемента «thumb».

### Пример CSS

В следующем примере показаны некоторые способы настройки внешнего вида индикатора выполнения с помощью CSS.
<glyphix id="comComponents-slider-styles" height="180" width="480" title="Стили слайдера">

``` HTML
<дел>
  <!--Стиль по умолчанию -->
  <слайдер ::value="значение" />
  <!-- Прямой стиль индикатора выполнения -->
  <слайдер class="плоский" ::value="value" />
  <slider class="more-style" ::value="value" />
  <p>значение: {{value}}</p>
</div>
```

``` CSS
div > * {
  поле: 8 пикселей;
  отступ: 6 пикселей;
}

.квартира::значение {
  /* Установите угловой радиус псевдоэлемента value равным 0, чтобы добиться эффекта прямой головки индикатора выполнения */
  граница-радиус: 0;
}

.more-стиль {
  /* Настраиваем радиус угла */
  радиус границы: 30%;
  /* цвет фона слайдера */
  цвет фона: #b3c5d7;
  /* цвет переднего плана ползунка */
  цвет: #b5179e;
  /* отступы могут регулировать границу переднего плана ползунка */
  отступ: 6 пикселей;
  высота: 1рем;
}

/* Определить стиль ползунка полосы прокрутки */
.more-style::thumb {
  ширина: 300%; /* Капсульный слайдер с соотношением сторон 2:1 */
  высота: 150%;
  цвет фона: белый;
  граница: сплошная 4 пикселя #f3722c; /* Граница ползунка */
  радиус границы: 50%;
}
```

``` js
экспортировать по умолчанию {
  данные: { значение: 50 }
}
```
