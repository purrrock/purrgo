
# складной заголовок

Компонент «collapsible-header» используется для добавления сворачиваемой строки заголовка в список прокрутки. Этот эффект используется для создания интерактивного эффекта, который сохраняет область просмотра для устройств типа часов и улучшает взаимодействие с пользователем.

::: предупреждение
<experimental /> Это экспериментальный компонент, не используйте его способами, не описанными в этом документе.
:::

## Свойства

Этот компонент поддерживает [общие свойства](/framework/generic/properties.md) и не имеет специальных свойств.

## Как использовать

В компоненте `collapsible-header` должно быть два подкомпонента, иначе могут возникнуть неожиданные эффекты. Конкретные примеры заключаются в следующем:

```html
<складной-заголовок>
  <p>Это сворачиваемый заголовок</p>
  <прокрутка> ... </прокрутка>
</collapsible-header>
```

Первый дочерний элемент — это сворачиваемый заголовок, а второй элемент должен быть контейнером с возможностью прокрутки, например [`scroll`](/comComponents/scroll.md). Вот конкретный пример:

<glyphix id="comComponents-collapsible-header-1" height="360" width="360" title="Складной заголовок">

```html
<складной-заголовок>
  <p class="title-bar" on:click="clickTitle">ПАНЕЛЬ ЗАГОЛОВКА</p>
  <scroll Scroll-snap="center" деформация="рыбий глаз">
    <p for="x in 20" class="item">элемент {{ x + 1 }}</p>
  </прокрутка>
</collapsible-header>
```

```js
импортировать приглашение из «@system.prompt»;

экспортировать по умолчанию {
  нажмитеTitle() {
    Prompt.showToast({ message: "заголовок нажат" });
  }
}
```

``` CSS
.title-бар {
  поле: 56 пикселей авто авто;
  прозрачный: правда;
  размер шрифта: 1,5рем;
}

.item {
  высота: 33,3%;
  цвет фона: #ddd;
  радиус границы: 20%;
  поле: 8 пикселей;
  прозрачный: правда;
  отступ: 12 пикселей;
  выравнивание текста: по центру;
}
```

### Описание принципа

`collapsible-header` принимает два дочерних компонента, первый из которых представляет собой сворачиваемую строку заголовка, а второй должен быть прокручиваемым компонентом, аналогичным `scroll`. `collapsible-header` объединяет эти два компонента и управляет отображением сворачиваемой панели заголовка при прокрутке списка.

Вы можете использовать что-то вроде Fluid Layout для управления положением строки заголовка, например:

``` CSS
/* Верхний интервал элемента составляет 48 пикселей, по центру слева и справа, подходит для круглых экранов. */
поле: 48 пикселей авто авто;
/* Расстояние между левой и верхней частью элемента составляет 12 пикселей, что подходит для квадратных экранов. */
поле: 12 пикселей авто авто 12 пикселей;
```

Установите приведенный выше стиль для элемента строки заголовка в соответствии с фактическими потребностями для достижения определенного эффекта выравнивания. Вы также можете использовать сложный компонент, содержащий дочерние элементы, в качестве строки заголовка, например, используя компонент, содержащий кнопку «Назад» и текст заголовка страницы. Но имейте в виду, что при щелчке по строке заголовка событие щелчка может быть отправлено как в список прокрутки, так и в строку заголовка. Если возник конфликт, его можно разрешить, предотвратив всплытие события.

### Примечания

Вы должны предоставить два подкомпонента для `collapsible-header`, как указано выше, и в правильном порядке. Кроме того, поскольку сворачиваемая строка заголовка и лежащий в ее основе список прокрутки отображаются в виде стопок, это может привести к перекрытию первого элемента списка со строкой заголовка. При необходимости разработчикам следует рассмотреть возможность использования какого-либо метода-заполнителя, чтобы избежать перекрытия, а центрированный [режим привязки](/comComponents/scroll.md#scrollsnap) (`scroll-snap="center"`) `scroll` также позволяет избежать перекрытия.
