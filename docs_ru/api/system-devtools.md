
#Отладка интерфейса

## Модуль импорта``` js
импортировать инструменты разработчика из @system.devtools
```## API

### `command` <decl type="(cmd: string, fn: (argv: string[]) => void): void" метод />

Зарегистрируйте функцию fn, выполнив команду с именем cmd. используйте команду `dev` на терминале устройства для его вызова.``` баш
dev cmd arg1 arg2
```Команда с именем cmd вызывается со списком аргументов `['arg1', 'arg2']`.
