
#Хранение данных

Модуль хранения данных system.storage Позволяет приложению хранить свои собственные данные. будут сохранены в объекте хранения приложений. хранящиеся в system.storage, будут удалены.

`system.storage` в видеопаре ключ-значение, где ключ должен быть строкой, значение — значением JSON (или значением JavaScript, которое можно сериализовать в JSON).

## Модуль импорта``` js
импортировать хранилище из @system.storage
```## API

### `get` <decl type="(key: string): любой" метод />

Получите значение, предоставив имя ключа `key` в хранилище. Возвращает неопределенное значение, если пара ключ-значение не существует.

### `set` <decl type="(ключ: строка, значение: любое): void" метод />

Этот метод принимает имя ключа «ключ» и значение «значение» в качестве параметров и добавляет эту пару ключ-значение в хранилище. значение.

### `delete` <decl type="(key: string): boolean" метод />

Удалите пару ключей-значений, соответствующих имени ключа `key`, в хранилище. Возвращает true, если пара-значение существует и успешно удалена.

### `clear` <decl type="(): void" метод />

Очистите все сохраненные данные в приложении.
