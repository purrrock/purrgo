
# Модуль Bluetooth сэкономит энергопотребление

Этот модуль обеспечивает возможности Bluetooth на основе технологии Bluetooth Low Energy (BLE), поддерживает инициацию ГАТТ (GATT) в настоящее время осуществляется только создание GattClient, а создание GattServer на данный момент не осуществляется).

::: предупреждение
Большинство API в `@system.bluetooth.ble` имеют синхронный доступ к вводу-выводу. Обещание и асинхронность/ожидание.
:::

импортировать ble из @system.bluetooth.ble
```## Разрешения

## определение интерфейса

### `РезультатКод`

Обещание

- `0`: успех;
- `1`: Bluetooth Low Energy не включен;
- `2`: ошибка параметра;
- `3`: не удалось включить Bluetooth с экономией энергопотребления;
- `4`: адаптер Bluetooth недоступен;
- `5`: соединение не удалось;
- `6`: Не удалось отключиться;
- `7`: установка этого атрибута пока не запланирована;
- `8`: неизвестная ошибка;

::: предупреждение
Поскольку базовый адаптер Bluetooth является одноэлементным, несколько приложений могут одновременно работать с устройствами Bluetooth. В течение определенного периода времени приложение B начинает сканирование снова. Результаты результата, отслеживаемые приложением Б, являются неполными. Рекомендуется, чтобы это решение запрашивало результаты в автоматическом режиме.
:::
