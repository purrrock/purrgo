
#Состояние батареи

## Модуль импорта``` js
импортировать батарею из @system.battery
```## API

### `getStatus` <decl type="(): Promise<{charge: ChargeState, level: number}>" метод />

Получите состояние зарядки аккумулятора (тип [`ChargeState`](#chargestate)) и значение уровня `level`. Значение степени представляет собой соединение числа между $[0, 100]$.

## Тип

### `Состояние заряда`

«ChargeState» Состояние заряда:``` тс
тип ChargeState = 'зарядка' | 'разрядка' | «не заряжается» | 'полный'
```Значение каждого значения следующее:
- «зарядка»: аккумулятор находится в состоянии зарядки;
- «разрядка»: отключить состояние зарядки;
- `'не заряжается'`: не в состоянии зарядки;
- `'full'`: аккумулятор полностью заряжен.
