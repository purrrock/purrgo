
#Управление яркостью

## Модуль импорта``` js
импортировать яркость из @system.brightness
```## API

### `getValue` <decl type="(): Number" метод />

Получите значение яркости экрана, диапазон $[0, 1]$.

### `setValue` <decl type="(значение: число): void" метод />

Установите значение яркости экрана. Диапазон оценок — $[0, 1]$.

### `getMode` <decl type="(): string" метод />

Включите режим экрана.

### `setMode` <decl type="(mode: Number): void" метод />

Установите режим яркости экрана. стандартный режим.

### `setKeepScreenOn` <decl type="(mode: Boolean): void" метод />

Установите, будет ли экран всегда включен. всегда включено.

### `wakeScreenOn`
<метод объявления><pre>
(варианты: {
  screenOn: логическое значение,
  тайм-аут?: число,
}): пустота
</pre></decl>

Включите или выключите экран.
- `screenOn`: включить подсветку экрана
- `timeout`: ограниченное время тушения, без ограничения по времени, если не заполнено.
