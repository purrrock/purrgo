
#Уведомление о сообщении

## Модуль импорта``` js
уведомление об импорте из @system.notification
```Watch.permission.NOTIFICATION` в файле [`manifest.json`](/framework/application/manifest.md#permissions).

## API

### `опубликовать`
<метод объявления><pre>
(варианты: {
  значок: строка,
  идентификатор?: номер,
  тип содержимого: число,
  содержание: объект,
  Время доставки: номер,
  actionUri: строка
}): пустота
</pre></decl>

Опубликовать!
- `icon`: URI значка сообщения;
- `id`: уникальные идентификаторы уведомлений приложения;
- `contentType`: тип текста. с изображениями временно не происходит;
- «content»: используется вместе с «contentType» для отображения текстового дополнения;
  - Когда `contentType` равен 1, он представляет собой традиционный традиционный текстовый уведомления; тип объекта включая следующие поля:
    - `title`: заголовок обычного текстового уведомления; строковый тип;
    - `текст`: содержание обычного текстового уведомления; строковый тип;
- `deliveryTime`: время отправки уведомлений;
- `actionUri`: URI, к которому можно перейти при появлении на сцене.

### `удалить`
<метод объявления><pre>
(варианты: {
  запрос: {
    идентификатор?:номер
  }
}): пустота
</pre></decl>

Очистить.
-: запрос уточнения условий запроса,
  - id: устойчивый. переданы, все уведомления о сообщениях будут удалены.
