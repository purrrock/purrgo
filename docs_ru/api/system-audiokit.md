
#Менеджер аудиоплеера

## Модуль импорта``` тс
импортировать аудиокит из @system.audiokit
```##Определение интерфейса

### `getPlayers` метод <decl type="(): AudioPlayer" />

Запросить список объектов аудиоплеера [`AudioPlayer`](#AudioPlayer), доступных в системе.

### `getActivePlayer` <decl type="(): AudioPlayer" метод />

Запросите активный объект аудиоплеера [`AudioPlayer`](#AudioPlayer) в системе.

### `subscribe` <decl type="(callback: (PlayerEvent) => void): Number" метод/>

Прочитайте изменения в аудиоплеерной системе. [уведомления о событии](#PlayerEvent). для отказа от подписки с помощью метода [`unsubscribe()`](#unsubscribe).

Введите подпись PlayerEvent:``` тс
введите PlayerEvent = {
  уведомить: строка; // Изменяем тип события
  игрок: строка; // Изменяем имя игрока
}
```Изменить тип мероприятия

- `active`: текущий активный игрок в системе изменился.
- `append`: Игрок добавляется в систему.
- `удалить`: Игрок был удален из системы.

### `unsubscribe` <decl type="(subscribeID: Number): void" метод/>

Отменить мониторинг смены игроков. `subscribeID` — это значение идентификатора, возвращаемого методом [`subscribe()`](#subscribe).

В то же время объект audiokit.Player имеет больше функций, чем объект media.Player, такие как next(), previous() и другие методы. выполняются объектом `audiokit.Player`, а также будут уведомлены объектом `media.Player слушателя`.

### `src` <decl type="string" set get />

Укажите или прочитайте URL-адрес, по которому необходимо воспроизвести звук. локальному ресурсу] (/framework/application/resource.md#uri-and path) и путь к сетевому ресурсу с использованием протоколов http и https (например: https://www.rt-thread.com/service/test/001.mp3`). текст:``` тс

```### `name` <decl type="string" set get />

Имя объекта. создавший проигрыватель. Соответствие, и это имя не может использоваться для идентификации объекта игрока.

### `icon` <decl type="string" set get />

### `mode` <decl type="string" set get />

режим переключения. приложением проигрывателя. только этот атрибут.

### `status` <decl type="string" get />

Прочитайте текущий статус протокола

- `play`: статус прохождения

- `стоп`: статус остановки остановки.
- `закончено`: статус завершения вывода.
- `ошибка`: статус ошибки перевода.

### `songAttribute` <decl type="songAttribute" set get />

### `play` <decl type="(): void" метод />

Начать звук звука, указанный в атрибуте src.

— если атрибут src не установлен перед вызовом этого метода, результат завершается неудачей и будет вызвано событие onerror;
— Этот метод представляет собой синхронный интерфейс. нужно дождаться событий в игре или событий при ошибке, чтобы определить, было ли завершение успешным или неудачным. обойтися;

Играть():``` тс
импортировать аудиокит из @system.audiokit
//Опрос активных аудиоплееров в системе
пусть player = audiokit.getActivePlayer()
если (игрок != ноль) {
  //Сначала останавливаем воспроизводимый в данный момент звук
  игрок.стоп()
  //Установим URL-адрес аудио для воспроизведения
  player.src = 'https://www.rt-thread.com/service/test/001.mp3'
  //Устанавливаем событие onplay
  player.onplay = () => { console.dir("Начать играть") }
  //Устанавливаем событие ошибки
  player.onerror = () => { console.dir("Ошибка воспроизведения") }
  // Начинаем воспроизведение аудио
  игрок.играть()
}
```### `pause` <decl type="(): void" метод />

Приостановить текущий звук

— Этот метод представляет собой синхронный интерфейс. нужно дождаться событий onpause или onerror, чтобы определить, была ли пауза успешной или неудачной. До того, как событие произойдет, другие операции будут выполняться;

### `requestFocus` <decl type="({acquireType: string, VolumeType: string}): void" метод />

Запросить аудиофокус. Требуется запрос или прекращение фокусировки звука, базовый уровень будет управлять логикой переключения и прерывания различных типов звука.

ПараметрacquireType указывает тип запроса:
- `gain`: запросить фокус звука.
- `потеря`: отпустить аудиофокус.

Параметр VolumeType указывает тип звука:
- `система`: системная подсказка
- `медиа`: медиа-музыка
- `tts`: голосовая трансляция

В следующем примере показано, как функция requestFocus запрашивает фокус звука:``` тс
импортировать аудиокит из @system.audiokit
//Опрос активных аудиоплееров в системе
пусть player = audiokit.getActivePlayer()
если (игрок != ноль) {
  // Получаем аудио-фокус типа медиа-музыки
  player.requestFocus({volumeType: 'media',acquireType: 'gain' });
}
```### `releaseFocus` <decl type="(): void" метод />

Отпустите аудиофокус. При возникновении фокуса звука нижний уровень будет управлять логикой переключения и включения различных типов звука.

### `onstop` <decl type="?: () => void" set />

### `onended` <decl type="?: () => void" set />

Событие обратного вызова после проведения прослушивания звука

### `onerror` <decl type="?: () => void" set />

Выполняете события обратного вызова для ошибок интерфейса, таких как «воспроизведение», «пауза», «стоп», «позиция» и других интерфейсов. события onplay и другие события не будут активированы.

### `ontimeupdate` <decl type="?: () => void" set />

Событие обратного вызова, который будет вызван при обновлении свойств позиции. будет вызвано только тогда, когда приложение находится на переднем плане, и перестанет отправляться, когда приложение находится в фоновом режиме.

### `oninterrupt` <decl type="?: (action: {interruptHint: Number}) => void" set />

Функция обратного вызова при реагировании на события прерывания звука. захватывает звук того же типа звука или звука другого типа, он будет уведомлен о том, что он временно отключается или полностью отключается.

Параметр InterruptHint action указывает тип события прерывания:
- `1`: последовательное прерывание (может автоматически восстанавливаться музыка, например: прерывается)
- `2`: полностью прервано (невозможно автоматически восстановить, например: NetEase Cloud прервано Himalaya).

В следующем примере показано, как зарегистрировать функцию обратного вызова по прерыванию, которая возникает при возникновении событий:``` js
player.oninterrupt = (действие) => {
  console.log(action.interruptHint)
}
