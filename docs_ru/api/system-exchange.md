
#Обмен данными

Модуль обмена данными system.exchange для хранения общих данных между приложениями. Эти данные не сохраняются постоянно и будут потеряны после отключения устройства. . По данным приложения System.exchange, оно не подходит для хранения конфиденциальных данных.

`system.exchange` значением JSON (или значением JavaScript, которое можно сериализовать в JSON).

## Модуль импорта``` js
импортировать обмен из '@system.exchange'
```## API

### `get` <decl type="(key: string): любой" метод />

Получите значение, предоставив имя ключа `key` в хранилище. Возвращает неопределенное значение, если пара ключ-значение не существует.

### `set` <decl type="(ключ: строка, значение: любое): void" метод />

Этот метод принимает имя ключа «ключ» и значение «значение» в качестве параметров и добавляет эту пару ключ-значение в хранилище. значение.

### `delete` <decl type="(key: string): boolean" метод />

Удалите пару ключей-значений, соответствующих имени ключа `key`, в хранилище. Возвращает true, если пара-значение существует и успешно удалена.

### `watch` <decl type="(key: string, callback: (value: Any) => void): Number" />

Отслеживайте изменения значений данных ключа с ключом имени в базе и вызывайте функцию обратного вызова обратного вызова при предоставлении значения. новое значение данных. метод [`unwatch()`](#unwatch) для продолжения наблюдения.

::: совет
Если мониторинг больше не нужен, для разблокировки Диптихов следует использовать метод [`unwatch()`](#unwatch), иначе может возникнуть утечка памяти.
:::

### `unwatch` <decl type="(watcherID: Number): void" метод />

Замените прослушивание ключа на имя «key» в хранилище. возвращаемый, когда метод [`watch()`](#watch) создает наблюдателя.
