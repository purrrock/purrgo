
# Тестовая среда

## Модуль импорта``` js
импортировать тест из @system.test
```## Введение

system.test — это среда комплексного тестирования, которая может имитировать действия пользователя с помощью программирования и проверки, соответствует алгоритмическому поведению интерфейса.

Простой код для имитации операций выглядит следующим образом:``` js
ждут test.getByClass('кнопка воспроизведения').click()
дождитесь test.getByClass('more-button').click()
дождитесь test.getByClass('кнопка загрузки').click()
ждут test.getByClass('кнопка закрытия').click()
дождитесь test.getByClass('кнопка меню').click()
await test.getHasText('Список загрузки').click()
await test.getByTag('Scroll').scroll(0, -200, 0.3)
дождитесь test.getHasText(/[a-z]/).click()
```Этот код будет автоматически отображать элементы интерфейса, используя такие жесты, как щелчок или прокрутка по ним.

## API

### Вспомогательные функции

Эти функции предоставляют вспомогательные функции при тестировании, такие как задержка и т. д. д.

#### `wait` <decl метод type="(duration: Number): Promise<void>" />

Время, указанное асинхронной задержкой, используется для ожидания определенных операций при тестировании или для имитации ожидания паузы.

### Локатор

Локатор находит элементы (собственные компоненты) на странице верхних уровней приложения, например, на основе тега или идентификатора элемента. в локаторах обратиться к [объекту `Локатор`](#locator-object).

#### `getByTag` <decl метод type="(тег: строка): Локатор" />

Найдите элементы с помощью тега. верблюжим регистре, как такие «P», «Swiper» и т. д. д.

#### `getByClass` <decl метод type="(class: string): Locator" />

Найдите элементы с помощью атрибута класса.

#### `getById` <decl метод type="(id: string): Locator" />

Найдите элементы с помощью атрибута `id`.

#### `getHasText` <decl метод type="(text: RegExp | string): <Locator>" />

Поиск элементов по этому параметру соответствует их атрибуту text параметру text. Параметр `text` представляет собой обычное выражение, например:
- `/hello/`, наконец, содержит ли значение атрибута `'text' представляет собой элемент `'hello'';
- `/^hello/` вначале начинается значение атрибута `'text` элемента с `'hello'';
- `/^hello$/`, следовательно, является значением атрибута `'text` элемента `'hello'`.

Правила рассмотрения для параметра `text` такие же, как и у [`RegExp.test()`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/RegExp/test).

### Объект `Локатор`

Объекты «Локатор» возвращаются API-интерфейсом локатора и могут использоваться для текущих операций. переместить его в поле зрения.

#### `click` <decl метод type="(): Promise<void>" />

Когда элемент существует и прокручивается в видимой области, подражайте жесту учителя в положении элемента.

#### `scroll` <decl метод type="(dx: число, dy: число, продолжительность?: число): Promise<void>" />

Когда элемент существует и был прокручен в видимой области, имитируйте жест прокрутки в позиции элемента. `dy` и `dy` — это смещение $(x, y)$ прокрутки в пикселях; необязательная `duration` — это продолжительность жеста в секундах, значение по умолчанию — $0,5\rm s$.

Этот метод будет ждать, пока атрибут элемента `scrolled` станет `false`, прежде чем заполнять возвращаемый объект Promise. Не будет запускать данную операцию до тех пор, пока инерционная анимация этих компонентов не остановится.

#### `wait` <decl метод type="(): Promise<void>" />

Ожидает появления элемента и его прокрутки в поле зрения, но не имитирует какие-либо жесты или другие операции.
