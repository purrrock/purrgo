##Определение интерфейса

### `подписатьсяАкселерометр`
<метод объявления><pre>
(варианты: {
  интервал?: 'игра' | 'пользовательский интерфейс' | 'нормальный',
  обратный вызов: (данные: AccelerometerValue) => void,
}): число
</pre></decl>

Отслеживайте данные датчика ускорения.
- `интервал`: частота прослушивания, по умолчанию "нормальная", дополнительные значения следующих.
  - «игра»: игровой режим, частота 20 мс/раз;
  - `'ui'`: режим пользовательского интерфейса, частота 60 мс/раз;
  - «нормальный»: нормальный режим, частота 200 мс/раз.
- `callback`: AccelerometerValue выглядит следующим образом:``` тс
  тип AccelerometerValue = {
    x: число // ускорение по оси X
    y: число // ускорение по оси Y
    z: число // ускорение по оси Z
  }
  ```Пример:```js
const id = Sensor.subscribeAccelerometer({
  интервал: «нормальный»,
  обратный вызов (рет) {
    console.log(`данные гироскопа, x = ${ret.x}, y = ${ret.y}, z = ${ret.z}`)
  }
})

//Отменяем прослушивание
Sensor.unsubscribeАкселерометр (id)
```### `unsubscribeAccelerometer` <decl type="(id: Number): void" метод/>

Отменить мониторинг данных датчика ускорения. возвращаемый метод [`subscribeAccelerometer`](#subscribeaccelerometer).

### `подписатьсяКомпас`
<метод объявления><pre>
(варианты: {
  обратный вызов: (данные: CompassValue) => void,
}): число
</pre></decl>

Отслеживайте изменения данных компаса. прослушивание, которое используется для прекращения прослушивания. `опции`:
- `обратный вызов`: обратный вызов изменения данных компаса.

Подпись `CompassValue`:``` тс
  введите CompassValue = {
    направление: число // Угол между осью Y и северным магнитным полюсом (радианы)
    точность: число // точность
  }
```- `направление`: угол в радианах между осью Y устройства и северным магнитным полюсом Земли, диапазон колебаний: $(-\pi,\pi]$, где:
  - `0`: строго на север.
  - $\pi$`/2` (приблизительно 1,57): направление на восток.
  - $\pi$ (около 3,14): в южном направлении.
  - -$\pi$`/2` (приблизительно -1,57): строго на запад.
- `точность`: уровень точности данных компаса.
  - `3`: высокая точность
  - `2`: средняя точность
  - `1`: достоверность
  - `0`: Ненадежно (неизвестная причина).
  - `-1`: Ненадежно (датчик потерял связь)

Пример:```js
const id = Sensor.subscribeCompass({
  обратный вызов (рет) {
    console.log(`direction=${ret.direction}, точность=${ret.accuracy}`)
  }
})

//Отменяем прослушивание
Sensor.unsubscribeCompass(id)
```### `unsubscribeCompass`<decl type="(id: Number): void" метод/>

Изменить данные компаса мониторинга. возвращаемый метод [`subscribeCompass`](#subscribecompass).

### `калибровкаКомпас` <decl type="(): Promise<void>" метод/>

Запустите процесс компаса. активируйте и вызовите этот метод для стабилизации компаса.

Эта функция возвращает безрезультатный объект Promise, который будет разрешен, когда система завершит калибровку.

### `getCompassValue` <decl type="(): Promise<CompassValue>" метод/>

Получите текущие данные компаса. включить информацию о направлении и точности компаса.

## Ограничения на использование

Если текущее устройство не поддерживает возможности датчика, вызывающий интерфейс напрямую выдает напряжение, и мониторинг не влияет на силу.
Пример журнала информации об исключении: `устройство не поддерживает датчик акселерометра`

Пример сбора информации об исключении:```js
попробуй {
  const id = Sensor.subscribeCompass({
    обратный вызов (рет) {
      console.log(`direction=${ret.direction}, точность=${ret.accuracy}`)
    }
  })
} поймать (е) {
  console.error(электронное сообщение)
}
```## Примечания

Отмените подписку вовремя, если датчики данных не нужны. от подписки, когда страница уничтожения (обратный вызов onDestroy), чтобы избежать ненужной потери производительности и энергопотребления.
