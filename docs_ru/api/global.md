
# глобальный объект

## Глобальная функция

### `encodeURIComponent` <decl type="(str: string): string" function />

Глобальная функция encodeURIComponent() для кодирования URI компонента `str`. (`%`), закодированные в UTF-8, что определяет правильный компонент как часть URL-адреса, особенно в параметрах строки запроса, пути или фрагменте.

Буквы, цифры, `- _ . ! ~ * ' ( )` не будет закодировано. Другие символы кодируются как escape-по последовательности знаков валюты (например, пробелы кодируются как `%20`).

`encodeURIComponent()` ведет себя так же, как аналогичная функция в Web.

Пример:```js
console.log(encodeURIComponent("https://example.com/page?id=100"));
// вывод: https%3A%2F%2Fexample.com%2Fpage%3Fid%3D100
```### `decodeURIComponent` <decl type="(str: string): string" function />

Глобальная decodeURIComponent() используется для декодирования URI компонента `str`, закодированного с помощью `encodeURIComponent()`. формируют символы, тем самым сохраняя исходные компоненты URI. обратно в пробел.

`decodeURIComponent()` ведет себя так же, как аналогичная функция в Web.

Пример:```js
console.log(decodeURIComponent("https%3A%2F%2Fexample.com%2Fpage%3Fid%3D100"));
// вывод: https://example.com/page?id=100
```### `URI` <decl type="(uri: string | Uri): Uri" function />

Эта функция использует преобразование и анализирует его в объекте Uri для обработки обработки. — это строка URI, на которую необходимо обратить внимание.

Возвращаемое значение представляет собой объект с учетом полей:
- `scheme: string`: поле схемы, полученное из параметра;
- `authority: string`: поле подключения, полученное из параметра;
- `path:string`: поле пути, полученное из параметра;
- `query: string`: поле запроса, полученное из параметра;
- `origin: string`: исходная строка URI в параметре.
- `toString: (string`: этот метод может перекодировать этот объект в код URI.

Например:``` js
console.log(URI("https://имя-приложения/icon.png"))
// {
// схема: 'https',
// полномочия: 'имя-приложения',
// путь: '/icon.png',
// запрос: '',
// происхождение: 'https://имя-приложения/icon.png',
// toString: <функция>
// }
```Функция `URI` также принимает объект в качестве параметра. параметр объекта методом toString, с помощью которого URI объекта можно закодировать в тексте:``` js
