### `requestFocus` <decl type="({acquireType: string, VolumeType: string}): void" метод />

Запросить аудиофокус. Требуется запрос или прекращение фокусировки звука, базовый уровень будет управлять логикой переключения и прерывания различных типов звука.

ПараметрacquireType указывает тип запроса:
- `gain`: запросить фокус звука.
- `потеря`: отпустить аудиофокус.

Параметр VolumeType указывает тип звука:
- `система`: системная подсказка
- `медиа`: медиа-музыка
- `tts`: голосовая трансляция

В следующем примере показано, как функция requestFocus запрашивает фокус звука:``` тс
импортировать медиа из «@system.media»

пусть player = media.createAudioPlayer()
// Получаем аудио-фокус типа медиа-музыки

```### `releaseFocus` <decl type="(): void" метод />

## Объект `AudioRecorder`

::: подробности тип подпись``` тс
интерфейс AudioRecorder {
    начать({
      ури: строка,
      образец?: 8000 | 16000 | 44100 | 48000,
      планировка?: 8 | 16 | 32,
      канал?: 1 | 2,
      битрейт?: 16 | 32 | 64,
      кодек?: «pcm» | "mp3" | "опус" | «шелк»,
      формат?: "ogg",
    }): Обещание<void>,
    read({callback: (ArrayBuffer) => void}): void,
    стоп(): пустота,
    выпуск(): пустота,
    onstart?: () => void,
    onstop?: () => void,
    при выпуске?: () => void,
    onavailable?: (ArrayBuffer) => void,
    onerror?: ({error: string})=> void
}
```:::

### `старт`
<метод объявления><pre>
(варианты: {
  ури: строка,
  образец?: 8000 | 16000 | 44100 | 48000,
  планировка?: 8 | 16 | 32,
  канал?: 1 | 2,
  битрейт?: 16 | 32 | 64,
  кодек?: «pcm» | "mp3" | "опус" | «шелк»,
  формат?: "ogg",
}): Обещание&lt;void>
</pre></decl>

прекратить запись звука. каждое поле параметра `options`:
- `uri`: URI файлов записей, которые необходимо сохранить, поддерживает только `внутренний` протокол, и каталог будет создан автоматически;
- `выборка`: частота видеосъемки звука, единица измерения — $\rm Гц$, по умолчанию — $8000$;
- `макет`: разрядность аудиоданных, по умолчанию $16$;
- `канал`: количество аудиоканалов, по умолчанию $1$;
- `битрейт`: битрейт аудио, единица измерения: $\rm кбит/с$, значение по умолчанию — $16$. битрейт, тем лучше качество звука, но тем больше размер файла.
- `кодек`: формат кодирования звука, тип строк, если не заполнено, автоматически подбирается соответствующий код согласно параметру `формат`;
- «формат»: формат инкапсуляции аудио, тип строки, если не заполнено, подходящая инкапсуляция будет автоматически выбрана на основе суффиксного имени параметра «uri»;

Отношения поддерживают часто используемые форматы записей, кодирования форматов и инкапсуляции следующих форматов (нет в таблице означает, что соответствующие параметры не нужно заполнять):

  | кодек (кодирование форматирования) | формат (формат инкапсуляции) |
  | -------------- | --------------- | ------------- |
  | ПКМ | Нет | Нет |
  | mp3 | mp3 | нет |
  | опус | опус | нет |
  | опус-ogg | опус | огг |
  | шелк | шелк | нет |

Следующий пример кода, начинающего запись:``` js
пусть рекордер = media.createAudioRecord()
рекордер.start({
  URI: "внутренний://tmp/media_test.mp3",
  проба: 16000,
  планировка: 16,
  канал: 1,
  битрейт: 16
})
```:::информация
Для получения дополнительной информации о «внутреннем» протоколе URI обратитесь к документу [Доступ к ресурсам](/framework/application/resource.md).
:::

После завершения записи вызовите метод [stop()](#stop-1), чтобы завершить запись.
