
#Информация об устройстве

## Модуль импорта``` js
импортировать устройство из @system.device
```Watch.permission.DEVICE_INFO` в файле [`manifest.json`](/framework/application/manifest.md#permissions).

##Определение интерфейса

### `getInfo`
<метод объявления><pre>
(): Обещание<{
  бренд: строка,
  производитель: струна,
  модель: струна,
  продукт: строка,
  osType: строка,
  osVersionName: строка,
  имя_платформы: строка,
  PlatformVersionCode: номер,
  язык: строка,
  регион: строка,
  имя устройства: строка
}>
</pre></decl>

Получите основную информацию об устройстве. следующее:
- `бренд`: торговая марка устройства.
- «производитель»: Производитель оборудования.
- `модель`: модель устройства.
- `продукт`: кодовое имя устройства.
- `osType`: имя системы освещения.
- `osVersionName`: имя версии устройства системы.
- `platformVersionName`: имя версии рабочей платформы.
- `platformVersionCode`: номер версии текущей платформы.
- `язык`: системный язык.
- `регион`: системный регион.
- `deviceName`: имя устройства.

### `getId`
<метод объявления><pre>
(типы: ('устройство' | 'mac' | 'пользователь' | 'реклама')[])
: Обещание<{
  устройство?: строка,
  макинтош?: строка,
  пользователь?: строка,
  реклама?: строка
}>
</pre></decl>

Получайте конкретную информацию об устройстве в пакетном режиме. Параметр «типы» определяет этот объект «Массив», состоящий из элементов «устройство», «mac», «пользователь» или «реклама». Типы:
- `тип`: .
- `device`: уникальный идентификатор устройства, существует только в том случае, если `types` содержит элемент `'device''`.
- `mac`: MAC-адрес устройства, присутствует только в том случае, если `types` содержит элемент `'mac'`.
- `user`: уникальный идентификатор пользователя, существует только в том случае, если `types` содержит элемент `'user'`.
- `реклама`: уникальный идентификатор рекламы, присутствующий только в том случае, если `types` содержит элемент ``реклама''.

### `getDeviceId` <decl type="(): Promise<{deviceId: string}>" метод />

Получите уникальный идентификатор устройства.

### `getSerial` <decl type="(): Promise<{serial: string}>" метод />

Получите серийный номер устройства.

### `getTotalStorage` <decl type="(): Promise<{totalStorage: Number}>" метод />

Получите общий размер дискового пространства в байтах.

### `getAvailableStorage` <decl type="(): Promise<{availableStorage: Number}>" метод />

Получите доступный размер дискового пространства в байтах.

::: совет
Значения возвращаемых методов getTotalStorage() и getAvailableStorage() в эмуляторе могут быть неточными и не изменяться при сохранении объема памяти.
:::

### `screenWidth` <decl type="number" get />

Ширина экрана устройства в пикселях.

### `screenHeight` <decl type="number" get />

Высота экрана устройства в пикселях.

### `screenDensity` <decl type="number" get />

Плотность изображения экрана устройства в $\rm PPI$.

### `screenShape` <decl type="'rect' | 'circle'" get />

Форма экрана устройства. Смысл мыслей следующий:
- «прямой»: устройство имеет прямоугольный экран.
- «круг»: устройство имеет круглый экран.

### `memoryProfile` <decl type="number" get />

Получает свойства профиля памяти устройства. медиа-запроса [`memory-profile`](/framework/render/media-query.md#memory-profile). медиа-запроса.

с фиксированной единицей измерения $\rm KiB$.
