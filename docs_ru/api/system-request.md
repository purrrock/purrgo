
# Загрузить запрос на загрузку

## Модуль импорта``` js
запрос на импорт из @system.request
```## API

### `скачать`
<метод объявления><pre>
(варианты: {
  URL: строка,
  заголовок?: {[ключ: строка]: строка},
  имя файла?: строка,
  обратный вызов: (прогресс: число) => void
}): DownloadTask
</pre></decl>

Загрузка файлов по протоколу HTTP/HTTPS. каждое поле параметра `options`:
- `url`: URL-адрес веб-сайта, к которому осуществляется доступ;
- `header`: объект, каскадная информация заголовка HTTP-запроса, ключ и значение являются строками. Типичными полями заголовка HTTP могут быть `Authorization`, `Content-Type` и т. д. д.;
- `имя_файла`: URI: `internal://files/download.txt`;
- `обратный вызов`: Функция обратного вызова процесса загрузки. сохраняется несколько раз во время загрузки. `прогресс` — это значение прогресса загрузки в направлении $[0, 100]$.

Метод download() возвращает объект [`DownloadTask`](#downloadtask), который можно использовать для ожидания завершения загрузки или управления нагрузкой загрузки.

::: предупреждение
$100\%$ в функции обратного вызова в качестве условия запуска операции после завершения загрузки. Подробную информацию см. в разделе [Ожидание выполнения загрузки](#Ожидание выполнения загрузки).

Текущая продукция не анализирует автоматически атрибут параметра `filename` на основе `url`. обязательно заполняйте `имя файла`.
:::

## Тип

### `ЗагрузкаЗагрузки`

DownloadTask — это тип возвращаемого значения метода download, его подпись:``` тс
интерфейс DownloadTask {
  завершено: Promise<void>,
  отменить(): недействительно
}
```Свойство Complete — это объект Promise, который можно использовать для ожидания завершения загрузки. Метод `cancel()` используется для отмены текущей загрузки задачи. метод `cancel()` не имеет никакого эффекта.

#### Дождитесь завершения загрузки

Используйте DownloadTask.complete, чтобы дождаться загрузки. Когда «Обещание» будет завершено, оно будет достигнуто, что файл был преобразован, поэтому можно смело переходить к следующему шагу. запись файла завершена. интерфейс и другие потребности.

При фактическом использовании, если загрузка может завершиться неудачно, рекомендуется использовать оператор try...catch для обработки ошибок загрузки. Следующие примеры познакомят вас с использованием.
