
#Состояние сети

## Модуль импорта```js
импортировать сеть из @system.network;
```##Определение интерфейса

### `subscribe` <decl type="(callback: (status: NetworkState) => void): Number" метод/>

Отслеживайте изменения состояния сети. сеть](#networkstate). подписка с помощью метода [`unsubscribe()`](#unsubscribe).

### `unsubscribe` <decl type="(subscribeID: Number): void" метод/>

`subscribeID` — это значение идентификатора, возвращаемого методом [`subscribe()`](#subscribe).

### `getType` <decl type="(): Promise<NetworkState>" метод/>

Получите текущий статус сети и приведите значение [`NetworkState`](#networkstate).

##Определение типа

### `NetworkState`

Этот объект используется для отображения текущего состояния сети.``` тс
тип NetworkState = {
  устройство: строка; //Имя сетевого устройства
  тип: строка; // Тип сетевого устройства
  linkUp: логическое значение; // Было ли открыто сетевое устройство
  онлайн: логическое значение; // Находится ли устройство в сети (имеет ли оно доступ к Интернету)
};
```Обычно вы можете использовать свойство `online` `NetworkState`, чтобы проверить, может ли устройство получить доступ к Интернету.
