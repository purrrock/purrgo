### `push` <decl type="(options: {uri: string, params?: Object}): Promise<any>" метод />

Перейти на указанную страницу в приложении.
- `uri`: имя включить страницу, которую необходимо настроить в `mainfest.json`;
- `params`: данные, которые необходимо передать при переходе. Атрибут параметра params заменить значение атрибута data отключить страницу.

`push()` вывод из открытой страницы. Например:```js
const result = await router.push({ uri: 'PageName' })
console.log("страница 'PageName' была закрыта с результатом:", result)
```Где `result` — это возвращаемое значение страницы, указанное методом [`close()`](#close), который вы можете получить с помощью полученного метода.

Перейдите на указанную страницу в приложении и закройте текущую страницу. Описание атрибута параметра `options`:
- `uri`: имя включить страницу, которую необходимо настроить в `mainfest.json`;
- `params`: данные, которые необходимо передать при переходе. Атрибут параметра params заменить значение атрибута data отключить страницу.

Последовательно [`push()`](#push) и [`back()`](#back) вызов `replace()` всегда воспроизводит стандартную анимацию перехода страницы. В стадии рендеринга пользователь все равно может ненадолго увидеть текущий кадр страницы, прежде чем перейти на целевую страницу. пользовательского потока», а не как средство «тихого перенаправления» или «полного открытия страницы входа».

Если текущая страница открывается с помощью метода [`push()`](#push), поскольку метод `replace()` заменяет текущую страницу, это приводит к выполнению объекта Promise, возвращаемого методом [`push()`](#push).

#### Избегайте асинхронных операций

Если вы хотите перейти на страницу в функции обратного вызова операции жеста (например, жеста философа), вам следует повторить асинхронные операции, поскольку это не только легко приведет к активному окну страницы, но и увеличит задержку ответа на жест. Обратите внимание, что задержка некоторых асинхронных операций неконтролируема. онлайн-статус может занять много времени в слабой сетевой среде.

Поэтому в каналах, где переходы по страницам должны запускаться учеными, лучше всего передать возможный доступ к новой странице сети и представить статус остановки средствами анимации загрузки.

### Заменить страницу по умолчанию

[`router.entry`](/framework/application/manifest.md#entry) файл `manifest.json` при запуске. на конкретную страницу на основе конкретных параметров запроса вместо входа на страницу входа.

В дополнении к внутренним ссылкам приложениям часто необходимо выбирать различные домашние экраны в зависимости от локального причины во время холодного запуска, например, при поиске решений о входе на страницу входа или внутренней странице на основе причины входа в систему или при таких решениях о входе в конфиденциальность страницы или функциональной внутренней странице на основе локально сохраненной отметки соглашения о конфиденциальности. Создайте одну из этих страниц как `router.entry`, а затем перейдите внутри страницы с помощью [`router.replace()`](#replace), в некоторых случаях ненужная страница Google в течение короткого времени, и это будет выглядеть так, как если бы страница "мигает".

Для этого вам нужно всего лишь открыть страницу, которую вы действительно хотите отобразить, через [`router.push()`](#push) на этапе запуска приложения. [`onCreate()`](/framework/comComponent/life-cycle.md#oncreate) или [`onRoute()`](/framework/comComponent/life-cycle.md#onroute). на конфиденциальность страницы или домашнюю страницу:```js

### Перейти к интерфейсу начального экрана

Многие приложения при первом входе отображают начальную страницу с логотипом, а затем переходят на фактическую функциональную домашнюю страницу. такова: `router.entry` через [`router.replace()`](#replace) во время инициализации. сначала видит краткий начальный экран, а затем видит анимацию, переходящую с начальной страницы на другую. страницы.``` js
// Предположим, что это скрипт index.ux страницы логотипа
экспортировать по умолчанию {
  onInit() {
    // Переход на начальную страницу логотипа после некоторой задержки
    setTimeout(() => {
      router.replace({uri: 'MainPage'})
    }, 1000)
  },
}
```В рамках этой структуры страница логотипа сама по себе является частью дизайнерского продукта, поэтому руководство показывает, что пользователи ненадолго увидят логотип, а затем перейдут на внешнюю страницу. страница логотипа на домашней странице. «Англия» на экране, и его нельзя будет «тихо» пропустить.

Если пользователь приложения не создает отдельный логотип или начальную страницу, но по-прежнему использует метод «входная страница + переход `replace()`», например, настроит страницу соглашения о конфиденциальности как `router.entry` и переключится на домашнюю страницу через `replace()`, увидит, что страница входа «мигает» при холодном запуске приложения, а затем переключится на `MainPage` через анимацию перехода.
