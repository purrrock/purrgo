
# Консольный модуль

Функция модуля консоли аналогична функции консоли в браузере и используется для реализации логирования. Этот модуль можно использовать напрямую, без импорта. вариативная консоль, например:``` js
console.log('Привет, мир!')
```##Определение интерфейса

### `backtrace` <decl type="boolean" />

После установки значения параметра backtrace true все распечатки журнала будут сохранять информацию о console.warn() и API более высоких уровней, которые будут выводить стек вызовов.

### `log` <decl type="(...data: Any[]): void" метод />

### `dir` <decl type="(...data: Any[]): void" метод />

### `debug` <decl type="(...data: Any[]): void" метод />

### `info` <decl type="(...data: Any[]): void" метод />

### `warn` <decl type="(...data: Any[]): void" метод />

### `error` <decl type="(...data: Any[]): void" метод />

## Уровень фильтрации журналов

Уровень фильтрации журналов модуляции консоли определяется базовым механизмом фильтрации журналов JavaScript.
