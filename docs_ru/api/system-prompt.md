#### `showToast`

Toast — это вражеское текстовое окно, расположенное в верхней части интерфейса. уведомления. поворачивать и включать постоянно.

Описание поля параметра `options`:
- `сообщение`: воссоздан реалистичный текст.
- `duration`: продолжительность воспроизведения тоста в мс. время ожидания.
- «Важно»: независимо от того, является ли это обязательным тостом, значение по умолчанию — «ложь». Если значение установлено как истинное, будет проявляться, когда приложение находится в фоновом режиме.

Стиль отображения уведомлений (шрифт, цвет и т. д.) определяется прошивкой и не может быть изменен в приложении. тоста: от 200 до 5000 долларов в миллисекундах.
