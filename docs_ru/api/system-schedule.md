## API

### `scheduleJob`
<метод объявления><pre>
(варианты: {
  тип: номер,
  тайм-аут: число,
  триггерный метод: строка,
  интервал?: число,
  параметры?: Объект,
}): число
</pre></decl>

Настроить запланированные задачи.
- `тип`:
  - 1: Аппаратное время, TriggerMethod может быть запущен посредством изменений системного времени;
  - 2: Идет реальное время, время будет рассчитываться даже в состоянии сна;
- `тайм-аут`:
  - Если тип равен 1, это временная метка первого времени выполнения, то есть количество миллисекунд от 1970/01/01 00:00:00 GMT до текущего времени;
  - Если тип равен 2, это интервал между текущим временем и временем первого выполнения в миллисекундах;
- `triggerMethod`: имя метода, срабатывающего в app.js, который вызывается по обеспечению тайм-аута и запускается в фоновом режиме;
- `интервал`: интервал периодического выполнения в миллисекундах. выполняться повторно;
- `params`: параметры задачи;

::: совет
Хотя тайм-аут и интервал указаны с точностью до миллисекунды, время — с точностью до секунды. Интервал между временем первого выполнения и временем периодического выполнения не может быть менее 60 секунд, иначе интерфейс выдаст запрос.
:::

Возвращаемое значение — это идентификатор задачи, который используется для отмены задачи. Возвращаемое значение равно -1, что указывает на то, что создание не удалось.``` js
пусть id = Schedule.scheduleJob({
  тип: 1,
  timeout: new Date('2025-03-14T23:00:00').getTime(), // временная метка времени первого выполнения
  интервал: 60000, // Интервал периодического выполнения не менее 60 секунд
  триггерный метод: 'scheduleFunc',
  параметры: {
    еда: «яблоко»,
  },
})
