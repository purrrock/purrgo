
# Управление пакетами

Этот модуль обеспечивает функции установки и удаления пакетов ресурсов.

## Модуль импорта``` js
импортировать пакет из @system.package
```поскольку `package` является ключевым словом JavaScript и не может использоваться в качестве переменного имени, мы можем экспортировать модуль `"@system.package"` в переменную `pkg`.

##Определение интерфейса

### `install` <decl function type="(options: { src: string }): Promise<void>" />

Установите приложение или пакет циферблата из файловой системы. Атрибут параметра src — это URI устанавливаемого файла пакета ресурсов.

Если пакет ресурсов является пакетом ресурсов приложения, то после установки пакета ресурсов с помощью `pkg.install({ src: 'package-uri' })` к URI-протоколу [`app`](/framework/application/resource.md#app).

`src` — это URI файла пакета ресурсов, который необходимо установить. Установленный пакет должен быть действительным пакетом приложения или циферблата, то есть он должен иметь файл [`manifest.json`](/framework/application/manifest.md).

После установки вы можете использовать протокол [`prc`](/framework/application/resource.md#prc) для доступа к ресурсам в пакете ресурсов.

Если пакет, который необходимо установить, уже существует, будет выполнена операция обновления. Если обновленное приложение запущено, сначала оно будет закрыто, а затем вы можете вызвать [`launch()`](system-launch.md#launch-launch-app), чтобы запустить его снова.

API [`remove()`](#remove).

### `remove`<decl type="(options: { package: string }): Promise<void>" function />

Удалите пакеты ресурсов, установленные с помощью [`install()`](#install). [`manifest.package`](/framework/application/manifest.md#package).

Прежде чем удалить пакет ресурсов, сначала следует закрыть соответствующий ресурс, например удалить соответствующие компоненты и закрыть связанные страницы. закроет приложение, содержащее пакет ресурсов (если это пакет ресурсов приложения).

::: предупреждение
Пакеты ресурсов необходимо удалить с помощью `remove()`, а не напрямую с помощью API файловой системы, поскольку последний раз не очищается кеш-ресурсы и не удаляется должным образом информация об установке.
:::

### `getInfo` <decl type="(query?: string | Query): Manifest | неопределенный" метод/>

Получите информацию о манифесте пакета приложений. Запрос: пакет или более сложный объект``` тс
введите запрос = {
  package: строка, // имя пакета для запроса
  options?: ('dial' | 'widgets')[] // Необязательные поля запроса
}
```Если пакет, указанный в поле `package`, существует, `getInfo()` вернет информацию о пакете `Manifest`, в случае возврата `undefed` он будет потерян. приложения.

#### Объект `Манифест`

Манифест Манифест по сути является подмножеством [manifest.json](/framework/application/manifest.md):``` тс
введите запрос = {
  введите: «приложение» | 'dial', // Тип пакета, может быть приложением или пакетом набора номера
  name: строка, // имя пакета
  versionName: строка, // название версии
  versionCode: номер, // номер версии
  icon?: string, // Путь к изображению приложения, это поле существует только в пакетах приложений.
  Dial?: { // Необязательное поле: информация о наборе номера, эта информация есть только в пакете набора номера.
    компонент: строка, //Путь к компоненту циферблата
    Preview: String // Путь к изображению предварительного просмотра циферблата
  },
  виджеты?: { // Необязательные поля: виджет и информация о виджете
    имя: строка, //Имя кулона/виджета
    компонент: строка, // виджет/путь к виджету
    Предварительный просмотр: строка // Предварительный просмотр изображения виджета/виджета
  }[]
}
```Поля «Dial» и «widgets» объекта «Manifest» являются необязательными, и их наличие или отсутствие определяется содержимым «Query.options». Например``` js
pkg.getInfo({
  пакет: «com.example.app»,
  опции: ['набор номера', 'виджеты']
})
```При этом результирующий `Manifest` будет сохранять поля `dial` и `widgets` (однако приложения всегда не содержат поле `dial`).

Когда параметр `query` пуст, то есть``` тс
pkg.getInfo('com.example.app')
pkg.getInfo({ package: 'com.example.app' })
```Результат тот же: в данном случае возвращаемый объект Манифест не содержит необязательных полей.

ПолучитьИнформацию():``` js
пусть манифест = pkg.getInfo()
console.log(манифест)
