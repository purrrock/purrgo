
# Применить конфигурацию

## Модуль импорта```js
импортировать конфигурацию из @system.configuration
```##Определение интерфейса

### `getLocale`
<метод объявления><pre>
(): {
  язык: строка,
  CountryOrRegion: строка,
}
</pre></decl>

Получите текущую локальную программу. который может измениться из-за изменений настроек или системы языкового стандарта.
 - «язык» представляет собой настоящий язык, например «zh», «en» и т. д. д.,
 - `countryOrRegion` представляет текущую страну или регион, например «CN», «США» и т. д. д.
