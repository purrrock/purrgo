описание параметра `options`

### `subscribe` <decl type="(callback: (location: Location) => void): Number" метод/>

При прослушивании изменений местоположения. [информация о местеположения] (#местоположение). для отказа от подписки с помощью метода [`unsubscribe()`](#unsubscribe).

### `unsubscribe` <decl type="(subscribeID: Number): void" метод/>

Отменить прослушивание изменений местоположения.

##Определение типа

### `Местоположение`

Данные о размещении, средствах для представления представлены.``` тс
тип Местоположение = {
  код: номер; // Код состояния позиционирования, указывающий, действительна ли текущая информация о местоположении
  сообщение: строка; // Сообщение об ошибке позиционирования
  данные: {
    //Данные информации о местоположении
    долгота: число; // значение широты
    широта: число; // значение долготы
    тип координат: строка; //Тип системы координат, например «WGS84», «GCJ02» и т. д.
  };
};
```Код состояния обращения поля `code` выглядит следующим образом:

- `200`: текущая информация о месте размещения действительна;
- `1002`: в настоящее время не подключен к сети Bluetooth, присутствующей на телефоне.
- «1300»: мобильный телефон не может получить услуги по определению местоположения.
- `1301`: служба определения местоположения не включена на телефоне.
- `1302`: мобильное приложение не обеспечивает четкости определения местоположения.
- `1399`: неизвестная ошибка.
