
# Переход к приложению

## Модуль импорта``` js
импортировать запуск из @system.launch
```##Определение интерфейса

### `launch` <decl type="(app: string): Promise<bool>" метод/>

`app` — это строка идентификатора установленного приложения.

### `inactive` <decl type="(app?: string): Promise<void>" метод/>

Переключите приложение в фоновый режим. `app` — это идентификатор запущенного приложения. параметры не указаны, текущее приложение переходит в фоновый режим. Только приложения переднего плана можно переключить в фоновый режим.

### `exit` <decl type="(app?: string): Promise<void>" метод />

Закрыть приложение. Параметр приложения — этот параметр не указан, текущее приложение будет закрыто.

### `getRunning` <decl type="(): string[]" метод />

Получите список имен пакетов запущенных приложений, в том числе в фоновом режиме.
