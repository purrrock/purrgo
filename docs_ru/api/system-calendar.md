```##Определение интерфейса

[`LunarDate`](#lunardate).

### `getLunar` <decl метод type="(год: число, месяц: число, день: число): LunarDate" />

Получите информацию лунного календаря, соответствующую указанному году, месяцу и дню по датам лунного календаря типа [`LunarDate`](#lunardate). параметры следующие:
- «год»: например, полный номер года, «2024»;
- `месяц`: номер месяца, начиная с `0`, число декабря - $11$;
- `day`: номер даты, начиная с `1`.

##Определение типа

### `ЛуннаяДата```` тс
введите LunarDate = {
  месяц: строка, // название лунного месяца
  день: строка, // название лунной даты
  фестиваль?: строка // Название фестиваля, может быть неопределенным
}
```- «месяц»: название лунного месяца, «первый месяц», «февраль».
- «день»: название даты лунного календаря, например «первый день лунного месяца», «пятнадцатый день».
- `фестиваль`: название фестиваля, если фестиваля нет, атрибуты не определены.
