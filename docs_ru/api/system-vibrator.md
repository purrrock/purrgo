```## API

### `вибрировать`
<метод объявления><pre>
(варианты: {
  режим: строка
}): логическое значение
</pre></decl>

Вызов вибрации. Функции каждого параметра поля:
- «режим»: режим вибрации, «длинный» означает длинную вибрацию, «короткий» означает короткую вибрацию. Значение по умолчанию — «длинный».
