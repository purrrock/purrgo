
# Внутренний интерфейс

Модуль `system.internal` можно использовать только в приложениях запуска.

## Модуль импорта``` js
импортировать внутренние данные из @system.internal
```## API

### `globalComponent` <decl type="(name: string, uri: string): void" метод />

Зарегистрируйте [глобальный компонент](/framework/comComponent/README.md#globalComponent). быть включен во все приложения. UX-файл глобального компонента относительно текущего исходного файла. Например``` js
Internal.globalComponent('TopBar', '/global/TopBar.ux')
```TopBar `<import name="TopBar" />` приложений.

Метод globalComponent() лучше всего выполнять на этапе запуска приложения app.js, чтобы загрузить любой интерфейс.

### `setDefaultKeyHandler` <decl type="(handler: (event: KeyEvent) => void): void" метод />

Зарегистрируйте системный обработчик ключей по умолчанию. вызов. Прототип типа KeyEvent:``` тс
интерфейс KeyEvent {
  введите: «нажатие клавиши» | 'keyup', // Тип ключевого события
  ключ: строка, // имя ключа
  timestamp: число, // временная метка отчета о ключевых событиях, единица измерения — миллисекунды
}
```Обработчик ключей по умолчанию можно зарегистрировать только один раз, поскольку множественные регистрации перезаписывают операцию.
