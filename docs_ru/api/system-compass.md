
#компас

Модуль `@system.compass` получает информацию о расположении устройства относительно северного магнитного полюса Земли.

## Модуль импорта``` js
импортировать компас из @system.compass
```##Определение интерфейса

### `subscribe` <decl type="(callback: (data: Value) => void): Number" метод/>

Подпишитесь на изменения данных Компас. Расположение устройства. [`Значение`](#значение).

Возвращает идентификатор подписки для отмены подписки.

### `unsubscribe` <decl type="(subscribeId: Number): void" метод/>

Компас. ПараметрsubscribeId — это идентификатор подписки, возвращаемый методом [`subscribe()`](#subscribe).

Этот метод следует прекратить при уничтожении страницы или компонента, чтобы отменить подписку на «subscribe()»:``` js
const subscribeId = compass.subscribe((данные) => {
  console.log(`Направление: ${data.direction} радианы`)
  console.log(`Точность: ${data.accuracy}`)
})

// Отписаться
компас.unsubscribe(идентификатор подписки)
```### `калибровка` <decl type="(): Promise<void>" метод/>

Запустите процесс компаса. активируйте и вызовите этот метод для стабилизации компаса.

Эта функция возвращает безрезультатный объект Promise, который будет разрешен, когда система завершит калибровку.

### `getValue` <decl type="(): Promise<Value>" метод/>

Получите текущие данные компаса. информация о направлении и точности компаса (тип [`Value`](#value)).

Пример:``` js
// Используем обещание
compass.getValue().then((data) => {
  console.log(`Направление: ${data.direction} радианы`)
  console.log(`Уровень точности: ${data.accuracy}`)
})

// Используем асинхронность/ожидание
асинхронная функция getCompassData() {
  константные данные = ждут компас.getValue()
  console.log(`Направление: ${data.direction} радианы`)
  console.log(`Уровень точности: ${data.accuracy}`)
}
```::: Примечание
Из-за недостатков реализации этот метод не поддерживает вызовы в стиле обратного вызова (например, `{ Success: (data) => {...} }`), используйте Promise или async/await.
:::

##Определение типа

### `Ценность`

Подпись типа данных компаса «Знание» выглядит следующим образом:``` тс
тип Значение = {
  направление: число // Направление по компасу (радианы)
  точность: число // Уровень точности компаса
}
```Описание недвижимости:
- `направление`: угол в радианах между осью Y устройства и северным магнитным полюсом Земли, диапазон значений $[0,2\pi]$, где:
  - `0`: строго на север.
  - `Math.PI/2` (около 1,57): прямо на восток.
  - `Math.PI` (около 3,14): строго в южном направлении.
  - `3*Math.PI/2` (приблизительно 4,71): прямо на запад
- `точность`: уровень точности данных компаса.
  - `3`: высокая точность
  - `2`: средняя точность
  - `1`: достоверность
  - `0`: Ненадежно (неизвестная причина).
  - `-1`: Ненадежно (датчик потерял связь)

Пример:``` js
// Определяем направление
константные данные = ждут компас.getValue()
const градусов = data.direction * 180 / Math.PI // Преобразование в угол

console.log(`Направление: ${градусы}°`)
if (градусы >= 337,5 || градусы < 22,5) {
  console.log('К северу')
} else if (градусы >= 22,5 && градусы < 67,5) {
  console.log('К северо-востоку')
} else if (градусы >= 67,5 && градусы < 112,5) {
  console.log('К востоку')
}
// ...суждение в других направлениях

// Проверка точности
если (data.accuracy >= 2) {
  console.log('Точность компаса хорошая')
} еще если (data.accuracy === 1) {
  console.log('Точность компаса низкая, рекомендуется калибровка')
  компас.калибровка()
} еще {
  console.log('Данные компаса не заслуживают доверия')
}
```
