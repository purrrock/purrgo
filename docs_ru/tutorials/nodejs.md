# Менеджер пакетов Node.js

Помимо независимого использования, инструмент упаковки gx можно использовать с менеджерами пакетов JavaScript, такими как npm, pnpm или Yarn. Обязательным условием является установка пакета `glyphix`:

::: кодовые вкладки
@tab нпм
``` баш
npm установить -D глификс
```

@tabpnpm
``` баш
pnpm я -D глификс

@tab пряжа
``` баш
пряжа добавить -D глификс
```
:::

В противном случае вы можете столкнуться с такой ошибкой при выполнении `gx build`:
``` баш
$ gx сборка
фатально: glyphix не найден, установите его с помощью npm install -D glyphix или другого менеджера пакетов.
```

Основные преимущества использования менеджера пакетов JavaScript при разработке приложений Glyphix заключаются в следующем:
- Используйте TypeScript вместо JavaScript в качестве языка разработки, чтобы обеспечить безопасность типов и улучшить опыт разработки.
- Используйте библиотеки JavaScript в экосистеме Node.js, подходящие для встроенной разработки (например, библиотеки алгоритмов, инструменты обработки данных и т. д.).
- Используйте такие инструменты, как ESLint и Prettier, для улучшения качества кода и эффективности разработки.
- Облегчает совместную работу команды и сопровождение проекта.

::: предупреждение
В настоящее время через менеджер пакетов поддерживаются только общие зависимости JavaScript или TypeScript, а компоненты Glyphix нельзя использовать повторно. Выбирая сторонние библиотеки, убедитесь, что они подходят для встроенных сред, и избегайте библиотек, которые полагаются на DOM, API-интерфейсы Node.js или слишком громоздки.
:::

::: совет
Если инструменты разработчика [Glyphix.js](glyphix.js/README.md) установлены глобально, вы можете напрямую использовать команду типа `gx build` для его упаковки, в противном случае вам нужно добавить конфигурацию `scripts` в `package.json`.
:::

## Конфигурация проекта

### конфигурация `package.json`

При использовании менеджера пакетов Node.js рекомендуется добавить необходимые скрипты и настройки в package.json:

```json
{
  "name": "my-glyphix-app",
  "версия": "1.0.0",
  "скрипты": {
    "build": "сборка gx",
    "emu": "gx emu",
    "чистый": "gx чистый"
  },
  "devDependency": {
    "glyphix": "^1.0.41",
    "машинописный текст": "^5.8.3"
  }
}
```

### Конфигурация `tsconfig.json`

Если вы используете TypeScript, вам необходимо создать файл tsconfig.json в корневом каталоге проекта:

```json
{
  "Параметры компилятора": {
    "цель": "ES2021",
    "модуль": "commonjs",
    "baseUrl": "./",
    "пути": {
      "/*": ["источник/*"],
      "/assets": ["src/assets/*"]
    },
    "types": ["глификс", "узел"],
    «allowImportingTsExtensions»: правда,
    «checkJs»: правда,
    «декларация»: правда,
    «declarationMap»: правда,
    «emitDeclarationOnly»: правда,
    «esModuleInterop»: правда,
    «forceConsistentCasingInFileNames»: правда,
    «строгий»: правда,
    «noImplicitAny»: правда,
    «noUnusedLocals»: правда,
    «noUnusedParameters»: правда,
    «skipLibCheck»: правда,
    «resolveJsonModule»: правда
  },
  "include": ["src/**/*.ts", "src/**/*.ux"]
}
```

:::информация
Инструмент упаковки Glyphix автоматически выполняет компиляцию файлов TypeScript. Приведенная выше конфигурация в основном используется для проверки типа IDE и подсказок кода.
:::

## Конфигурация `glyphix.config.js`

Рекомендуется создать файл glyphix.config.js в корневом каталоге проекта (src/или каталог, где находится package.json), чтобы настроить параметры упаковки:
```js
модуль.экспорт = {
  minify: false, // Отключаем сжатие кода, чтобы облегчить отладку и получить номера строк исходного кода
};
```
Если вы используете TypeScript, вместо этого вы можете создать файл glyphix.config.ts.

::: совет
Обязательно создайте этот файл и настройте `minify: false`, иначе упакованный код будет сжат и запутан, что приведет к невозможности соответствия номеру строки исходного кода во время отладки.
:::

## Использование TypeScript

Платформа Glyphix предлагает экспериментальную поддержку TypeScript, что позволяет вам использовать преимущества безопасности типов и современного синтаксиса JavaScript при разработке приложений.

### Пример базового компонента

Вот пример компонента, написанного на TypeScript:

```html
<шаблон>
  <p on:click="onClick">{{count}}</p>
</шаблон>

<script lang="ts">
импортировать { defineComponent } из "glyphix"

экспортировать по умолчанию defineComponent({
  данные: {
    количество: 0
  },
  onClick() {
    это.count++
  }
})
</скрипт>
```

По сравнению со сценарием компонента JavaScript по умолчанию, использование TypeScript требует следующих изменений:
1. Используйте `lang="ts"` в теге `<script>`, чтобы отметить тип языка как TypeScript.
2. Импортируйте функцию defineComponent из модуля glyphix.
3. Экспортируемый объект компонента должен использоваться в качестве параметра `defineComponent`, а возвращаемое значение этой функции должно быть экспортировано.

После использования TypeScript функция defineComponent сделает подсказки по коду и проверку типов в IDE более точной.

### `app.ts`

Переименуйте `app.js` в `app.ts`, чтобы использовать файл записи приложения TypeScript, и инструмент упаковки обработает его автоматически.
