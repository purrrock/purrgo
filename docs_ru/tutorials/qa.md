# Часто задаваемые вопросы

## Инструменты для упаковки

### Проблемы со сборкой проекта

#### `Ошибка Lisp: поток уничтожен` отчет об ошибке

Конкретное явление заключается в том, что появляется сообщение об ошибке, подобное следующему:

``` журнал
[47%] Обработка изображения src/assets/images/frame1.png
ошибка: Ошибка Lisp: поток уничтожен
```

Эта проблема связана с предыдущей ошибкой сборки, которая привела к отмене выполняемой операции сборки преобразования изображения. Вам нужно только исправить «фатальную» операцию построения отчета об ошибках, чтобы возобновить ее без специальной обработки.

### Эмулятор

#### Язык симулятора по умолчанию

Язык симулятора по умолчанию — zh-CN. Поэтому, если вы добавите конфигурацию [Интернационализация](/framework/comComponent/i18n.md), файл перевода `zh-CN.json` будет использоваться по умолчанию. Чтобы запустить симулятор с помощью команды `gx`, вы можете использовать опцию `-l` или `--language` для указания языка:
``` оболочка
gx emu -l en-US # Использовать американский английский
```
Вы также можете динамически менять язык во время работы эмулятора с помощью инструмента отладки инспектора.
