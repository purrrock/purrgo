
# JavaScript-скрипт

JavaScript — это язык сценариев, используемый для разработки приложений Glyphix. Разработчики могут размещать код JavaScript в теге `<script>` файла UX или напрямую ссылаться на файлы сценариев `*.js`.

## Поддержка грамматики

Поддерживает синтаксис ES6.

## Модуль импорта

Ссылайтесь на другие файлы js в своем коде, импортируя модули. Обычно существует два способа импорта модулей, определенных разработчиком, по путям:
``` js
импортировать утилиты из '../Common/utils.js' // Используйте ключевое слово import
const utils = require('../Common/utils.js') // Используем функцию require
```
Правила пути к модулю см. в разделе [Путь и URI](../application/resource). Кроме того, `.js`, появляющийся в качестве суффикса файла, может быть опущен в пути к модулю, поэтому приведенный выше оператор импорта можно записать как
``` js
импортировать утилиты из '../Common/utils' // Используйте ключевое слово импорта
const utils = require('../Common/utils') // Используем функцию require
```

Используйте имя модуля для импорта встроенных модулей системы. Все системные модули начинаются с символа `@`:
``` js
импортировать маршрутизатор из @system.router // Используйте ключевое слово import
const router = require('@system.router') // Используем функцию require
```

::: предупреждение
Разработчикам не следует начинать имена модулей с символа `@`; эти имена зарезервированы для системных модулей.
:::

# Модуль экспорта

Используйте синтаксис экспорта ES6 для экспорта модулей, например:
``` js
//Экспортируем значение по умолчанию
экспортировать по умолчанию {
  метод() {
    // ...
  }
  реквизит: {
    // ...
  }
}

//Экспортируем именованные значения
функция экспорта процесс(args) {
  // ...
}
```
