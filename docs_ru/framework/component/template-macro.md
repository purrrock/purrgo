
# Макрос шаблона

Макрос шаблона — это способ упростить повторяющийся код и представляет собой элемент верхнего уровня `<template>` в UX-файле с атрибутом `macro:`:
``` HTML
<макрос шаблона: прокрутка>
  <scroll #props media-query="(shape: rect)">
    <слот />
  </прокрутка>
  <scroll #props деформация="рыбий глаз"
          Scroll-snap="center" media-query="(форма: круг)">
    <слот />
  </прокрутка>
</шаблон>
```
Например, здесь определен макрос с именем «прокрутка». Макрос заменит одноименный компонент в шаблоне `<template>` текущего UX-файла, и
- Все одноимённые свойства компонента заменят заполнитель #props в макросе шаблона;
— Дочерние элементы компонентов с таким же именем заменят узел `<slot />` в макросе шаблона.

Например
``` HTML
<шаблон>
  <прокрутка :index="3" on:index="onIndexChange">
    <p for="i in 10">item {{i + 1}}</p>
  </прокрутка>
</шаблон>
```
будет заменен макросом шаблона `scroll`
``` HTML
<шаблон>
  <scroll :index="3" on:index="onIndexChange" media-query="(форма: прямоугольник)">
    <p for="i in 10">item {{i + 1}}</p>
  </прокрутка>
  <scroll :index="3" on:index="onIndexChange" деформация="рыбий глаз"
          Scroll-snap="center" media-query="(форма: круг)">
    <p for="i in 10">item {{i + 1}}</p>
  </прокрутка>
</шаблон>
```

::: совет
Имя макроса в этом примере — «прокрутка», а содержимое макроса также содержит тег «прокрутка», но замена макроса будет выполнена только один раз и не будет повторяться.
:::

## Цель

Как видно из приведенного выше примера, макросы шаблонов могут статически заменять обычные компоненты в другую форму. Замененный код обычно неудобно писать и понимать от руки. Такие как:
``` HTML
<прокрутка :index="3" on:index="onIndexChange">
  <p for="i in 10">item {{i + 1}}</p>
</прокрутка>
```
заменяется на:
``` HTML
<scroll :index="3" on:index="onIndexChange" media-query="(форма: прямоугольник)">
  <p for="i in 10">item {{i + 1}}</p>
</прокрутка>
<scroll :index="3" on:index="onIndexChange" деформация="рыбий глаз"
        Scroll-snap="center" media-query="(форма: круг)">
  <p for="i in 10">item {{i + 1}}</p>
</прокрутка>
```
Замененный код фактически статически выбирает различные свойства компонента прокрутки на основе [медиа-запроса](/framework/render/media-query.md) формы экрана. В частности, он добавляет два свойства к компоненту [`scroll`](/comComponents/scroll.md) на круглых экранах:
- [`deformation="fisheye"`](/comComponents/scroll.md#deformation): включить эффект «рыбий глаз» для круглых экранов;
- [`scroll-snap="center"`](/comComponents/scroll.md#scrollsnap): выравнивание дочерних элементов `scroll` по центру на круглом экране.

Этот макрос шаблона добавляет адаптацию формы экрана специальной формы к исходному рукописному коду. Эта модификация не требует изменения исходного кода шаблона и, следовательно, не является интрузивной.

## Как использовать

В настоящее время нет возможности экспортировать макросы шаблонов для использования в других файлах UX. Поэтому макрос шаблона нужно прописывать неоднократно в каждом необходимом UX-файле, то есть что-то вроде
``` HTML
<макрос шаблона: прокрутка>
  ...
</шаблон>
```
элемент верхнего уровня. Узлы макросов шаблона и узлы `<template>` могут располагаться в любом порядке, но не определяют макросы шаблона с одинаковыми именами в UX-файле.
