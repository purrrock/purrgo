
# 组件复用

应用层面的组件复用主要由自定义组件来实现。

## 子组件

Предположим, что структура в теге `<template>` [UX-файла](/framework/comment/README.md#ux-file) описывает организацию интерфейса, например:
``` HTML
<шаблон>
  <дел>
    <p>текст</p>
    <image src="path/to/image.png" />
    <qrcode value="Привет, мир!" />
  </div>
</шаблон>
```
Соответствует следующей древовидной структуре компонентов во время выполнения:
``` русалка
блок-схема ТБ
  div --- п
  div --- изображение
  div --- qrcode
```
Это дерево компонентов имеет родительский узел div и дочерние узлы $3$ p, image и qrcode. Компонент div — это самый внешний компонент тега <template>. Мы называем этот компонент **корневым компонентом**. Иногда компоненты не уникальны, например:
``` HTML
<шаблон>
  <p>текст</p>
  <image src="path/to/image.png" />
  <qrcode value="Привет, мир!" />
</шаблон>
```
В . есть 3 корневых компонента. Кроме того, использование директивы [`for`](/framework/commands/for.md) также может привести к появлению нескольких экземпляров корневого компонента, например
``` HTML
<шаблон>
  <p for="x in ['один', 'два', 'три']">
    метка: {{x}}
  </p>
</шаблон>
```
Будет отображаться как экземпляры компонента `p` за $3$.
