
#Связь между компонентами

Связь между компонентами достигается с помощью параметров компонентов и привязок событий. Например:
``` HTML
<scroll Scroll-snap="center" on:scroll="scrolled($event)" />
```
Параметр атрибута `scroll-snap` передается экземпляру компонента `scroll` для выравнивания элемента по центру и будет прослушивать изменения в атрибуте `scroll`.

## Параметры атрибута

Параметры можно передавать подкомпонентам через поле атрибута узла компонента, например:
``` HTML
<p text="Сообщение"></p>
```
Экземпляру компонента `p` будет передано свойство с именем `text` со значением `"A message"`. Можно передать несколько атрибутов, следуя синтаксису XML/HTML. Вычисленное значение можно передать в свойства компонента через [Выражение интерполяции] (шаблон#Выражение интерполяции).

## Ответ на событие

[Native-Component] инкапсулирует многие события ввода пользовательского интерфейса, такие как реакции на сенсорные жесты и события изменения пользовательского интерфейса. Эти события можно отслеживать с помощью команды [`on`](../commands/on.md).

## Триггерное событие

Для пользовательских компонентов вы можете использовать метод объекта компонента [`$emit(name, value)`](/framework/comComponent/comComponent-apis.md#emit) для запуска события:
``` HTML
<panel on:some-event="console.log(`событие ${$event} было создано!`)">
```

``` js
// в Panel.ux
экспортировать по умолчанию {
  излучатьEvent() {
    this.$emit('someEvent', 'привет')
  }
}
```

Метод $emit принимает два параметра:
- `name`: имя атрибута, который должен отправить событие, должно использовать именование в верблюжьем регистре (соответствующий атрибут шаблона — это именование в виде змеи или верблюжьего регистра).
- `value`: необязательный параметр, значение атрибута события, будет использоваться как значение переменной `$event` директивы `on`.

Если в модели представления объекта компонента есть свойство с именем `name`, метод `$emit` не изменит значение свойства на `value`.
