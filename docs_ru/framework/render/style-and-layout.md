
# Стиль и макет

Система стилей Glyphix похожа на CSS в веб-технологиях. CSS обычно определяется непосредственно в теге `<style>` UX-файла.

## Написание CSS

Вы можете написать CSS внутри тега `<style>`:

``` HTML
<стиль>
  div {дисплей: гибкий; }
</стиль>
```

Файлы CSS можно импортировать с помощью команды @import:

``` HTML
<стиль>
  @import 'style.css';
  div {дисплей: гибкий; }
</стиль>
```

Glyphix также предоставляет ограниченную поддержку встроенных стилей, которые записываются непосредственно в атрибуте стиля компонента:
``` HTML
<div style="background: #f00; color: #fff"> ... </div>
```
Значением встроенного стиля является строка, и вы можете обновить стиль, изменив эту строку. [Свойства CSS](/framework/generic/styles.md), поддерживающие использование во встроенных стилях, добавят тег <badge type="info" text="inline" />.

::: предупреждение
Текущая версия встроенных стилей неэффективна и ее следует использовать только в качестве решения для логики js для обновления стилей компонентов. Интенсивное использование может вызвать проблемы с производительностью. Обычно вам следует использовать схему определения правил CSS в теге `<style>`.
:::

## Выбор стиля

В настоящее время платформа стилей поддерживает следующие селекторы:

- селектор класса
- выбор типа
- селектор идентификатора
- Псевдокласс (используется редко)
- Псевдоэлементы (используются редко)
- Селекторы потомков и прямые селекторы потомков, такие как `div > .title` или `div .title`
- Составные селекторы, такие как #id.class или div.class.

### селектор классов

Селектор классов выбирает компоненты с соответствующими атрибутами класса. Компоненты могут иметь несколько значений класса, например
``` HTML
<p class="ceil content">...</p>
```
Будет соответствовать следующим двум определениям стиля:
``` CSS
.ceil {
  цвет фона: #222;
  радиус границы: 12 пикселей;
}

.content {
  размер шрифта: 24 пикселей;
  отступ: 12 пикселей;
}
```

### Селектор комбинаций

Поддерживает использование `,` для указания нескольких селекторов для набора правил:
``` CSS
#id, .class, div {
  дисплей: гибкий;
  гибкое направление: столбец;
  цвет: красный;
}
```

### Унаследованные свойства

Некоторые свойства CSS могут быть унаследованы от родительских элементов к дочерним, взяв в качестве примера «font-size»:
``` HTML
<дел>
  <p>Текст</p>
</div>
```

``` CSS
дел {
  размер шрифта: 1,25рем;
}
```
Несмотря на то, что атрибут `font-size` не установлен для элемента `<p>`, он по-прежнему отображает размер шрифта `1,25rem`, поскольку элемент `<p>` наследует настройку размера шрифта от родительского `<div>`. Другими словами, после установки наследуемого атрибута стиля в контейнере все дочерние элементы также получат настройку атрибута. Но обратите внимание, что приоритет механизма наследования свойств CSS очень низок. Унаследованное значение будет использоваться только в том случае, если элемент не указывает унаследованный атрибут стиля. Предположим, что в приведенном выше примере используется следующий CSS:
``` CSS
* {
  размер шрифта: 1rem;
}
дел {
  размер шрифта: 1,25рем;
}
```
Из-за наличия блока обычного стиля `*` размер шрифта элемента `<p>` теперь будет равен `1rem` вместо унаследованного значения.

В документе [CSS Properties](/framework/generic/styles.md) к свойствам, поддерживающим наследование, будет добавлен тег <badge type="info" text="Inherited" />.

### Отзывчивая поддержка

В настоящее время ни атрибут class, ни атрибут id не поддерживают отзывчивость, поэтому
``` HTML
<div class="{{expr}}" id="{{expr}}"> ... </div>
```
Ни один из них не поддерживается, напрямую можно записать только статические значения атрибутов class и id.

::: предупреждение
Разработчикам следует обратить внимание на ограничение: class и id не поддерживают адаптивные атрибуты!
:::

## Значение цвета

### Цветовой код

Значения цвета поддерживают цветовые коды RGB или RGBA, начинающиеся с символа `#`. Допустимые цветовые коды:

- `#RRGGBB[AA]`, например `#102000`, `#00ff0080`
- `#RGB[A]`, например `#0f0`, `#ff08`

Если цветовой код не содержит альфа-канала, значением этого канала является `ff` (формат `#RRGGBB`) или `f` (формат `#RGB`). Каждый бит цветового кода представляет собой шестнадцатеричное число, доступные символы: «0–9», «AF» и «a-f». `#RGB[A]` — это сокращенный метод для кода `#RRGGBB[AA]`, например, `#0f38` имеет тот же цвет, что и `#00ff3388`.

### Функция цвета

В настоящее время функции rgb() и rgba() поддерживаются в блоках CSS для определения значений цвета. Цветовой формат HSL не поддерживается.

### Стандартное название цвета

В блоках CSS можно использовать имена цветов, соответствующие веб-стандартам, например:
``` CSS
цвет: коричневый;
цвет: светло-серый;
```

### Цвета во встроенных стилях

Во встроенных стилях поддерживаются только коды цветов, начинающиеся с `#`, например:
``` HTML
<p style="color: #ff00ff">...</p> <!-- Поддержка -->
<p style="color: grey">...</p> <!-- Не поддерживается, не подлежит анализу -->
```

## Длина

Общий формат значения длины: `<value><unit>`, `value` — это числовое значение длины, а `unit` — это единица длины, например `15px`. Между «значением» и «единицей» не должно быть пробелов.

Также поддерживается специальное значение длины auto. Это значение длины не имеет конкретного значения или единицы измерения. Длина фактического рендеринга определяется конкретными сценами и правилами.

Доступны следующие единицы длины:

- `px`: использовать пиксели в качестве единицы длины.
- `pt`: используйте фунты в качестве единицы длины, один фунт равен 1/72 доллара дюйма.
- `%`: единица длины в процентах, определенное значение будет иметь разные отношения преобразования в зависимости от атрибутов и макета.
- [`rem`](/framework/application/font-config.md#rem-font size unit): единица длины относительно размера системного шрифта по умолчанию, например, `1rem` равна размеру системного размера шрифта по умолчанию, $1,5\rm rem$ в $1,5$ раза больше прежнего.

где `pt` — абсолютная единица длины, например, `72pt` соответствует $1''$ (дюйм) или $25,4\rm мм$, независимо от устройства. `px` относится к устройству, но не соответствует напрямую физическим пикселям. Отношения преобразования см. в описании поля [`manifest.config.designWidth`](/framework/application/manifest.md#designwidth). Процентная единица длины обычно рассчитывается относительно размера родительского элемента и самого элемента. Например, процентные значения таких свойств CSS, как «width» и «margin», рассчитываются на основе размера родительского элемента, а «border-radius» рассчитывается на основе размера самого элемента.

Единица rem используется исключительно для размеров шрифтов (т. е. атрибутfont-size), что представляет собой простую схему обеспечения согласованности шрифтов на разных устройствах. Дополнительные инструкции см. в разделе [единица размера шрифта `rem`](/framework/application/font-config.md#rem-font size unit).

## Макет

Структура макета может автоматически располагать элементы на основе содержимого интерфейса и геометрической информации экрана. Разработчикам не нужно вручную указывать положение и размер элементов. Фреймворки макета — это мощный механизм адаптации интерфейсов к устройствам различного разрешения или размера, а также обработки изменяющегося контента. Большинство собственных компонентов Glyphix поддерживают два автоматических режима макета: потоковый макет и макет флексбокса, а также поддерживают макет вручную. Некоторые собственные компоненты имеют специальные макеты, которые являются обязательными, например, дочерние элементы компонента [`swiper`](/comComponents/swiper.md) всегда имеют размер, равный области просмотра, в то время как компонент [`stack`](/comComponents/stack.md) полностью разработан для обеспечения составного макета.

Концепции гибкого макета и макета flexbox взяты из веб-стандартов, но адаптированы для малопроизводительных устройств.

## Запросы СМИ

В CSS [медиа-запрос](media-query.md) в основном управляет стилями CSS в соответствии с конкретными устройствами или типами мультимедиа с помощью [правил `@media`](media-query.md#css-media-rules). Более подробную информацию о медиа-запросах можно найти в соответствующем [документе](media-query.md).

## Меньше расширения

Если вы хотите использовать [less](https://lesscss.org/) в качестве препроцессора CSS, вам необходимо сначала установить пакет `less` через [менеджер пакетов](/tutorials/nodejs.md):

::: кодовые вкладки
@tab нпм
``` баш
npm установить -D меньше
```

@tabpnpm
``` баш
пнпм я -D меньше

@tab пряжа
``` баш
пряжи добавить -D меньше
```
:::

::: совет
Глобально установленный пакет «less» (например, «npm install -g less») не будет распознан инструментом упаковки Glyphix, поэтому пакет «less» необходимо установить в проект, используя описанный выше метод.
:::

После этого вы сможете указать тип стиля, используя атрибут `lang="less"` в теге `<style>` UX-файла:

``` HTML
<style lang="меньше">
@цвет: #4D926F;

.header {
  цвет: @color;
  .вложенный {
    размер шрифта: 0,75рем;
  }
}
</стиль>
```
