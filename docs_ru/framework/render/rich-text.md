
# форматированный текст

При использовании гибкого макета встроенные элементы, такие как [`a`](/comComponents/a.md), [`span`](/comComponents/span.md) и [`checkbox`](/comComponents/checkbox.md), могут располагаться вдоль линии и могут быть разбиты. Текст таких компонентов, как «span», также можно расположить в несколько строк. Это можно использовать для отображения форматированного текста.

## Отображение обычного текста

Давайте сначала посмотрим, как Glyphix отображает простой текст. Компоненты [`p`](/comComponents/a.md) и [`text`](/comComponents/text.md) можно использовать для отображения обычного текста. Просто укажите текстовую строку в качестве свойства text этих компонентов:
``` HTML
<p text="обычная текстовая строка." />
<text text="обычная текстовая строка." />
```
Также поддерживаются узлы веб-текста (т. е. текст является дочерним узлом элемента):
``` HTML
<p>обычная текстовая строка."</p>
<text>обычная текстовая строка."</text>
```
Glyphix преобразует единственный текстовый дочерний узел компонента в атрибут `text`, поэтому два способа записи по сути одинаковы. Другими словами, пока пользовательский компонент поддерживает атрибут text, вы можете использовать дочерний узел text так же, как компонент p.

## Отображение расширенного текста

Компоненты `p` и `text` нельзя использовать для форматированного текста, поскольку они всегда представляют собой полный блок и не могут быть размещены на нескольких строках. Чтобы реализовать форматированный текст, вам сначала нужно иметь контейнер с гибким макетом, а затем использовать такие компоненты, как «span», для отображения текста. Например:
``` HTML
<дел>
  <span>богатый</span>
  <span style="color: red">текст&nbsp;</span>
  <span>строка.</span>
</div>
```
Многие компоненты по умолчанию используют гибкую компоновку, например div, p и т. д. Для простоты вы также можете опустить тег <span>:
``` HTML
<дел>
  насыщенная <span style="color: red">текстовая</span> строка.
</div>
```
Если компонент имеет несколько дочерних элементов, текстовые дочерние элементы будут автоматически преобразованы в компоненты «span».
