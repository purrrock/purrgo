
# 动画

## 基础知识

“动画”通过连续、快速地播放若干帧，从而使界面呈现在一段时间的过渡效果。在 Glyphix 中有两种方法实现动画：
- 通过快速播放一组图片的**轮播图动画**；
- 通过程序自动计算中间帧的**关键帧动画**。

### 关键帧动画

轮播图动画是通过专门的组件来实现的，它的原理和视频类似。本节主要介绍关键帧动画。下面的例子演示了一个关键帧动画：

<div class="animation-example-box">
  <div style="visibility: hidden">Hello World!</div>
  <div class="animation-span">Hello World!</div>
  <div class="keyframes-from">Hello World</div>
  <div class="keyframes-to">Hello World</div>
</div>

要实现这个动画，开发者需要定义动画的的起始帧（红色文本）和结束帧（绿色文本）。而程序会自动计算动画中的每一帧。由开发者指定的开始帧和结束帧被成为**关键帧**，关键帧动画还允许定义中间关键帧。由程序计算的帧称为**插值帧**。在这个例子中，起始关键帧为原始的文本组件，而结束关键帧是对该文本平移 $200\rm px$ 并缩放 $0.75$ 倍，插值帧则是根据动画进度计算的中间变换值。例如动画播放到 $50\%$ 时的插值帧是将原文本平移 $100\rm px$ 并缩放 $0.875$ 倍。

在相比于轮播图，关键帧动画更容易制作，并且适用于界面元素的过渡效果（例如按钮的按下动效）。

关键帧动画主要由几个要素来定义：
- 关键帧：人工指定的帧，通常来说 $0\%$ 和 $100\%$ 进度时会使用关键帧；
- 动画时长：即动画进度从 $0\%$ 到 $100\%$ 所需要的时间；
- 缓动函数：定义插值帧的进度调整曲线，线性的动画效果观感比较差；
- 重复次数、延时、播放方向（正向、反向、往复）等。

### 属性动画

Glyphix 中使用的关键帧动画主要是**属性动画**。即关键帧是由元素的属性来定义，而插值帧计算中间属性值。例如 [`transition` 属性修饰符](../component/prop-modifier.md#transition-修饰符)所实现的动画那样：动画系统会自动处理属性变化的过渡效果。

Анимации свойств в основном делятся на две категории:
- Анимация свойств компонента: добавление анимированных переходов к свойствам компонента, реализованных с помощью модификатора свойства `transition`;
- CSS-анимация: добавьте анимацию в свойства стиля.

## Функция замедления

Функция замедления определяет кривую регулировки хода анимации, что позволяет избежать эффекта монотонной линейной интерполяции. Читатели могут перейти на https://cubic-bezier.com/, чтобы оценить эффект функции замедления.

В [модификаторе свойства `transition`](../comComponent/prop-modifier.md#transition-modifier) ​​и CSS [свойстве `animation`](../generic/styles.md#animation). Функция плавности представляет собой строку, содержимое которой показано в следующей таблице.

| ценность | описание |
| :--------------------------------: | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `легкость` | Значение по умолчанию. Анимация начинается с медленной скорости, затем ускоряется и замедляется перед завершением.                                                                                      |
| `легкость` | Анимация начинается на медленной скорости.                                                                                                                       |
| `послабление` | Анимация заканчивается на медленной скорости.                                                                                                                       |
| `легкость выхода` | Анимация начинается и заканчивается на медленной скорости.                                                                                                                 |
| `линейный` | Скорость анимации одинакова от начала до конца.                                                                                                           |
| `весна` | Имитирует эффект анимации отскока пружины, эквивалентный Spring(1,1,1).                                                                                       |
| `cubic-Bezier(x1, y1, x2, y2)` | Используйте [кубическую кривую Безье](https://developer.mozilla.org/en-US/docs/Web/CSS/easing-function#cubic_b%C3%A9zier_easing_function), чтобы определить функцию плавности. |
| `пружина(пружина, демпфирование, масса)` | Имитирует анимационный эффект отскока пружины. Вы можете указать коэффициент упругости, параметры демпфирования и массы (требуется документ).                                                                 |

Для большинства анимаций хорошие результаты можно получить с помощью функции плавности `ease`, а для сложных задач можно использовать функцию `cubic-bezier()`. Функция Spring() подходит для таких сценариев, как вращение указателя, требующих физических эффектов отскока.

## Пример

### Анимация кнопок

Как показано ниже, эффект кнопки по умолчанию не имеет анимации нажатия:

<Glyphix id="render-animation-button1" width="200" height="80">

``` HTML
<дел>
  <button>Кнопка</button>
</div>
```

``` CSS
кнопка {
  дисплей: блок;
  цвет фона: #8af;
  отступы: 8 пикселей 16 пикселей;
  радиус границы: 50%;
  поле: 16 пикселей;
}

кнопка: активная {
  преобразование: масштаб (1.1, 1.1);
}
```
</Глификс>

Используйте свойство CSS [`animation`](../generic/styles.md#animation), чтобы добавить интерактивную анимацию к этой кнопке:

<Glyphix id="render-animation-button2" width="200" height="80">

``` HTML
<дел>
  <button>Кнопка</button>
</div>
```

``` CSS
/* Определить активный ключевой кадр псевдокласса, не писать из / 0% ключевого кадра
   Анимация начнет воспроизводиться с текущего состояния компонента */
@keyframes button-active {
  до {
    преобразование: масштаб (1.1, 1.1);
  }
}

/* Не определять ключевые кадры псевдокласса, не писать из / 0% ключевых кадров
   Анимация начнет воспроизводиться с текущего состояния компонента */
@keyframes button-normal {
  до {
    преобразование: масштаб (1, 1);
  }
}

кнопка {
  дисплей: блок;
  цвет фона: #8af;
  отступы: 8 пикселей 16 пикселей;
  радиус границы: 50%;
  поле: 16 пикселей;
  /* Анимируем кнопку масштабирования до 100% в стиле без псевдокласса */
  анимация: 0,2 с. Кнопка облегчения — нормальная;
}

кнопка: активная {
  /* Масштабируем кнопку до 120% с помощью анимации в стиле активного псевдокласса */
  анимация: 0,2 с. Кнопка легкости активна;
}
```
</Глификс>

Свойство CSS `transition` в настоящее время не поддерживается, поэтому анимацию необходимо определять отдельно в неклассифицированном стиле кнопки и в стиле псевдокласса `active`.


### Эффект анимации `весны`

Функция замедления «пружина» обеспечивает эффект интерполяции, аналогичный пружинной вибрации, которую можно использовать для перемещения указателей. В следующем примере демонстрируются два метода реализации анимации указателя: равномерное вращение указателя слева и использование функции плавности Spring справа.

<Glyphix id="render-animation-spring" width="400" height="200">

``` HTML
<div class="окно">
  <div class="часы">
    <div class="указатель"
      Transform="translate(0, -40%) Rotate({{angle}}deg) Translate(0, 50%)"
      Transform.transition="{curve: 'linear', продолжительность: 1}" />
    <div class="невидимый указатель"></div>
  </div>
  <div class="часы">
    <div class="указатель"
      Transform="translate(0, -40%) Rotate({{angle}}deg) Translate(0, 50%)"
      Transform.transition="{curve: 'spring(1.2,1,1.2)', продолжительность: 1}" />
    <div class="невидимый указатель"></div>
  </div>
</div>
```

``` CSS
.окно {
  дисплей: гибкий;
}

.часы {
  цвет фона: серый;
  радиус границы: 50%;
  гибкий: 1;
  поле: 4 пикселя;
}

.pointer {
  цвет фона: #0f0;
  ширина: 12 пикселей;
  высота: 50%;
  поле: 4 пикселя авто;
  радиус границы: 50%;
}

.невидимый {
  видимость: скрыта;
}
```

``` js
экспортировать по умолчанию {
  данные: {
    угол: 0
  },
  onInit() {
    setInterval(() => this.angle += 5, 1000)
  }
}
```

</Глификс>

Обе анимации обновляют угол указателя с интервалом в $1$ секунды, но модификатор `transition` свойства компонента автоматически добавляет анимацию вращения.
