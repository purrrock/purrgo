# по директиве

Директива on используется для отслеживания изменений значений свойств, которые поддерживают мониторинг.

## Синтаксис

``` HTML
<div on:attribute="expr"></div>
<div onattribute="expr"></div> <!-- Синтаксис, совместимый с быстрыми приложениями -->
<div @attribute="expr"></div> <!-- Синтаксис стиля Vue -->
```

«атрибут» — это имя атрибута, изменения которого необходимо отслеживать, а «выражение» — это выражение, которое необходимо выполнить при изменении атрибута. Стандартная директива on использует префикс on:, а также поддерживает префиксы символов on и @.

Значение атрибута директивы on поддерживает синтаксис [значение атрибута команды](/framework/comment/template.md#значение атрибута команды).

::: совет
Рекомендуется использовать формат on:attribute. `onattribute` может легко привести к тому, что разработчики по незнанию перепутают директиву `on` с обычными атрибутами. Кроме того, имена атрибутов, такие как «oneself», будут анализироваться в инструкции «on:eself», поэтому следует уделить особое внимание.
:::

## Выражение прослушивания

### Базовое использование

Следующий код прослушивает события касания в компоненте div:
``` HTML
<div on:touchmove="console.log($event)"></div>
```
В этом примере прослушивается событие [`touchmove`](../generic/properties.md#touchmove) и здесь напрямую печатается [объект события касания](../generic/properties.md#touchevent). Переменная `$event` используется для получения значения события, которое представляет собой переменную, определенную директивой `on` (область действия находится только внутри выражения директивы `on`).

Вы также можете вызывать методы, определенные в объекте компонента:
``` HTML
<div on:touchmove="onTouch('move', $event)"></div>
```

``` js
экспортировать по умолчанию {
  onTouch (тип, событие) {
    console(`touch ${type}:`, событие)
  }
}
```

Способы настройки событий можно найти в [Межкомпонентное общение](../comComponent/communicate.md).

### Функциональное выражение

Если значение выражения слушателя является функцией, функция будет вызвана автоматически:
``` HTML
<div on:click="onClick" />
```

``` js
экспортировать по умолчанию {
  onClick (событие) {
    console.log(событие)
  }
}
```
Как показано в примере, значение события передается функции как единственный параметр.

::: совет
Выражение прослушивателя не обязательно должно быть функциональной переменной, но также может быть сложным выражением (например, выражением, содержащим вызов функции). Пока значение выражения является функцией, оно будет вызываться директивой on.
:::

## Прослушивание изменений значений атрибутов компонента

Некоторые компоненты генерируют события при изменении значений их свойств, что можно отслеживать с помощью директивы on:

``` HTML
<список на:index="indexChanged($event)">
  <содержание/>
</список>
```

Как описано в [Спецификация документа свойства](../comComponent/README.md#Спецификация документа свойства), свойства, поддерживающие **прослушивание**, могут использовать директиву `on` для прослушивания изменений значений.
