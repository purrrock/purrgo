# директива модели

Двусторонняя привязка свойств компонента может быть достигнута с помощью директивы model.

## Синтаксис

``` HTML
<com модель:prop="value"></com>
<com ::prop="value"></com>
```
Используйте префикс `model:` или аббревиатуру `::` в атрибуте, чтобы изменить атрибут, и вы можете использовать директиву `model` для двусторонней привязки. Где prop — это имя свойства целевого компонента, а value — имя свойства модели представления в текущем компоненте, требующем двусторонней привязки.

## Двусторонняя привязка

Используя [директиву `on`](on.md) и [выражение привязки свойства](/framework/compose/template.md#выражение привязки свойства) можно добиться двусторонней привязки между свойствами компонента и свойствами модели представления:
``` HTML
<дел>
  <switch :value="state" on:value="state = $event"/> значение: {{state}}
</div>
```

``` js
экспортировать по умолчанию {
  данные: {
    состояние: ложь
  },
  onReady() {
    setInterval(() => this.state = !this.state, 2000)
  }
}
```

Когда значение `this.state` изменено в коде JavaScript, выражение `:value="state"` в теге `switch` приведет к обновлению состояния отображения элемента `switch`, а выражение директивы `on` приведет к обновлению значения `state` после того, как пользователь щелкнет элемент `switch`.

Во время этого процесса состояние отображения интерфейса (компонент `switch` и текстовое `value: {{state}}`) и атрибут `state` в модели представления согласуются. Мы называем этот механизм **двусторонней привязкой**.

Директива model является, по сути, синтаксическим сахаром для описанного выше подхода, который позволяет выполнить простую двустороннюю привязку:
``` HTML
<дел>
  Значение <switch::value="state"/>: {{state}}
</div>
```

## Двусторонняя привязка пользовательских компонентов

Двусторонняя привязка часто используется для компонентов формы, но директива model также поддерживает пользовательские компоненты. Просто укажите событие с тем же именем для свойства пользовательского компонента и запускайте его при изменении свойства. Например:

``` js
// файл: com.ux
экспортировать по умолчанию {
  данные: {
    prop: 0 // Предположим, что вы хотите выполнить двустороннюю привязку атрибута prop
  },
  смотреть: {
    prop(x) { // Запускаем событие с тем же именем при изменении значения атрибута prop
      this.$emit('prop', x)
    }
  }
}
```
Предположим, что это частичный объект компонента пользовательского компонента, где свойство prop используется для двусторонней привязки. В этом примере объект «watch» используется для прослушивания изменений в свойстве «prop» и запускает событие с именем «prop» при его изменении. Просто выполните двустороннюю привязку в вызывающем компоненте следующим образом:
``` HTML
<com ::prop="valueName"></com>
```
