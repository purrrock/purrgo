# директива if/elif/else

Директивы `if`/`elif`/`else` используются для условного рендеринга. Эти директивы контролируют, будет ли отображаться компонент. Например, директива if будет отображать компонент только в том случае, если условие истинно, в противном случае компонент будет удален. Это отличается от свойства show компонента, которое контролирует, отображается ли компонент, но не удаляет его.

## Синтаксис

### если директива

``` HTML
<p if="cond">если: правда</p>
```
Если выражение `cond` истинно, компонент будет визуализирован, в противном случае он не будет визуализирован.

## директивы elif и else

Компоненты, содержащие директивы elif и else, должны следовать за компонентами, содержащими директивы if или elif, и использовать отрицание предыдущего условия, чтобы контролировать, отображается ли компонент:
``` HTML
<p if="cond1">если cond1: true</p>
<p elif="cond2">elif cond2: правда</p>
<p elif="cond3">elif cond3: правда</p>
<p else>else</p> <!-- директива else не поддерживает значения атрибутов -->
```
Код ведет себя следующим образом:
- Если условие `cond1` истинно, то будет отображаться только текст `if cond1: true`;
- В противном случае, если `cond2` имеет значение true, будет отображаться только `elif cond2: true`;
- В противном случае, если `cond3` имеет значение true, будет отображаться только `elif cond3: true`;
- Если все условия ложны, отобразите текст else.

Значения атрибутов директив `if`/`elif`/`else` поддерживают синтаксис [Значение атрибута инструкции](/framework/comComponent/template.md#Значение атрибута инструкции).
