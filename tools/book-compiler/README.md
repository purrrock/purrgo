# PurrGO Book Compiler

Конвертер книг (`.txt`, `.fb2`, `.fb2.zip`, `.epub`) в формат электронных книг PGB 1.0 для PurrGO.
Спецификация формата: [PGB-format.md](PGB-format.md).

## Требования

- Python 3.10 или новее, остальное - стандартная библиотека;
- необязательно: пакет `pyphen` для автоматической расстановки переносов (`--hyphenate`):

```console
python -m pip install -r requirements.txt
```

Таблица символов PurrGO-256 берётся из `../map-compiler/purrgo_models.py`, поэтому каталог `tools` нужно держать целиком.

## Использование

```console
python purrgo_book_compiler.py book.txt            # -> book.pgb
python purrgo_book_compiler.py book.fb2 BOOK.PGB
python purrgo_book_compiler.py book.epub BOOK.PGB --verify
```

Готовые файлы копируются на SD-карту в `0:/PURRGO/BOOKS/`.

Проверить готовый файл (структура, оба CRC, страницы), показав первую и последнюю страницы:

```console
python purrgo_book_compiler.py BOOK.PGB
```

## Параметры

| Параметр | Назначение |
|---|---|
| `--encoding auto\|utf-8\|cp1251\|cp866` | Кодировка `.txt`. По умолчанию `auto`: UTF-16 по BOM, затем UTF-8, иначе CP1251. CP866 надёжно отличить от CP1251 нельзя, указывайте явно. |
| `--title`, `--author` | Название и автор. По умолчанию из метаданных FB2 / EPUB, для `.txt` название - имя файла. Названия длиннее 200 и авторы длиннее 100 символов обрезаются. |
| `--reflow auto\|on\|off` | Только `.txt`: склеивать строки с жёсткими переносами (как в книгах Project Gutenberg) в абзацы. `auto` решает по длине строк; результат выводится в консоль. Абзацы разделяются пустой строкой или строкой с отступом от двух пробелов. |
| `--indent N` | Отступ первой строки абзаца (по умолчанию 2; для стихов в `.txt` ставьте 0). |
| `--collapse-blank` | Несколько пустых строк подряд сворачиваются в одну. |
| `--hyphenate LANG` | Переносы слов по словарю pyphen (`ru_RU`, `uk_UA`, `en_US`, ...). Без параметра слова переносятся только по пробелам и дефисам. |
| `--verify` | Перечитать записанный файл, проверить и показать первую и последнюю страницы. |

## Правила преобразования текста

- Переводы CRLF и CR нормализуются в LF, TAB заменяется четырьмя пробелами (для определения абзацев), текст приводится к NFC.
- Невидимые знаки (мягкий перенос, ZWSP, BOM) и знаки ударения удаляются.
- Тире и минус (`— – ‑ −`) заменяются на `-`, `…` на `...`, `×` на `x`, маркеры списков на `*`, `ﬁ` на `fi`, `²` на `2`, латинские буквы с диакритикой, которых нет в шрифте, - на базовую букву (`é` → `e`).
- Остальные символы вне таблицы PurrGO-256 становятся `?`.
- Строки переносятся по словам и после дефисов до 29 символов; слова длиннее строки режутся. Страница содержит максимум 32 строки, пустые строки в начале и конце страницы отбрасываются.
- Заголовки (FB2 `title`, `subtitle`; EPUB `h1`–`h6`) центрируются и отделяются пустыми строками.
- FB2: сноски (`<body name="notes">`) и изображения не включаются. EPUB: берётся текст файлов из spine, изображения, таблицы стилей и содержание (`nav`) пропускаются; книги с DRM не поддерживаются.
- Страницы хранятся без сжатия. Записываются `meta_crc32` (заголовок + метаданные + индекс) и `file_crc32` (весь файл).

После сборки конвертер сам проверяет структуру, оба CRC, непрерывность смещений, допустимые символы и размеры строк каждой страницы.
