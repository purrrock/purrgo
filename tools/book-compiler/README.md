# PurrGO Book Compiler

Конвертер книг (`.txt`, `.fb2`, `.fb2.zip`, `.epub`) в формат электронных книг PGB 1.1 для PurrGO: текст (24 строки по 29 символов) и страницы-картинки (обложка, иллюстрации) в 1 bit с дизерингом.

> PGB 1.1 несовместим с 1.0: читалка файлы 1.0 не открывает («unsupported version»), книги нужно пересобрать этим конвертером.
Спецификация формата: [PGB-format.md](PGB-format.md).

## Требования

- Python 3.10 или новее, остальное - стандартная библиотека; для графического интерфейса нужен `tkinter` (в Windows и macOS идёт с Python, в Linux: `sudo apt install python3-tk`);
- необязательно: пакет `Pillow` - обложка и иллюстрации (без него книга собирается без картинок, конвертер об этом сообщает);
- необязательно: пакет `lz4` - сжатие страниц режимом HC (без него работает встроенный кодер LZ4, файл получается примерно столько же, результат детерминирован);
- необязательно: пакет `pyphen` для автоматической расстановки переносов (`--hyphenate`):

```console
python -m pip install -r requirements.txt
```

Таблица символов PurrGO-256 берётся из `../map-compiler/purrgo_models.py`, поэтому каталог `tools` нужно держать целиком.

## Графический интерфейс

Запуск без параметров открывает окно: слева файлы, метаданные и настройки преобразования, справа предпросмотр страниц ровно в том виде, в каком текст попадёт в книгу (29 колонок, линейка над страницей, режим «пробелы как ·», размер шрифта предпросмотра). Предпросмотр пересчитывается после каждой правки настроек. Блок «Обложка и иллюстрации» управляет картинками: включение иллюстраций и обложки, дизеринг, автоконтраст, увеличение маленьких картинок, порог «украшений» и своя обложка. Страницы-картинки в предпросмотре показываются ровно в том виде, в каком их выведет читалка (1 bit), вдвое увеличенными. Под настройками показаны число страниц, размер текста и файла, степень сжатия и принятые решения (кодировка, склейка строк).

- перелистывание: кнопки, поле номера страницы, ползунок, стрелки и PageUp/PageDown/Home/End, колесо мыши над страницей;
- «Сохранить PGB» записывает файл и перечитывает его проверкой;
- «Открыть PGB…» показывает готовый файл (структура, оба CRC, распаковка каждой страницы).

```console
python purrgo_book_compiler.py                # окно
python purrgo_book_compiler.py --gui book.fb2 # окно с уже открытой книгой
```

## Командная строка

Любой запуск с параметрами работает в консоли, без окна.

```console
python purrgo_book_compiler.py book.txt            # -> book.pgb
python purrgo_book_compiler.py book.fb2 BOOK.PGB
python purrgo_book_compiler.py book.epub BOOK.PGB --verify
python purrgo_book_compiler.py book.fb2 --cover cover.jpg --dither atkinson
python purrgo_book_compiler.py book.epub --save-images shots   # PNG страниц-картинок для просмотра
```

Готовые файлы копируются на SD-карту в `0:/PURRGO/BOOKS/`.

Проверить готовый файл (структура, оба CRC, страницы), показав первую и последнюю страницы:

```console
python purrgo_book_compiler.py BOOK.PGB
```

## Параметры

| Параметр | Назначение |
|---|---|
| `--encoding auto\|utf-8\|cp1251\|cp866` | Кодировка `.txt`. По умолчанию `auto`: UTF-16 по BOM, затем UTF-8, иначе CP1251. CP866 надёжно отличить от CP1251 нельзя, указывайте явно. |
| `--title`, `--author` | Название и автор. По умолчанию из метаданных FB2 / EPUB, для `.txt` название - имя файла. Названия длиннее 200 и авторы длиннее 100 символов обрезаются. |
| `--reflow auto\|on\|off` | Только `.txt`: склеивать строки с жёсткими переносами (как в книгах Project Gutenberg) в абзацы. `auto` решает по длине строк; результат выводится в консоль. Абзацы разделяются пустой строкой или строкой с отступом от двух пробелов. |
| `--indent N` | Отступ первой строки абзаца (по умолчанию 2; для стихов в `.txt` ставьте 0). |
| `--collapse-blank` | Несколько пустых строк подряд сворачиваются в одну. |
| `--blank-between-paragraphs` | Разделять абзацы пустой строкой (по умолчанию отключено). |
| `--hyphenate LANG` | Переносы слов по словарю pyphen (`ru_RU`, `uk_UA`, `en_US`, ...). Без параметра слова переносятся только по пробелам и дефисам. |
| `--compression lz4\|none` | Сжатие каждой страницы отдельным LZ4 Block (по умолчанию `lz4`). Страница, которую сжатие не уменьшило, хранится как есть. |
| `--cover FILE` | Своя обложка (jpg, png, gif, bmp, webp) вместо обложки из книги; первая страница книги. |
| `--no-cover` | Не добавлять обложку. |
| `--no-images` | Не включать иллюстрации из текста FB2 / EPUB (обложка управляется отдельно). Текст вокруг пропущенных картинок не разрывается. |
| `--dither fs\|atkinson\|bayer\|none` | Дизеринг картинок до 1 bit: Floyd-Steinberg со змейкой (по умолчанию), Atkinson (контрастнее, лучше для штриховых рисунков), упорядоченный Bayer 8x8, порог. |
| `--no-autocontrast` | Не растягивать контраст картинок перед дизерингом. |
| `--upscale` | Увеличивать картинки меньше окна 176x256 (по умолчанию картинки только уменьшаются). |
| `--min-image PX` | Пропускать картинки, у которых обе стороны меньше PX пикселей (украшения, значки; по умолчанию 64). |
| `--save-images DIR` | Сохранить страницы-картинки готовой книги в DIR как `page_NNNN.png` (так их покажет читалка). Работает и при проверке готового `.pgb`. |
| `--gui` | Открыть окно (с указанной книгой). |
| `--verify` | Перечитать записанный файл, проверить и показать первую и последнюю страницы. |

## Правила преобразования текста

- Переводы CRLF и CR нормализуются в LF, TAB заменяется четырьмя пробелами (для определения абзацев), текст приводится к NFC.
- Невидимые знаки (мягкий перенос, ZWSP, BOM) и знаки ударения удаляются.
- Тире и минус (`— – ‑ −`) заменяются на `-`, `…` на `...`, `×` на `x`, маркеры списков на `*`, `ﬁ` на `fi`, `²` на `2`, латинские буквы с диакритикой, которых нет в шрифте, - на базовую букву (`é` → `e`).
- Остальные символы вне таблицы PurrGO-256 становятся `?`.
- Строки переносятся по словам и после дефисов до 29 символов; слова длиннее строки режутся. Страница содержит максимум 24 строки (на экране шаг строк 10 px), пустые строки в начале и конце страницы отбрасываются.
- Заголовки (FB2 `title`, `subtitle`; EPUB `h1`–`h6`) центрируются и отделяются пустыми строками.
- FB2: сноски (`<body name="notes">`) не включаются; обложка (`<coverpage>`) и изображения (`<image l:href="#...">`, данные `<binary>` в Base64) становятся страницами-картинками. EPUB: берётся текст файлов из spine, таблицы стилей и содержание (`nav`) пропускаются; обложка (`<meta name="cover">` или `cover-image`), `<img>` и SVG `<image>` становятся страницами-картинками; книги с DRM не поддерживаются.
- Картинки: прозрачность заливается белым, картинка переводится в серый, вписывается в окно 176x256 с сохранением пропорций (по умолчанию только уменьшается), растягивается контраст, затем дизеринг до 1 bit. Картинка всегда занимает отдельную страницу (текст перед ней заканчивает страницу); обложка - первая страница; обложка, повторяющаяся в начале текста, не дублируется. Картинки меньше `--min-image` пикселей по обеим сторонам, SVG и нечитаемые файлы пропускаются с сообщением.
- Каждая страница сжимается отдельным сырым LZ4 Block (не LZ4 Frame). Записываются `meta_crc32` (заголовок + метаданные + индекс) и `file_crc32` (весь файл, данные страниц в сжатом виде).

После сборки конвертер сам проверяет структуру, оба CRC, непрерывность смещений и **распаковывает каждую страницу собственным строгим декодером** (независимым от кодера), проверяя допустимые символы и размеры строк текста, а у картинок - размеры, окно и нулевые биты выравнивания строк.
