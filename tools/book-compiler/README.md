# PurrGO Book Compiler

Конвертер обычного текстового файла в формат электронных книг PGB 1.0 для PurrGO.

## Требования

- Python 3.10 или новее
- пакет Python `lz4`

Установка зависимости:

```console
python -m pip install -r requirements.txt
```

## Использование

```console
python purrgo_book_compiler.py input.txt output.PGB
```

По умолчанию исходный файл читается как UTF-8, а название книги берётся из имени файла без расширения.

Другие кодировки:

```console
python purrgo_book_compiler.py book.txt book.PGB --encoding cp1251
python purrgo_book_compiler.py book.txt book.PGB --encoding cp866
```

Название можно задать явно:

```console
python purrgo_book_compiler.py book.txt book.PGB --title "Название книги"
```

`--verify` дополнительно перечитывает записанный файл и повторно проверяет его:

```console
python purrgo_book_compiler.py book.txt book.PGB --verify
```

## Правила преобразования текста

- Переводы CRLF и CR нормализуются в LF.
- TAB заменяется одним пробелом.
- Другие управляющие символы заменяются пробелом; NUL заменяется `?`.
- Символы переводятся в PurrGO-256 по таблице из `src/core/pgo_text.c` и `tools/map-compiler/purrgo_models.py`; неподдерживаемые символы становятся `?`.
- Несколько пробелов между словами схлопываются.
- Строки переносятся по словам до 29 символов.
- Слова длиннее 29 символов разрезаются на фрагменты по 29 символов.
- Пустые исходные строки сохраняются.
- Одна завершающая новая строка трактуется как конец файла, а не как дополнительная пустая строка.
- Страница содержит максимум 32 строки; каждая страница сжимается отдельным сырым LZ4 Block (не LZ4 Frame).
- В файл записывается один CRC-32/ISO-HDLC всего файла; байты поля CRC при расчёте считаются нулевыми.

Автоматическое распознавание CP1251 против CP866 не выполняется: оба формата однобайтовые, и надёжно определить их только по байтам общего случая нельзя. Выбирайте `--encoding` явно.

## Формат

Файл формируется согласно спецификации PGB 1.0:
- заголовок — 64 байта;
- запись индекса — 12 байт на страницу;
- заголовок и индекс используют little-endian;
- название книги хранится в PurrGO-256 сразу после индекса;
- страницы следуют подряд и содержат сырые LZ4 Block данные;
- CRC-32 расположен по смещению 36.

После сборки конвертер автоматически проверяет структуру, CRC, непрерывность смещений, размеры строк и распаковку каждой страницы.

## Важное замечание

Таблица PurrGO-256 в конвертере должна синхронно обновляться с таблицей проекта. При изменениях `src/core/pgo_text.c` или `_PGO_CHAR_MAP` следует сверить эту копию.
